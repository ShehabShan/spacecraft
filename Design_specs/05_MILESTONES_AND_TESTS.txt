# 05_MILESTONES_AND_TESTS


This document dictates the exact build sequence. The AI coder MUST complete and pass the Acceptance Tests of the current milestone before writing code for the next.


## Milestone 1A: Core F64 Skeleton & Floating Origin
*   **Goal:** Establish the pure TypeScript `Float64` simulation core, Zustand store, and the 256m discrete origin rebasing system.
*   **Acceptance Test:** Fly a dummy object in a straight line at 2,000 m/s for 10,000 metres. The `Float64` absolute coordinates must track correctly, and the `Float32` Three.js local coordinates must never exceed ~3,000m. The origin shift must produce zero visible frame stutter.


## Milestone 1B: Rails & Two-Tier Time
*   **Goal:** Implement closed-form Kepler equations for the planets and moons using 30x macro time (`simTime`).
*   **Acceptance Test:** Fast-forward `simTime` by 60 days. The planets must instantly snap to their exact real-world relative positions. Reversing `simTime` by 60 days must return them to the exact starting pixel.


## Milestone 1C: Web Worker Terrain & Zero-GC Pool
*   **Goal:** Implement the Spherified Cube projection, 3D Noise, Skirts, and Exact Normals in a Web Worker, piped back to the Main Thread via Transferables.
*   **Acceptance Test:** Fly across the surface at 2,000 m/s for 60 seconds. `renderer.info.memory.geometries` must remain absolutely constant. V8 Memory profiling must show <1KB of allocation per frame (Zero-GC stutter).


## Milestone 1D: Flight & Aerodynamic Governor
*   **Goal:** Implement 2,000 m/s kinematic flight, 2D DDA raycast collision, and the exponential drag governor.
*   **Acceptance Test:** Dive straight down at Earth at 2,000 m/s. The governor must mathematically force the ship to  by 1,000m altitude. The ship must *never* clip through the procedural ground, even if Web Worker chunk generation is intentionally delayed by 2 seconds.


## Milestone 1E: The Spherical Astronaut
*   **Goal:** Implement the Kinematic Character Controller, quaternion parallel transport for surface walking, and Coriolis relative-velocity handoff.
*   **Acceptance Test:** Jump vertically on the equator of a planet spinning at 52 m/s. The astronaut must land slightly west (Coriolis drift) but must immediately settle into a 0 m/s relative walk state without "skating" or sliding.


## Milestone 1F: 3-Camera Layers & Impostors
*   **Goal:** Set up the Near/Mid/Far cameras, object assignment logic, and the Impostor Ray-Cone shader.
*   **Acceptance Test:** Fly away from a planet crossing the 2.4km (Near/Mid) and 250km (Mid/Far) thresholds. Record the screen. The pixel difference across the threshold frame must be identically zero.


## Milestone 1G: Pause-and-Prime Save/Load
*   **Goal:** Implement IndexedDB state serialization and the strictly-gated hydration pipeline.
*   **Acceptance Test:** Save the game while diving at 2,000 m/s, 500m above the terrain. Reload the save. The game must freeze, display a loading overlay, generate the terrain beneath the ship, confirm `intersectionsWithShape == EMPTY`, and only then unpause the physics loop. The ship must not take damage or clip upon loading.
