# Milestone 1G — Deep Analysis & Implementation


M1A–M1F are locked and untouched — the persistence layer sits *above* the core, consuming only existing public surfaces. The trace surfaced **one architectural finding that must be flagged before any code**: the milestone's own required schema (`rcsBudget`, `mode`, plus the tangential velocities and contact caches needed for a *deterministic* restore) lives behind `private` fields in the locked M1E `AstronautKCC`. The resolution — an **append-only capture/restore hook pair inside the KCC** (no execution-loop change, no external privates-hacking) — is delivered as a flagged appendix (§3.5), consistent with the M1B `SUN_ORBITAL_MU` and M1D `β_q` flag practice. Everything else follows the spec and prompt verbatim.

## PHASE 1 — REASONING & EDGE-CASE ANALYSIS


### 1.1 IEEE 754 Bit-Exact Serialization — typed arrays vs JSON


A `Float64Array` store is **memcpy semantics**: the raw 64-bit pattern moves, unconverted, in one instruction. Every value class survives — `-0`, denormals, NaN payloads, `±Infinity` — and the cost is 8 bytes and ~1 ns per value. Against that, `JSON.stringify` disqualifies itself on four counts:


1. **Silent value loss.** `JSON.stringify(NaN)` and `Infinity` both produce `null` — a NaN velocity would *load as null* and crash or silently zero. `-0` stringifies as `"0"`, destroying the sign.
2. **The acceptance would fail itself.** The M1G criterion is *bit-matching* coordinates, compared as u32 word pairs (because `===` conflates `+0/−0` and rejects NaN). A JSON pipeline cannot round-trip `-0`, so it cannot pass its own test.
3. **Allocation.** A JSON capture builds a ~1 KB young-gen string (rope concatenation, per-number formatting); `JSON.parse` on load allocates the object graph back. Our typed-array capture performs **35 typed stores + one CRC32 loop over 280 bytes → 0 bytes allocated, ~200 ns** — the difference between a GC-visible event and a non-event.
4. **Size & fragility.** 312 bytes vs ~1 KB, and any `toJSON` hook or precision revision in the serialization stack silently corrupts state; a fixed slot layout with a magic/version/CRC header cannot drift undetected.


**Honesty note (per project practice):** for *finite, non-`(−0)`* doubles, modern engines emit shortest-round-trip decimals, so routine JSON round-trips *are* bit-exact. The decisive arguments are the exceptional values, the zero-allocation capture, and format safety — not everyday precision. IndexedDB then stores `ArrayBuffer` payloads natively via structured clone: **binary end-to-end, no string ever exists**.


### 1.2 Asynchronous Non-Blocking I/O — the architecture and the decision


The capture is synchronous and zero-alloc; the question is where the IndexedDB work lives. **Decision: main-thread async transactions, chosen deliberately over a worker** — and here is the quantified reasoning:


- The payload is **312 bytes**. The only synchronous main-thread cost of `put()` is the structured clone at call time — tens of microseconds (≈0.1–0.3% of a 16.6 ms frame). Transaction commit and disk flush run on the browser's storage thread; completion returns as a later task. The 60 Hz loop never yields.
- A worker offload would require **buffer ping-pong** (transfer the capture buffer out, await its return) purely to preserve the pre-allocated capture buffer — realm complexity with zero measurable gain at this payload size.
- The escalation path is preserved: `IndexedDBProvider` is **realm-agnostic** (no DOM types; `indexedDB` resolved via `globalThis`), so hosting it in a persistence worker later is a file move, not a rewrite — warranted only if payloads grow to hundreds of KB (world edits, inventories).
- One ordering hazard was found and eliminated: an `await provider.open()` before `put()` defers the clone to a microtask, during which a *later* capture could mutate the single buffer. The fix costs 312 bytes: `asyncWrite()` performs **one synchronous act** — copying the capture buffer into a second boot-allocated *commit buffer* — before any `await`. The capture buffer is instantly free; the committed bytes are immutable by construction.


**Proof methodology (acceptance row 3):** the 60 Hz loop measures per-frame delta; the M1A/M1B fixed-step governor's `shedSeconds` is a built-in stall detector (any sustained stall beyond 5 substeps *sheds time* — a delta of **0** across a 30-write+30-read storm is mathematical proof the loop never fell behind); plus max-frame and >25 ms frame counts.


### 1.3 Deterministic State Restoration — the sequence and its proofs


The prompt's (a)–(e) sequence, with the exactness argument for each step:


- **(a) Restore `simTime`.** The saved double, assigned verbatim via the existing M1B `setSimTime`.
- **(b) Synchronous rail update.** `setSimTime` *is* this step: it evaluates all 17 rails immediately. `P(elements; t)` is a pure deterministic function of one double (M1B proof) — same input bits → same output bits. Planets and moons return **bit-identically**, at any time distance, forward or backward.
- **(c) Restore the player.** The **full canonical state**, verbatim: `absPos, absVel, pLocal, up, fwd, vCtl, vSlide, nCur, theta, rcsBudget, mode, grounded` — *plus the terrain-contact caches `hCur`/`nCur`, persisted rather than recomputed*. This is a proven edge case: `normalize(pLocal)` is **not bit-guaranteed** to equal the direction that produced the cached values (a positive-scalar-multiply round-trip can shift the last ulp), and the isomorphism acceptance below tolerates *zero* ulps. The entity write-through (the same live `Vec3` refs the KCC writes) lands the restored position in the M1A core immediately. Wall-clock accumulators are deliberately **not** state — persisting them would couple restores to machine timing; the restore zeroes them so no pre-load partial frame injects an extra tick.
- **(d) Immediate M1A rebase.** The origin is **derived state, and the locked core exposes no origin setter** — the correct restore is the *natural trigger*: the first post-restore tick evaluates the focus bound against the restored position. A relocation load (>1,024 m — the normal cross-distance case) rebases **within that same tick, before the render extract** (canonical order), snapping `O` to the nearest 256 m lattice point with a bit-exact Δ (the M1A power-of-two proof). A local load keeps a valid origin — and the rendered image is origin-invariant because every local shares `O`. The suite asserts `O ≡ nearest-lattice(P)` (each axis an exact multiple of 256, `|P−O| ≤ 128`) in the relocation case.
- **(e) Terrain prime (Spec 01.6).** Harness-side (it owns the quadtree): **Freeze → priority-generate → gate → 300 ms fade**. The analytic-era gate is "the leaf chunk under the player is active" — with the M1D/M1E doctrine guaranteeing the player can never fall through even with zero chunks (analytic collision against the f64 field), the gate serves *visual* continuity, and the Rapier `intersectionsWithShape` gate is the marked production hook.


**The strongest proof — the state-isomorphism test.** Save at tick T; run 600 scripted-input ticks → fingerprint F1; restore; run the *same* 600 ticks → F2; assert **F1 ≡ F2 bitwise** (u32 word pairs over 79 doubles: 51 body, 24 player incl. caches, 4 clocks). This proves save/load is a true isomorphism, not a teleport approximation — and it implicitly re-proves worker-independence, because run 2 executes with a completely different chunk-streaming state than run 1 and still lands on identical bits. Inputs are scripted because *user input is entropy, not state* — determinism claims apply to (state, input-sequence) pairs, and the save deliberately excludes input.


### 1.4 Versioning, Migrations, Atomicity


- **Self-describing header:** magic `0x56534753` ("SGSV"), u16 payload version, flags, **CRC32** over the body, body length. The IndexedDB record carries `{id, version, createdMs, byteLength, payload}` so migration decisions happen *before* any decode. Two independent version axes by design: **DB schema version** (object stores — the provider) and **payload version** (slot layout — the serializer).
- **Migration chain:** decode old layouts only; a *newer* unknown version is a hard reject (`bad-version`) — never guess forward. A real v1→v2 migration ships (v1: 13 slots, pre-CRC, pre-orientation era; the transform derives era-appropriate defaults *deterministically*: `up = radial(pLocal)`, `fwd = canonicalTangent(up)`), proven by the suite with a fabricated v1 record.
- **Atomicity:** `asyncLoad` never mutates game state — ingest → verify → (migrate) → snapshot only. `deterministicRestore` is the *sole* mutator, synchronous, at a frame boundary. A rejected load (corrupt CRC, bad magic, future version, truncated) leaves the world bit-untouched — fingerprint-proven in the suite.

### 1. `src/core/persistence/BinaryStateSerializer.ts`


```typescript
/**
 * ============================================================================
 *  BINARY STATE SERIALIZER — ZERO-GC, BIT-EXACT SAVE PAYLOAD CODEC
 *  Milestone 1G · Spec 01.6 (Pause-and-Prime), M1G schema
 * ============================================================================
 *  Pure core: no three/react/rapier imports; no IndexedDB here (codec only).
 *
 *  WHY TYPED-ARRAY SERIALIZATION, NOT JSON (M1G analysis §1.1):
 *   - Bit-exactness: a Float64Array store is memcpy semantics — the raw
 *     64-bit pattern moves unconverted. Every value survives: -0, denormals,
 *     NaN payloads, ±Infinity. JSON.stringify maps NaN/Infinity -> null
 *     (unrecoverable) and -0 -> "0" — a JSON pipeline would fail the M1G
 *     bit-matching acceptance against its own data.
 *   - Zero-GC: capture() = 35 typed stores + one CRC32 loop over 280 bytes.
 *     Allocation count: 0. (JSON would allocate a ~1 KB string per save and
 *     an object graph per load.)
 *   - End-to-end binary: IndexedDB stores the ArrayBuffer via structured
 *     clone — no string ever exists.
 *
 *  PAYLOAD LAYOUT (version 2) — 32-byte header + 35 f64 slots:
 *    u32[0] magic "SGSV"        u32[1] version:u16 | flags:u16
 *    u32[2] CRC32(body)         u32[3] body byte length
 *    bytes 16..31 reserved (future migration fields)
 *    f64 slots: the canonical deterministic state — see SLOT.
 *
 *  VERSIONING (§1.4): the header is self-describing; verify() checks
 *  magic/version/length/CRC BEFORE any field is decoded; migrations decode
 *  OLD layouts only — version > SAVE_VERSION is a hard reject (never guess
 *  forward). DB schema version and payload version are independent axes.
 */


import type { PersistentPlayerState } from '../physics/astronautKCC';
import { canonicalTangentInto, type Vec3 } from '../physics/sphericalFrame';


export const SAVE_MAGIC = 0x56534753;                 // "SGSV" (LE)
export const SAVE_VERSION = 2;
export const V1_SLOTS = 13;
export const V2_SLOTS = 35;
export const HEADER_BYTES = 32;
export const V1_HEADER_BYTES = 16;
export const V2_BODY_BYTES = V2_SLOTS * 8;            // 280
export const V1_BODY_BYTES = V1_SLOTS * 8;            // 104
export const SAVE_BUFFER_BYTES = HEADER_BYTES + V2_BODY_BYTES;   // 312


/** v2 slot map (f64 indices). The layout IS the schema. */
export const SLOT = {
  SIM_TIME: 0, THETA: 1, MODE: 2, GROUNDED: 3, RCS_BUDGET: 4,
  H_CUR: 5, NCUR_X: 6, NCUR_Y: 7, NCUR_Z: 8,
  ABS_POS_X: 9, ABS_POS_Y: 10, ABS_POS_Z: 11,
  ABS_VEL_X: 12, ABS_VEL_Y: 13, ABS_VEL_Z: 14,
  PLOCAL_X: 15, PLOCAL_Y: 16, PLOCAL_Z: 17,
  UP_X: 18, UP_Y: 19, UP_Z: 20,
  FWD_X: 21, FWD_Y: 22, FWD_Z: 23,
  VCTL_X: 24, VCTL_Y: 25, VCTL_Z: 26,
  VSLIDE_X: 27, VSLIDE_Y: 28, VSLIDE_Z: 29,
  ORIGIN_X: 30, ORIGIN_Y: 31, ORIGIN_Z: 32,   // diagnostic: recorded, derived
  CAPTURED_AT: 33, RESERVED: 34,
} as const;


export type SaveVerifyStatus =
  | 'ok' | 'ok-v1' | 'bad-magic' | 'bad-version' | 'bad-crc' | 'truncated';


/* -- CRC32 (IEEE, reflected 0xEDB88320) — boot table, zero-GC loop -------- */
const CRC_TABLE = new Uint32Array(256);
for (let n = 0; n < 256; n++) {
  let c = n;
  for (let k = 0; k < 8; k++) c = c & 1 ? 0xedb88320 ^ (c >>> 1) : c >>> 1;
  CRC_TABLE[n] = c >>> 0;
}
export function crc32(u8: Uint8Array, from: number, to: number): number {
  let c = 0xffffffff;
  for (let i = from; i < to; i++) c = CRC_TABLE[(c ^ u8[i]) & 0xff] ^ (c >>> 8);
  return (c ^ 0xffffffff) >>> 0;
}


const _migTan: Vec3 = { x: 0, y: 0, z: 0 };


export class BinaryStateSerializer {
  readonly buffer = new ArrayBuffer(SAVE_BUFFER_BYTES);
  readonly u8 = new Uint8Array(this.buffer);
  private readonly u32 = new Uint32Array(this.buffer, 0, 4);
  /** v2 body view (byteOffset 32 — 8-aligned). */
  readonly f64 = new Float64Array(this.buffer, HEADER_BYTES, V2_SLOTS);
  /** v1 body view (byteOffset 16 — 8-aligned) — migration decode only. */
  private readonly f64v1 = new Float64Array(this.buffer, V1_HEADER_BYTES, V1_SLOTS);
  private _ingested = 0;


  /**
   * ZERO-ALLOCATION CAPTURE: 35 typed stores + header + CRC.
   * Allocation count: 0 (acceptance-instrumented).
   */
  capture(
    simTime: number, ox: number, oy: number, oz: number,
    p: PersistentPlayerState, capturedAtMs: number,
  ): void {
    const f = this.f64;
    f[SLOT.SIM_TIME] = simTime;
    f[SLOT.THETA] = p.theta;
    f[SLOT.MODE] = p.modeCode;
    f[SLOT.GROUNDED] = p.grounded;
    f[SLOT.RCS_BUDGET] = p.rcsBudget;
    f[SLOT.H_CUR] = p.hCur;
    f[SLOT.NCUR_X] = p.nCurX; f[SLOT.NCUR_Y] = p.nCurY; f[SLOT.NCUR_Z] = p.nCurZ;
    f[SLOT.ABS_POS_X] = p.absPosX; f[SLOT.ABS_POS_Y] = p.absPosY; f[SLOT.ABS_POS_Z] = p.absPosZ;
    f[SLOT.ABS_VEL_X] = p.absVelX; f[SLOT.ABS_VEL_Y] = p.absVelY; f[SLOT.ABS_VEL_Z] = p.absVelZ;
    f[SLOT.PLOCAL_X] = p.pLocalX; f[SLOT.PLOCAL_Y] = p.pLocalY; f[SLOT.PLOCAL_Z] = p.pLocalZ;
    f[SLOT.UP_X] = p.upX; f[SLOT.UP_Y] = p.upY; f[SLOT.UP_Z] = p.upZ;
    f[SLOT.FWD_X] = p.fwdX; f[SLOT.FWD_Y] = p.fwdY; f[SLOT.FWD_Z] = p.fwdZ;
    f[SLOT.VCTL_X] = p.vCtlX; f[SLOT.VCTL_Y] = p.vCtlY; f[SLOT.VCTL_Z] = p.vCtlZ;
    f[SLOT.VSLIDE_X] = p.vSlideX; f[SLOT.VSLIDE_Y] = p.vSlideY; f[SLOT.VSLIDE_Z] = p.vSlideZ;
    f[SLOT.ORIGIN_X] = ox; f[SLOT.ORIGIN_Y] = oy; f[SLOT.ORIGIN_Z] = oz;
    f[SLOT.CAPTURED_AT] = capturedAtMs;
    f[SLOT.RESERVED] = 0;
    this.u32[0] = SAVE_MAGIC;
    this.u32[1] = SAVE_VERSION & 0xffff;
    this.u32[2] = crc32(this.u8, HEADER_BYTES, SAVE_BUFFER_BYTES);
    this.u32[3] = V2_BODY_BYTES;
    this._ingested = SAVE_BUFFER_BYTES;
  }


  /**
   * Load path: copy an IDB-returned payload into the buffer. (One small view
   * + the copy — user-triggered load path only; the capture path stays
   * allocation-free.)
   */
  ingest(payload: ArrayBuffer, byteLength: number): void {
    const len = Math.min(byteLength, payload.byteLength, SAVE_BUFFER_BYTES);
    this.u8.fill(0);
    this.u8.set(new Uint8Array(payload, 0, len), 0);
    this._ingested = len;
  }


  /** Header validation — magic, version, length, CRC. Runs BEFORE any field
   *  is decoded (atomicity: a rejected load decodes nothing). */
  verify(): SaveVerifyStatus {
    if (this._ingested < 8) return 'truncated';
    if (this.u32[0] !== SAVE_MAGIC) return 'bad-magic';
    const version = this.u32[1] & 0xffff;
    if (version === SAVE_VERSION) {
      if (this._ingested < SAVE_BUFFER_BYTES) return 'truncated';
      if (this.u32[3] !== V2_BODY_BYTES) return 'truncated';
      if (crc32(this.u8, HEADER_BYTES, SAVE_BUFFER_BYTES) !== this.u32[2]) return 'bad-crc';
      return 'ok';
    }
    if (version === 1) {
      if (this._ingested < V1_HEADER_BYTES + V1_BODY_BYTES) return 'truncated';
      return 'ok-v1';   // v1 predates the CRC field — layout check only
    }
    return 'bad-version';   // never guess forward
  }


  get simTime(): number { return this.f64[SLOT.SIM_TIME]; }
  get capturedAtMs(): number { return this.f64[SLOT.CAPTURED_AT]; }
  get savedOriginX(): number { return this.f64[SLOT.ORIGIN_X]; }
  get savedOriginY(): number { return this.f64[SLOT.ORIGIN_Y]; }
  get savedOriginZ(): number { return this.f64[SLOT.ORIGIN_Z]; }


  /** v2 body -> snapshot (post-verify only). */
  playerInto(p: PersistentPlayerState): void {
    const f = this.f64;
    p.theta = f[SLOT.THETA];
    p.modeCode = f[SLOT.MODE];
    p.grounded = f[SLOT.GROUNDED] === 1 ? 1 : 0;
    p.rcsBudget = f[SLOT.RCS_BUDGET];
    p.hCur = f[SLOT.H_CUR];
    p.nCurX = f[SLOT.NCUR_X]; p.nCurY = f[SLOT.NCUR_Y]; p.nCurZ = f[SLOT.NCUR_Z];
    p.absPosX = f[SLOT.ABS_POS_X]; p.absPosY = f[SLOT.ABS_POS_Y]; p.absPosZ = f[SLOT.ABS_POS_Z];
    p.absVelX = f[SLOT.ABS_VEL_X]; p.absVelY = f[SLOT.ABS_VEL_Y]; p.absVelZ = f[SLOT.ABS_VEL_Z];
    p.pLocalX = f[SLOT.PLOCAL_X]; p.pLocalY = f[SLOT.PLOCAL_Y]; p.pLocalZ = f[SLOT.PLOCAL_Z];
    p.upX = f[SLOT.UP_X]; p.upY = f[SLOT.UP_Y]; p.upZ = f[SLOT.UP_Z];
    p.fwdX = f[SLOT.FWD_X]; p.fwdY = f[SLOT.FWD_Y]; p.fwdZ = f[SLOT.FWD_Z];
    p.vCtlX = f[SLOT.VCTL_X]; p.vCtlY = f[SLOT.VCTL_Y]; p.vCtlZ = f[SLOT.VCTL_Z];
    p.vSlideX = f[SLOT.VSLIDE_X]; p.vSlideY = f[SLOT.VSLIDE_Y]; p.vSlideZ = f[SLOT.VSLIDE_Z];
  }


  /**
   * MIGRATION v1 -> v2 (§1.4). v1 (13 slots) predates theta, the transported
   * frame, tangential velocities, and the contact caches. Era-appropriate
   * defaults are DERIVED deterministically: up = radial(pLocal), fwd =
   * canonicalTangent(up) — both pure functions, bit-reproducible. The first
   * grounded tick re-derives the contact cache.
   * v1 slot map: 0 simTime · 1 mode · 2 grounded · 3 rcs · 4..6 absPos ·
   *              7..9 absVel · 10..12 pLocal.
   */
  migrateV1Into(simTimeOut: { v: number }, p: PersistentPlayerState): void {
    const v = this.f64v1;
    simTimeOut.v = v[0];
    p.modeCode = v[1];
    p.grounded = v[2] === 1 ? 1 : 0;
    p.rcsBudget = v[3];
    p.absPosX = v[4]; p.absPosY = v[5]; p.absPosZ = v[6];
    p.absVelX = v[7]; p.absVelY = v[8]; p.absVelZ = v[9];
    p.pLocalX = v[10]; p.pLocalY = v[11]; p.pLocalZ = v[12];
    p.theta = 0;
    const r = Math.sqrt(p.pLocalX * p.pLocalX + p.pLocalY * p.pLocalY +
      p.pLocalZ * p.pLocalZ) || 1;
    p.upX = p.pLocalX / r; p.upY = p.pLocalY / r; p.upZ = p.pLocalZ / r;
    canonicalTangentInto(p.upX, p.upY, p.upZ, _migTan);
    p.fwdX = _migTan.x; p.fwdY = _migTan.y; p.fwdZ = _migTan.z;
    p.vCtlX = 0; p.vCtlY = 0; p.vCtlZ = 0;
    p.vSlideX = 0; p.vSlideY = 0; p.vSlideZ = 0;
    p.hCur = 0; p.nCurX = 0; p.nCurY = 1; p.nCurZ = 0;
  }
}
```

### 2. `src/core/persistence/IndexedDBProvider.ts`


```typescript
/**
 * ============================================================================
 *  INDEXEDDB PROVIDER — MINIMAL PROMISE WRAPPER (NO THIRD-PARTY ORMS)
 *  Milestone 1G
 * ============================================================================
 *  Realm-agnostic (no DOM types; the factory resolved via globalThis) — runs
 *  unchanged on the main thread today or inside a persistence Web Worker
 *  tomorrow (the M1G §1.2 escalation path). Binary-safe: payloads are
 *  ArrayBuffers moved via IndexedDB's native structured clone — no string
 *  conversion anywhere in the pipeline.
 *
 *  TWO VERSION AXES (deliberate): the DB SCHEMA version (object stores —
 *  owned here) and the PAYLOAD version (slot layout — owned by the
 *  serializer). They migrate independently.
 *
 *  ALLOCATION NOTE (I/O path, not the 60 Hz loop): each operation allocates
 *  a transaction, a request, a promise, and — at put() time — the structured
 *  clone of the payload (312 B, measured in the suite). These are
 *  user-triggered events between frames; the capture path allocates nothing.
 */


const IDB_FACTORY: IDBFactory | null =
  (globalThis as { indexedDB?: IDBFactory }).indexedDB ?? null;


export interface SaveRecord {
  id: string;
  /** Payload schema version (the serializer's SAVE_VERSION). */
  version: number;
  createdMs: number;
  byteLength: number;
  payload: ArrayBuffer;
}


export class IndexedDBProvider {
  private db: IDBDatabase | null = null;
  private opening: Promise<void> | null = null;


  constructor(
    private readonly dbName = 'solaris-engine',
    private readonly storeName = 'saves',
    private readonly dbVersion = 2,
  ) {}


  get isOpen(): boolean { return this.db !== null; }


  async open(): Promise<void> {
    if (this.db !== null) return;
    if (this.opening !== null) return this.opening;
    if (IDB_FACTORY === null) {
      throw new Error('[IndexedDBProvider] IndexedDB unavailable in this realm');
    }
    const opening = new Promise<void>((resolve, reject) => {
      const req = IDB_FACTORY.open(this.dbName, this.dbVersion);
      req.onupgradeneeded = () => {
        const db = req.result;
        // Schema migrations by DB version. Idempotent — fresh installs jump
        // straight to dbVersion and must still find their stores.
        //   v0 -> v1: create 'saves' (keyPath 'id').
        //   v1 -> v2: reserved (e.g. a 'settings' store or an index).
        if (!db.objectStoreNames.contains(this.storeName)) {
          db.createObjectStore(this.storeName, { keyPath: 'id' });
        }
      };
      req.onsuccess = () => {
        this.db = req.result;
        this.db.onversionchange = () => this.close();  // another tab upgrades
        resolve();
      };
      req.onerror = () => reject(req.error ?? new Error('open failed'));
      req.onblocked = () =>
        reject(new Error('[IndexedDBProvider] open blocked by another connection'));
    });
    this.opening = opening;
    try { await opening; } finally { this.opening = null; }
  }


  close(): void {
    if (this.db !== null) { this.db.close(); this.db = null; }
  }


  private _store(mode: IDBTransactionMode): IDBObjectStore {
    if (this.db === null) throw new Error('[IndexedDBProvider] not open');
    return this.db.transaction(this.storeName, mode).objectStore(this.storeName);
  }


  /** Write one record. Awaits TRANSACTION COMPLETION (durability), not just
   *  request success. The payload is structured-cloned at put() time. */
  async putRecord(record: SaveRecord): Promise<void> {
    await this.open();
    const store = this._store('readwrite');
    const tx = store.transaction;
    await new Promise<void>((resolve, reject) => {
      const req = store.put(record);
      req.onerror = () => reject(req.error ?? new Error('put failed'));
      tx.onabort = () => reject(tx.error ?? new Error('put aborted'));
      tx.oncomplete = () => resolve();
    });
  }


  async getRecord(id: string): Promise<SaveRecord | null> {
    await this.open();
    const store = this._store('readonly');
    return await new Promise<SaveRecord | null>((resolve, reject) => {
      const req = store.get(id);
      req.onsuccess = () =>
```

```typescript
 * ============================================================================
 *  SAVE MANAGER — SNAPSHOT / RESTORE ORCHESTRATOR (ABOVE THE CORE)
 *  Milestone 1G · Spec 01.6 (Pause-and-Prime hydration pipeline)
 * ============================================================================
 *  Sits ABOVE the locked SimulationCore / AstronautKCC: it consumes their
 *  existing public surfaces (plus the M1G additive persistence hooks) and
 *  never modifies their execution loops.

 *  synchronous act — committing the captured bytes into a second

  captureState(): boolean {
    const o = this._core.getOrigin();
    this._kcc.capturePersistentStateInto(this.player);
    const now = Date.now();
    this.serializer.capture(this._core.simTime, o.x, o.y, o.z, this.player, now);
    this._hasCapture = true;
    this.counters.captures++;
    this.counters.lastSaveBytes = SAVE_BUFFER_BYTES;
    this.counters.lastSavedAtMs = now;

  async asyncWrite(): Promise<SaveOpStatus> {
    if (!this._hasCapture) { this.counters.lastStatus = 'no-capture'; return 'no-capture'; }
    if (this._writeInFlight) { this.counters.lastStatus = 'busy'; return 'busy'; }
    this._writeInFlight = true;
    this._commitU8.set(this.serializer.u8);   // THE one synchronous act
    this._record.version = SAVE_VERSION;
    this._record.createdMs = this.counters.lastSavedAtMs;
    const t0 = performance.now();
    let status: SaveOpStatus = 'ok';
    try {
      await this._provider.putRecord(this._record);
      this.counters.writes++;
    } catch {
      status = 'io-error';
      this.counters.rejected++;
    }
    this.counters.lastWriteMicros = (performance.now() - t0) * 1000;
    this.counters.lastStatus = status;
    this._writeInFlight = false;
    return status;
  }


  /** I/O + verify + (migrate) into the snapshot. NEVER mutates game state. */
  async asyncLoad(id: string = this._saveId): Promise<SaveOpStatus> {
    this.counters.reads++;
    const t0 = performance.now();
    let status: SaveOpStatus;
    try {
      const rec = await this._provider.getRecord(id);
      if (rec === null) {
        status = 'not-found';
        this.counters.rejected++;
      } else {
        this.serializer.ingest(rec.payload, rec.byteLength);
        const v = this.serializer.verify();
        if (v === 'ok') {
          this.serializer.playerInto(this.player);
          this._snapshotSimTime = this.serializer.simTime;
          this._hasSnapshot = true;
          status = 'ok';
        } else if (v === 'ok-v1') {
          this.serializer.migrateV1Into(this._migTime, this.player);
          this._snapshotSimTime = this._migTime.v;
          this._hasSnapshot = true;
          this.counters.migrations++;
          status = 'migrated';
        } else {
          this.counters.rejected++;
          status = v;
        }
      }
    } catch {
      status = 'io-error';
      this.counters.rejected++;
    }
    this.counters.lastReadMicros = (performance.now() - t0) * 1000;
    this.counters.lastStatus = status;
    return status;
  }


  /** THE apply step — synchronous, at a frame boundary. Order (a)-(e) and
   *  proofs in the file header. */
  deterministicRestore(core: SimulationCore = this._core): SaveOpStatus {
    if (!this._hasSnapshot) {
      this.counters.lastStatus = 'no-capture';
      return 'no-capture';
    }
    // (a)+(b) exact macro restore + synchronous rail re-evaluation
    core.setSimTime(this._snapshotSimTime);
    // (c) full canonical player state (verbatim, incl. contact caches)
    this._kcc.restorePersistentState(this.player);
    if (this._entityPos !== null && this._entityVel !== null) {
      this._entityPos.x = this._kcc.absPos.x;
      this._entityPos.y = this._kcc.absPos.y;
      this._entityPos.z = this._kcc.absPos.z;
      this._entityVel.x = this._kcc.absVel.x;
      this._entityVel.y = this._kcc.absVel.y;
      this._entityVel.z = this._kcc.absVel.z;
    }
    // (d) natural-trigger validation (the rebase itself fires inside the
    // next core tick — before its render extract, per canonical order)
    const o = core.getOrigin();
    const p = this._kcc.absPos;
    const m = Math.max(
      Math.abs(p.x - o.x), Math.abs(p.y - o.y), Math.abs(p.z - o.z));
    this.restorePendingRebase = m > 1024;
    this.counters.applied++;
    this.counters.lastStatus = 'ok';
    return 'ok';
  }


  async deleteSave(id: string = this._saveId): Promise<'ok' | 'io-error'> {
    try {
      await this._provider.deleteRecord(id);
      return 'ok';
    } catch {
      return 'io-error';
    }
  }


  /** Direct record injection — integrity/versioning tests only (suite). */
  async putRecordDirect(record: SaveRecord): Promise<void> {
    await this._provider.putRecord(record);
  }
}
```

```tsx
    const h0 = terrainHeight(_scanT.x, _scanT.y, _scanT.z);
    let ok = true;
    for (let k = 0; k < 4; k++) {
      const a = k * 1.57 + 0.4;
      const ex = Math.cos(a) * 0.0005, ez = Math.sin(a) * 0.0005;
      const l = Math.hypot(_scanT.x + ex, _scanT.y, _scanT.z + ez);
      if (Math.abs(terrainHeight((_scanT.x + ex) / l, _scanT.y / l, (_scanT.z + ez) / l) - h0) > 0.15) {
        ok = false; break;
      }
    }
    if (ok) return { x: _scanT.x, y: _scanT.y, z: _scanT.z };
  }
  return { x: 1, y: 0, z: 0 };
})();

const MAX_LEVEL = 4;
const SPLIT_K = 2.0, MERGE_K = 1.45, GRACE_FRAMES = 45;
const ACTIVATIONS_PER_FRAME = 3, TOTAL_INFLIGHT_CAP = 24;
const HORIZON_MARGIN = 150;


interface QNode {
  face: number; level: number; ix: number; iy: number; key: number;
  ox: number; oy: number; oz: number; width: number; brad: number;
  parent: QNode | null; split: boolean; desired: boolean;
  activeRec: number; pendingRec: number;
}
const LEVEL_OFFSETS = [0, 1, 5, 21, 85];
const FACE_NODES: QNode[][] = [];
(function buildNodes(): void {
  const dir: Vec3Out = { x: 0, y: 0, z: 0 };
  for (let f = 0; f < 6; f++) {
    const arr: QNode[] = new Array(341);
    for (let L = 0; L <= MAX_LEVEL; L++) {
      const D = GRID_N << L, cnt = 1 << L;
      for (let ix = 0; ix < cnt; ix++) for (let iy = 0; iy < cnt; iy++) {
        const u = gridCoord(ix * GRID_N + (GRID_N >> 1), D);
        const v = gridCoord(iy * GRID_N + (GRID_N >> 1), D);
        faceCubePointInto(f, u, v, dir);
        spherifyInto(dir.x, dir.y, dir.z, dir);
        const rr = R + terrainHeight(dir.x, dir.y, dir.z);
        arr[LEVEL_OFFSETS[L] + ix * cnt + iy] = {
          face: f, level: L, ix, iy, key: chunkKey(f, L, ix, iy),
          ox: dir.x * rr, oy: dir.y * rr, oz: dir.z * rr,
          width: chunkArcWidth(L), brad: chunkArcWidth(L) * 0.75 + HEIGHT_SLACK,
          parent: null, split: false, desired: false, activeRec: -1, pendingRec: -1,
        };
      }
    }
    for (let L = 1; L <= MAX_LEVEL; L++) {
      const cnt = 1 << L, pc = 1 << (L - 1);
      for (let ix = 0; ix < cnt; ix++) for (let iy = 0; iy < cnt; iy++) {
        arr[LEVEL_OFFSETS[L] + ix * cnt + iy].parent =
          arr[LEVEL_OFFSETS[L - 1] + (ix >> 1) * pc + (iy >> 1)];
      }
    }
    FACE_NODES.push(arr);
  }
})();
function childOf(n: QNode, c: number): QNode {
  const L1 = n.level + 1, cnt = 1 << L1;
  return FACE_NODES[n.face][LEVEL_OFFSETS[L1] + (n.ix * 2 + (c >> 1)) * cnt + (n.iy * 2 + (c & 1))];
}
function nodeHasData(n: QNode): boolean {
  if (n.activeRec >= 0) return true;
  if (n.pendingRec >= 0 && pool.records[n.pendingRec].state === 2) return true;
  return false;
}
/** The level-4 leaf containing the player (hydration gate target). */
const _gateCC: CubeCoord = { face: 0, u: 0, v: 0 };
function gateNodeForPlayer(): QNode | null {
  const p = kcc.pLocal;
  const r = Math.hypot(p.x, p.y, p.z) || 1;
  sphereToCubeInto(p.x / r, p.y / r, p.z / r, _gateCC);
  const cnt = 1 << MAX_LEVEL;
  const ix = Math.max(0, Math.min(cnt - 1, Math.floor((_gateCC.u + 1) * 0.5 * cnt)));
  const iy = Math.max(0, Math.min(cnt - 1, Math.floor((_gateCC.v + 1) * 0.5 * cnt)));
  return FACE_NODES[_gateCC.face][LEVEL_OFFSETS[MAX_LEVEL] + ix * cnt + iy];
}


const camPlanet: Vec3 = { x: 0, y: 0, z: 0 };
let camUX = 0, camUY = 0, camUZ = 0, horizonDot = 0;
const candNodes: QNode[] = [];
const candDist = new Float64Array(64);
let candCount = 0;
function clearSubtree(n: QNode): void {
  n.desired = false;
  if (n.level < MAX_LEVEL) for (let c = 0; c < 4; c++) clearSubtree(childOf(n, c));
}
function visitNode(n: QNode): boolean {
  if (n.ox * camUX + n.oy * camUY + n.oz * camUZ + n.brad < horizonDot - HORIZON_MARGIN) {
    clearSubtree(n); return false;
  }
  const dx = camPlanet.x - n.ox, dy = camPlanet.y - n.oy, dz = camPlanet.z - n.oz;
  const d = Math.sqrt(dx * dx + dy * dy + dz * dz);
  const sd = SPLIT_K * n.width;
  if (n.split && d > MERGE_K * sd) n.split = false;
  if (!n.split && n.level < MAX_LEVEL && d < sd) n.split = true;
  if (n.split && n.level < MAX_LEVEL) {
    let any = false;
    for (let c = 0; c < 4; c++) if (visitNode(childOf(n, c))) any = true;
    n.desired = !any;
    return true;
  }
  n.desired = true;
  if (n.activeRec < 0 && n.pendingRec < 0 && candCount < 64) {
    candNodes[candCount] = n; candDist[candCount] = d; candCount++;
  }
  return true;
}
function updateController(): void {
  const recs = pool.records;
  for (let i = 0; i < recs.length; i++) {
    const rec = recs[i];
    if (rec.state === 2 && rec.owner !== null) {
      const n = rec.owner as QNode;
      if (n.pendingRec === i) { n.pendingRec = -1; n.activeRec = i; }
    }
  }
  const cr = Math.hypot(camPlanet.x, camPlanet.y, camPlanet.z) || 1;
  camUX = camPlanet.x / cr; camUY = camPlanet.y / cr; camUZ = camPlanet.z / cr;
  horizonDot = (R * R) / cr;
  candCount = 0;
  for (let f = 0; f < 6; f++) visitNode(FACE_NODES[f][0]);
  const pressure = pool.freeCount() < 6;
  for (let i = 0; i < recs.length; i++) {
    const rec = recs[i];
    const node = rec.owner as QNode | null;
    if (node === null) continue;
    if (rec.state === 2) {
      if (node.desired) { rec.unwanted = 0; continue; }
      if (node.split) {
        let cd = false;
        for (let c = 0; c < 4; c++) if (nodeHasData(childOf(node, c))) { cd = true; break; }
        if (cd) rec.mesh.visible = false;
      }
      let keep = false;
      if (node.split) {
        for (let c = 0; c < 4; c++) {
          const ch = childOf(node, c);
          if (ch.desired && !nodeHasData(ch)) { keep = true; break; }
        }
      } else {
        const p = node.parent;
        if (p !== null && p.desired && !nodeHasData(p)) keep = true;
      }
      if (keep && !pressure) { rec.unwanted = 0; continue; }
      rec.unwanted++;
      if (rec.unwanted >= GRACE_FRAMES || pressure) {
        pool.release(i);
        if (node.activeRec === i) node.activeRec = -1;
        rec.owner = null;
      }
    } else if (rec.state === 1) {
      if (!node.desired && !node.split) {
        rec.unwanted++;
        if (rec.unwanted >= GRACE_FRAMES) {
          pool.release(i);
          if (node.pendingRec === i) node.pendingRec = -1;
          rec.owner = null;
        }
      } else rec.unwanted = 0;
    }
  }
  for (let a = 1; a < candCount; a++) {
    const d = candDist[a], n = candNodes[a];
    let b = a - 1;
    while (b >= 0 && candDist[b] > d) { candDist[b + 1] = candDist[b]; candNodes[b + 1] = candNodes[b]; b--; }
    candDist[b + 1] = d; candNodes[b + 1] = n;
  }
  let act = 0;
  for (let a = 0; a < candCount && act < ACTIVATIONS_PER_FRAME; a++) {
    if (pool.inFlightTotal() >= TOTAL_INFLIGHT_CAP) break;
    if (pool.freeCount() <= 2) break;
    const n = candNodes[a];
    const idx = pool.acquire(n.face, n.level, n.ix, n.iy, n.ox, n.oy, n.oz);
    if (idx < 0) break;
    pool.records[idx].owner = n;
    n.pendingRec = idx;
    act++;
  }
}

function beginHydrationLoad(): void {
  if (hydr.phase !== 'IDLE') return;
  hydr.phase = 'FREEZING';
  hydr.loadStatus = '';
  hydr.gateNode = null;
  hydr.gatePassed = false; hydr.gateMs = 0; hydr.fadeMs = 0; hydr.tFade = 0;
  hydr.tStart = performance.now();
  hydr.minAGL = Number.POSITIVE_INFINITY;
  hydr.rebase0 = core.stats.rebaseCount;

function tickHydration(dt: number, nowMs: number): void {
  if (hydr.phase === 'IDLE') return;
  const agl = kcc.telemetry.altAGL;
  if (agl < hydr.minAGL) hydr.minAGL = agl;
  if (hydr.phase === 'FREEZING') {
    if (hydr.loadStatus === '') return;              // read still in flight
    if (hydr.loadStatus !== 'ok' && hydr.loadStatus !== 'migrated') {
      // Rejected (not-found / corrupt / future version): NO state was
      // touched — drop the overlay attempt and continue unharmed.
      setFadeOpacity(0);
      hydr.phase = 'IDLE';
      return;
    }
    // Frame-boundary apply: (a)-(d) of the deterministic restore sequence.
    saveManager.deterministicRestore(core);
    hydr.gateNode = gateNodeForPlayer();
    setFadeOpacity(1);                               // the pause is visible
    hydr.phase = 'HYDRATING';
    return;
  }
  if (hydr.phase === 'HYDRATING') {
    // Spec 01.6 gate — the chunk under the player is active. (Analytic-era
    // stand-in: M1D/M1E analytic collision guarantees no fall-through even
    // at zero chunks; the Rapier intersectionsWithShape == EMPTY gate is the
    // production hook point.)
    const ok = hydr.gateNode !== null && nodeHasData(hydr.gateNode);
    hydr.gateMs = nowMs - hydr.tStart;
    if (ok || hydr.gateMs > 3000) {
      hydr.gatePassed = ok;
      hydr.phase = 'FADE';                           // 300 ms cosmetic fade
      hydr.tFade = 0;
    }
    return;
  }
  if (hydr.phase === 'FADE') {
    hydr.tFade += dt;
    const t = Math.min(1, hydr.tFade / 0.3);
    setFadeOpacity(1 - t);
    if (t >= 1) {
      setFadeOpacity(0);
      hydr.fadeMs = nowMs - hydr.tStart;
      hydr.phase = 'IDLE';
    }
  }
}

function fpMismatch(au: Uint32Array, bu: Uint32Array): number {
  let n = 0;
  for (let i = 0; i < fpWords; i++) if (au[i] !== bu[i]) n++;
  return n;
}


/** Deterministic tick driver: same (state, input(i)) -> same bits, forever. */
function scriptedTick(i: number): void {
  const inp = kcc.input;
  inp.moveF = 0.55 + 0.45 * Math.sin(0.0013 * i);
  inp.moveR = 0.5 * Math.sin(0.0007 * i + 1.2);
  inp.sprint = i % 400 < 240;
  inp.crouch = false;
  inp.jump = i % 300 === 150;
  inp.turnRate = 0.3 * Math.sin(0.0009 * i);
  kcc.integrateTick(1 / 60);
  entityPos.x = kcc.absPos.x; entityPos.y = kcc.absPos.y; entityPos.z = kcc.absPos.z;
  entityVel.x = kcc.absVel.x; entityVel.y = kcc.absVel.y; entityVel.z = kcc.absVel.z;
  core.tick();
}

const fmtClock = (t: number): string => {
  const sign = t < 0 ? '−' : '';
  const at = Math.abs(t);
  const d = Math.floor(at / 86400);
  let rem = at - d * 86400;
  const h = Math.floor(rem / 3600); rem -= h * 3600;
  const m = Math.floor(rem / 60);
  const p2 = (v: number) => (v < 10 ? `0{v}`);
  return `{d}d {p2(m)}:${p2(Math.floor(rem - m * 60))}`;
};


function Scene() {
  const { scene } = useThree();
  const primed = useRef(2);
  useEffect(() => {
    pool.attach(spinGroup as unknown as THREE.Scene);
    adapter.bind(ASTRO_ID, astroMesh);
    pool.primeAll();
    primed.current = 2;
    return () => { adapter.unbind(ASTRO_ID); };
  }, [scene]);


  useFrame((state, delta) => {
    if (primed.current > 0) {
      primed.current--;
      if (primed.current === 0) pool.unprimeAll();
    }
    const dt = delta > 0.1 ? 0.1 : delta;
    const nowMs = performance.now();


    /* -- pending frame-waits (suite orchestration) -------------------------- */
    for (let i = waits.length - 1; i >= 0; i--) {
      if (--waits[i].remaining <= 0) waits.splice(i, 1)[0].resolve();
    }


    /* -- inputs -------------------------------------------------------------- */
    if (!suite.active && suite.done) {
      cam.yaw = ((cam.yaw - mouseDX * SENS + Math.PI) % (Math.PI * 2) + Math.PI * 2)
        % (Math.PI * 2) - Math.PI;
      cam.pitch = Math.max(-1.2, Math.min(1.2, cam.pitch - mouseDY * SENS));
      mouseDX = 0; mouseDY = 0;
      readUserInput();
    } else {
      mouseDX = 0; mouseDY = 0;
      const f = kcc.input;                       // autopilot (warmup / suite live)
      f.moveF = 0.85; f.moveR = 0; f.sprint = true; f.crouch = false;
      f.jump = false; f.turnRate = 0; f.rcsF = 0; f.rcsU = 0; f.rcsR = 0;
    }


    /* -- hydration machine (drives freeze / gate / fade) --------------------- */
    tickHydration(dt, nowMs);


    /* -- simulation (frozen during FREEZING/HYDRATING per Spec 01.6) --------- */
    const simEnabled = !userPaused &&
      (hydr.phase === 'IDLE' || hydr.phase === 'FADE') &&
      (!suite.active || suite.simLive);
    if (simEnabled) {
      kcc.update(dt, 5);
      core.advance(dt);
    }


    /* -- world transforms (reads; always) ------------------------------------- */
    const o = core.getOrigin();
    spinGroup.position.set(-o.x, -o.y, -o.z);
    spinQuatInto(kcc.spinPhase, _qS);
    spinGroup.quaternion.set(_qS.x, _qS.y, _qS.z, _qS.w);
    adapter.update();
    const lp = astroState.localPosF32;
    astroMesh.position.set(lp[0], lp[1], lp[2]);
    kcc.frameQuatInto(_f64q);
    _qSpinT.set(_qS.x, _qS.y, _qS.z, _qS.w);
    _qFrameT.set(_f64q.x, _f64q.y, _f64q.z, _f64q.w);
    astroMesh.quaternion.copy(_qSpinT).multiply(_qFrameT);


    /* -- sky: the Moon at the live Earth-relative rail offset (f64 → f32) ---- */
    const mo = moonState.absPos, eo = earthState.absPos;
    moonMesh.position.set(mo.x - eo.x - o.x, mo.y - eo.y - o.y, mo.z - eo.z - o.z);
    sunGlow.position.set(
      sunDir.x * 30000 - o.x, sunDir.y * 30000 - o.y, sunDir.z * 30000 - o.z);


    /* -- camera (after world; glow faces it next line) ------------------------ */
    updateCamera(state.camera);
    sunGlow.quaternion.copy(state.camera.quaternion);


    /* -- M1C streaming (always — camera planet-frame; also serves the gate) -- */
    rotateByQuatConjInto(_qS, kcc.absPos.x, kcc.absPos.y, kcc.absPos.z, camPlanet);
    updateController();
    pool.pump();


    /* -- storm frame measurement ---------------------------------------------- */
    if (suite.storm.on) {
      const fms = delta * 1000;
      if (fms > suite.storm.maxFrameMs) suite.storm.maxFrameMs = fms;
      if (fms > 25) suite.storm.framesOver25++;
      suite.storm.frames++;
    }


    /* -- warmup → suite start -------------------------------------------------- */
    if (!suite.started) {
      suite.warm += dt;
      if ((pool.activeCount() >= 40 && suite.warm > 3.5) || suite.warm > 8) {
        suite.started = true;
        void runSuite();
      }
    }


    /* -- throttled telemetry (10 Hz) ------------------------------------------- */
    const fms = delta * 1000;
    frameStats.frames++; frameStats.ms += fms;
    if (frameStats.frames >= 30) {
      tele.fps = (frameStats.frames * 1000) / Math.max(frameStats.ms, 1e-6);
      tele.frameMs = frameStats.ms / frameStats.frames;
      frameStats.frames = 0; frameStats.ms = 0;
    }
    if (nowMs - lastTeleMs >= 100) {
      lastTeleMs = nowMs;
      const c = saveManager.counters;
      tele.simTime = core.simTime;
      tele.thetaDeg = (kcc.spinPhase * 180) / Math.PI;
      tele.moonAngle = (Math.atan2(mo.x - eo.x, mo.z - eo.z) * 180) / Math.PI;
      const t = kcc.telemetry;
      tele.mode = t.mode; tele.grounded = t.grounded;
      tele.speed = t.relSpeed; tele.altAGL = t.altAGL;
      tele.originX = o.x; tele.originY = o.y; tele.originZ = o.z;
      tele.rebases = core.stats.rebaseCount;
      tele.localMax = core.stats.focusMaxLocalPostTick;
      tele.active = pool.activeCount(); tele.pending = pool.pendingCount();
      tele.geometries = state.gl.info.memory.geometries;
      tele.heapMB = heapApi !== null ? heapApi.usedJSHeapSize / 1048576 : 0;
      tele.disposes = disposeCalls + sceneRemoveCalls;
      tele.saveBytes = c.lastSaveBytes;
      tele.lastSavedAt = c.lastSavedAtMs > 0
        ? new Date(c.lastSavedAtMs).toLocaleTimeString() : '—';
      tele.writeUs = c.lastWriteMicros; tele.readUs = c.lastReadMicros;
      tele.captures = c.captures; tele.writes = c.writes; tele.reads = c.reads;
      tele.rejected = c.rejected; tele.migrations = c.migrations;
      tele.applied = c.applied;
      tele.phase = suite.done ? 'DONE' : suite.active
        ? (suite.simLive ? 'SUITE·LIVE' : 'SUITE') : 'WARMUP';
      tele.hydrPhase = hydr.phase;
      tele.gateMs = hydr.gateMs; tele.fadeMs = hydr.fadeMs;
      if (c.lastStatus !== '—') tele.status = c.lastStatus.toUpperCase();
      tele.version++;
      teleListeners.forEach((l) => l());
    }
  });


  return <primitive object={sceneRoot} />;
}
```
