## PHASE 1 — REASONING & EDGE-CASE ANALYSIS


### 1.1 Parallel Transport Orientation on Spheres


The character frame is the pair **(up, fwd)** — tangent-bundle state, never a yaw/pitch accumulator (Spec 01.4: Euler prohibited). Each tick: `up ← blend(n(d̂), r̂)` (n = the analytic terrain normal, w = 0.65), then **Gram–Schmidt reprojection** `fwd ← normalize(fwd − (fwd·up)up)`, then quaternion via basis (X=fwd, Y=up, Z=fwd×up).


**Why there are no singularities — three separate arguments:**


1. **Degeneracy is unreachable in continuous motion.** Gram–Schmidt fails only if `fwd ∥ up_new`. Per tick, walking at 8 m/s rotates up by ≤ ~5×10⁻³ rad (curvature 1.33×10⁻⁴ rad + terrain-normal change over 0.13 m), so `|fwd·up|` stays ~10⁻³ — the projection is magnitudes from degenerate. Teleports/first-spawn get a **canonical-tangent fallback** (least-aligned-axis frame; provably never degenerate since the least-aligned axis satisfies |u·ref| ≤ 1/√3 ⇒ |u×ref| ≥ 0.816).
2. **Poles and face boundaries are not coordinates.** There is no global yaw anywhere in the state — yaw exists only as *differential* input (a finite rotation about the current up applied per tick). At a pole, "north" is undefined but the transported `fwd` is a perfectly well-defined vector; crossing a cube face boundary changes nothing because `up` derives from the analytic normal field `n(d̂)`, which M1C proved is C¹ across face seams (the same zero-communication bitwise argument) — the frame never sees the cube parameterization at all.
3. **Holonomy is physical and smooth.** Transporting around a closed loop rotates `fwd` by the enclosed solid angle. The T1 walk follows a great circle (bounds a hemisphere, solid angle 2π) → holonomy 2π ≡ identity — a verifiable endpoint property.


Camera pitch is a scalar clamped to ±1.48 rad applied as a local rotation about the body-right axis when composing the camera quaternion — a one-axis offset inside a transported frame, not world Euler state.


### 1.2 Spherical KCC Ground Snapping, Steps, and Slopes


Ground probing is **analytic and worker-independent**: height `h(d̂)` at the move target (f64, the same field the workers mesh). The move Δ = (vCtl + vSlide)·dt is a tangent-plane step from the current feet position; the target direction `d̂_try = normalize(pLocal + Δ)` probes `surf_try = R + h(d̂_try)`; `Δh = surf_try − surf_cur`.


**The step rule (derived — flagged for Lead review).** A move is *climbable* iff **both** `Δh ≤ stepHeight (0.55 m)` **and** `Δh/arc ≤ tan(50°)`. The first clause is the classic KCC step; the second is what makes steep terrain *predictable*: without it, a uniform 60° slope passes the per-move step check at walking speed (Δh = 0.13·tan60° = 0.23 ≤ 0.55) and the character would scramble up cliffs at full sprint, with behavior varying by speed (0.067 m/tick walk vs 0.133 sprint changes the effective climb threshold from 83° to 76° — speed-dependent rules are the definition of unpredictable). The ratio clause makes "walkable" a property of the *terrain* (≤ 50°), invariant to speed.


- **Blocked (wall):** project Δ against the wall direction — the tangential component of the *target* normal (a steep uphill face's normal leans back downhill, so its tangential part points away from the wall) — one retry, then full stop.
- **Snap-down:** drops ≤ 0.45 m follow the surface (grounded maintained on downhills to ~81°); larger drops → cliff → airborne.
- **Slope physics:** gravity decomposed against n: load `g_N`, downhill `g_T = g − (g·n)n`. Static grip holds while slope ≤ 45° (μ_s = tan 45° implicit); above, `v̇_slide = g_T − μ_k·g_N·v̂` (μ_k = 0.6), grip decays below threshold with τ = 60 ms. On a 60° slope: slide accel = 9.81·(sin60 − 0.6·cos60) ≈ 5.5 m/s² — uphill sprint (8 m/s) is overwhelmed in ~1.5 s and the blocked rule prevents any scrambling shortcut.
- **Structural AGL bound:** every grounded tick *ends* anchored to a probed surface point (+0.02 m clearance), so post-tick AGL ≥ 0 by construction — the same "post-tick invariant" style as M1A's 1,024 m local bound.


### 1.3 Gravity & Reference Frame State Machine


Three modes with hysteresis on the **spec-02.3 range-faded gravity** (full inverse-square to 75% of range, C¹ smoothstep to zero at 100% — the fade is what makes zero-G *reachable* and the transition smooth): `SURFACE ⇄ ZERO-G` on g < 0.05 / > 0.15 m/s² (≈ 28 km on the test planet), `VEHICLE` by explicit attach/detach with velocity inheritance.


**The Coriolis handoff (Spec 01.4, verbatim implementation).** Grounded: the KCC's canonical state is planet-frame `pLocal` + tangential `v_walk`; absolute is *composed*: `P = R(θ)·pLocal`, `V = Ω×P + R(θ)·v_walk` — the rotation is the **analytic transport velocity, never integrated and never fed to any physics engine as speed**. Airborne: pure inertial integration of absolute (P, V) under central gravity — no fictitious forces exist because we never leave the inertial frame. On landing: `v_rel = R(θ)⁻¹(V − Ω×P)`, normal component killed, tangential **planted** (vWalk = input target, zero if no input) — "immediately settle into a 0 m/s relative walk state, never skate."


**The drift is a theorem, and the suite measures it.** Jump speed u along the vertical at the equator (transport speed ΩR = 52 m/s, Spec's exact numbers). Rotating frame: a_west = −2Ω×v_rel integrates to **drift = (4/3)·Ω·u³/g²**. Inertial frame: angular momentum conservation gives relative westward rate ω_ast − Ω ≈ 2ΩΔh/r (the factor 2 from 1 − (R/r)² ≈ 2Δh/R), and ∫Δh dt over the ballistic arc = (2/3)u³/g² — the same (4/3)Ωu³/g². With Ω = 0.0104, u = 5, g = 9.81: **1.8 cm westward, flight time 2u/g ≈ 1.03 s, residual tangential speed at touchdown 2Ωu ≈ 0.10 m/s** (which the plant kills in one tick). The test also validates the compose/decompose round-trip implicitly: launch and landing positions are compared in the planet frame across a 53 m transport displacement.


### 1.4 Collision Sweeps & Terrain Snapping (worker-independent)


Airborne motion sweeps the tick's inertial segment against the f64 noise field: gap-limited sampling (≤ 0.25 m — at ≤ 10 m/s jumps that is 1 sample; the 500 m/s orbital fall uses ~35), Lipschitz-bounded transient penetration (≤ gap·L, always detected at the next sample; every tick *starts* with an embed check and *ends* at or above the surface), then **spin-interpolated bisection** to sub-tick contact. The spin interpolation is the edge case that matters: without it, evaluating terrain at tick-start θ misplaces the rotating ground by up to `r·Ω·dt = 0.87 m` per tick at the equator — with `θ(s) = θ₀ + Ω·dt·s` per sample the sweep is exact for the uniformly rotating rigid terrain. No Rapier object exists in this path (Spec 01.5's Active-state heightfield colliders are the production attach point; the M1E analytic KCC is exactly the spec's "relative walking displacement" domain, and the entity write-through is the seam — a hook, not a regression).


**Zero-G:** RCS pack (Spec 00.4: limited, for recovery) — 1.2 m/s² along the character frame, 25 m/s Δv budget, regenerating 0.5 m/s when grounded; attitude via finite frame rotations (yaw/pitch/roll about transported axes). Hard landings plant without damage (damage/health explicitly out of scope, Spec 00.4).

### 1. `src/core/physics/sphericalFrame.ts`


```typescript
/**
 * ============================================================================
 *  SPHERICAL FRAME — PARALLEL TRANSPORT & SURFACE FRAME MATH (PURE FLOAT64)
 *  Milestone 1E · Spec 01.4 (quaternion parallel transport, no Euler angles)
 * ============================================================================
 *  Pure core: no renderer/physics imports. All functions zero-allocation
 *  (out-param style); all arithmetic in 64-bit doubles.
 *
 *  THE FRAME: a character orientation is the pair (up, fwd) — tangent-bundle
 *  state, NEVER a yaw/pitch accumulator (Spec 01.4: Euler prohibited to
 *  prevent gimbal lock and pole snapping). Transport is Gram-Schmidt
 *  reprojection of fwd against the new up; the render quaternion is built
 *  directly from the transported basis (X=fwd, Y=up, Z=fwd×up).
 *
 *  NO SINGULARITIES (see M1E analysis §1.1):
 *   - Degeneracy (fwd ∥ newUp) is unreachable under continuous motion;
 *     teleports fall back to the canonical least-aligned-axis tangent,
 *     which is provably never degenerate (|u×ref| >= 0.816).
 *   - Poles/cube-face boundaries are invisible: up derives from the C1
 *     analytic normal field n(d) (M1C seam proof); no global yaw exists.
 *
 *  SPIN CONVENTION: planet spin is +Y, phase theta (radians, wrapped mod
 *  2pi; quaternion consumers are sign-invariant under the wrap because
 *  rotation-by-quaternion is quadratic in q). Planet frame <-> world frame:
 *      world = R(theta) . planet,   R = rotation about +Y by theta.
 *  The planet is origin-centered in M1E, and spin-about-Y leaves radial
 *  directions eigenvectors — gravity is IDENTICAL in both frames.
 */


export interface Vec3 { x: number; y: number; z: number; }
export interface Quat { x: number; y: number; z: number; w: number; }


export const TWO_PI = Math.PI * 2;


export function clamp(v: number, lo: number, hi: number): number {
  return v < lo ? lo : v > hi ? hi : v;
}


/** Spec 02.3 gravity-range fade: 1 to 75% of range, C1 smoothstep to 0. */
export function rangeFade(rOverRange: number): number {
  if (rOverRange <= 0.75) return 1;
  if (rOverRange >= 1) return 0;
  const t = (rOverRange - 0.75) / 0.25;
  return 1 - t * t * (3 - 2 * t);
}


/**
 * Canonical tangent at up (least-aligned world axis, fixed tie order
 * x -> y -> z). |up . ref| <= 1/sqrt(3) => |up x ref| >= 0.816: NEVER
 * degenerate. Used as the transport fallback and for deterministic spawns.
 */
export function canonicalTangentInto(ux: number, uy: number, uz: number, out: Vec3): Vec3 {
  let rx = 1, ry = 0, rz = 0;
  let m = Math.abs(ux);
  if (Math.abs(uy) < m) { m = Math.abs(uy); rx = 0; ry = 1; rz = 0; }
  if (Math.abs(uz) < m) { rx = 0; ry = 0; rz = 1; }
  let tx = uy * rz - uz * ry;
  let ty = uz * rx - ux * rz;
  let tz = ux * ry - uy * rx;
  const inv = 1 / Math.sqrt(tx * tx + ty * ty + tz * tz);
  out.x = tx * inv; out.y = ty * inv; out.z = tz * inv;
  return out;
}


/**
 * PARALLEL TRANSPORT (Spec 01.4): Gram-Schmidt reprojection of fwd onto the
 * tangent plane of the new up. Degenerate input (fwd nearly parallel to the
 * new up — teleports only) falls back to the canonical tangent.
 */
export function transportFrameInto(
  fx: number, fy: number, fz: number,
  ux: number, uy: number, uz: number,
  out: Vec3,
): Vec3 {
  const d = fx * ux + fy * uy + fz * uz;
  let tx = fx - d * ux, ty = fy - d * uy, tz = fz - d * uz;
  const m = Math.sqrt(tx * tx + ty * ty + tz * tz);
  if (m < 0.02) {
    return canonicalTangentInto(ux, uy, uz, out);
  }
  const inv = 1 / m;
  out.x = tx * inv; out.y = ty * inv; out.z = tz * inv;
  return out;
}


/** Rodrigues rotation of v about unit axis k by angle a. */
export function rotateAboutAxisInto(
  vx: number, vy: number, vz: number,
  kx: number, ky: number, kz: number,
  a: number,
  out: Vec3,
): Vec3 {
  const c = Math.cos(a), s = Math.sin(a), t = 1 - c;
  const dot = vx * kx + vy * ky + vz * kz;
  const cx = ky * vz - kz * vy;
  const cy = kz * vx - kx * vz;
  const cz = kx * vy - ky * vx;
  out.x = vx * c + cx * s + kx * dot * t;
  out.y = vy * c + cy * s + ky * dot * t;
  out.z = vz * c + cz * s + kz * dot * t;
  return out;
}


/** Quaternion from an orthonormal character basis: X=fwd, Y=up, Z=fwd×up. */
export function quatFromFrameInto(
  fx: number, fy: number, fz: number,
  ux: number, uy: number, uz: number,
  out: Quat,
): Quat {
  const zx = fy * uz - fz * uy;
  const zy = fz * ux - fx * uz;
  const zz = fx * uy - fy * ux;
  const m00 = fx, m10 = fy, m20 = fz;
  const m01 = ux, m11 = uy, m21 = uz;
  const m02 = zx, m12 = zy, m22 = zz;
  const tr = m00 + m11 + m22;
  if (tr > 0) {
    const s = Math.sqrt(tr + 1) * 2;
    out.w = 0.25 * s;
    out.x = (m21 - m12) / s;
    out.y = (m02 - m20) / s;
    out.z = (m10 - m01) / s;
  } else if (m00 > m11 && m00 > m22) {
    const s = Math.sqrt(1 + m00 - m11 - m22) * 2;
    out.w = (m21 - m12) / s;
    out.x = 0.25 * s;
    out.y = (m01 + m10) / s;
    out.z = (m02 + m20) / s;
  } else if (m11 > m22) {
    const s = Math.sqrt(1 + m11 - m00 - m22) * 2;
    out.w = (m02 - m20) / s;
    out.x = (m01 + m10) / s;
    out.y = 0.25 * s;
    out.z = (m12 + m21) / s;
  } else {
    const s = Math.sqrt(1 + m22 - m00 - m11) * 2;
    out.w = (m10 - m01) / s;
    out.x = (m02 + m20) / s;
    out.y = (m12 + m21) / s;
    out.z = 0.25 * s;
  }
  return out;
}


/** Planet spin quaternion: rotation about +Y by theta. */
export function spinQuatInto(theta: number, out: Quat): Quat {
  out.x = 0;
  out.y = Math.sin(theta * 0.5);
  out.z = 0;
  out.w = Math.cos(theta * 0.5);
  return out;
}


/** Rotate v by q. */
export function rotateByQuatInto(
  q: Quat, vx: number, vy: number, vz: number, out: Vec3,
): Vec3 {
  const tx = 2 * (q.y * vz - q.z * vy);
  const ty = 2 * (q.z * vx - q.x * vz);
  const tz = 2 * (q.x * vy - q.y * vx);
  out.x = vx + q.w * tx + (q.y * tz - q.z * ty);
  out.y = vy + q.w * ty + (q.z * tx - q.x * tz);
  out.z = vz + q.w * tz + (q.x * ty - q.y * tx);
  return out;
}


/** Rotate v by the conjugate of q (world -> planet under the spin). */
export function rotateByQuatConjInto(
  q: Quat, vx: number, vy: number, vz: number, out: Vec3,
): Vec3 {
  const qx = -q.x, qy = -q.y, qz = -q.z, qw = q.w;
  const tx = 2 * (qy * vz - qz * vy);
  const ty = 2 * (qz * vx - qx * vz);
  const tz = 2 * (qx * vy - qy * vx);
  out.x = vx + qw * tx + (qy * tz - qz * ty);
  out.y = vy + qw * ty + (qz * tx - qx * tz);
  out.z = vz + qw * tz + (qx * ty - qy * tx);
  return out;
}


/** Hamilton product a ⊗ b (used for world-frame orientation compose). */
export function quatMulInto(a: Quat, b: Quat, out: Quat): Quat {
  const ax = a.x, ay = a.y, az = a.z, aw = a.w;
  const bx = b.x, by = b.y, bz = b.z, bw = b.w;
  out.x = aw * bx + ax * bw + ay * bz - az * by;
  out.y = aw * by - ax * bz + ay * bw + az * bx;
  out.z = aw * bz + ax * by - ay * bx + az * bw;
  out.w = aw * bw - ax * bx - ay * by - az * bz;
  return out;
}


/**
 * ANALYTIC TRANSPORT VELOCITY (Spec 01.4): v = Ω × p with Ω = (0, ω, 0).
 * Equator check: ω = 0.0104, p = (5000,0,0) -> |v| = 52 m/s exactly.
 * NEVER integrated, NEVER injected as physics-engine speed.
 */
export function transportVelocityInto(
  omega: number, px: number, py: number, pz: number, out: Vec3,
): Vec3 {
  out.x = omega * pz;
  out.y = 0;
  out.z = -omega * px;
  return out;
}


/**
 * Spec 02.3 gravity: inverse-square toward the (origin-centered) body with
 * the C1 range fade. Identical in planet and world frames (spin-about-Y
 * preserves radial directions).
 */
export function gravityInto(
  mu: number, range: number, px: number, py: number, pz: number, out: Vec3,
): Vec3 {
  const r2 = px * px + py * py + pz * pz;
  const r = Math.sqrt(r2);
  const g = -(mu / r2) * rangeFade(range > 0 ? r / range : 0);
  const inv = g / r;
  out.x = px * inv;
  out.y = py * inv;
  out.z = pz * inv;
  return out;
}


/** Signed angle from f to t about unit axis u (atan2 — safe near ±pi). */
export function signedAngleAbout(
  fx: number, fy: number, fz: number,
  tx: number, ty: number, tz: number,
  ux: number, uy: number, uz: number,
): number {
  const cx = fy * tz - fz * ty;
  const cy = fz * tx - fx * tz;
  const cz = fx * ty - fy * tx;
  return Math.atan2(cx * ux + cy * uy + cz * uz, fx * tx + fy * ty + fz * tz);
}
```

  /* ---- setup-path API ----------------------------------------------------- */


  attachWriteThrough(absPos: Vec3, velocity: Vec3): void {

  }


  get mode(): AstronautMode { return this._mode; }
  get grounded(): boolean { return this._grounded; }

  attachVehicle(provider: VehicleProvider): void {
    // Offset & frame captured in the PARENT frame at attach time.
    const p = provider.pos;
    rotateByQuatConjInto(provider.quat,
      this.absPos.x - p.x, this.absPos.y - p.y, this.absPos.z - p.z, _vehScratch);
    this._vehOffset.x = _vehScratch.x;
    this._vehOffset.y = _vehScratch.y;
    this._vehOffset.z = _vehScratch.z;
    rotateByQuatConjInto(provider.quat, this.up.x, this.up.y, this.up.z, _vehScratch);
    this._vehUp.x = _vehScratch.x; this._vehUp.y = _vehScratch.y; this._vehUp.z = _vehScratch.z;
    rotateByQuatConjInto(provider.quat, this.fwd.x, this.fwd.y, this.fwd.z, _vehScratch);
    this._vehFwd.x = _vehScratch.x; this._vehFwd.y = _vehScratch.y; this._vehFwd.z = _vehScratch.z;
    this._vehicle = provider;
    this._mode = 'VEHICLE';
    this._grounded = false;
  }


  detachVehicle(): void {
    if (this._vehicle === null) return;
    this._vehicle = null;
    gravityInto(this.cfg.planetMu, this.cfg.gravityRange,
      this.absPos.x, this.absPos.y, this.absPos.z, _g);
    const gm = Math.sqrt(_g.x * _g.x + _g.y * _g.y + _g.z * _g.z);
    this._mode = gm < 0.05 ? 'ZERO-G' : 'SURFACE';
    this._grounded = false;
  }


  /** Teleport to an absolute state (inertial). Setup path. */
  teleportAbs(px: number, py: number, pz: number, vx: number, vy: number, vz: number): void {
    this.absPos.x = px; this.absPos.y = py; this.absPos.z = pz;
    this.absVel.x = vx; this.absVel.y = vy; this.absVel.z = vz;
    this._grounded = false;
    this._vCtl.x = 0; this._vCtl.y = 0; this._vCtl.z = 0;
    this._vSlide.x = 0; this._vSlide.y = 0; this._vSlide.z = 0;
    // Planet-frame mirror + radial-aligned frame (continuous, deterministic).
    spinQuatInto(this._theta, _qSpin);
    const r = Math.sqrt(px * px + py * py + pz * pz) || 1;
    rotateByQuatConjInto(_qSpin, px / r, py / r, pz / r, _dS);
    this.pLocal.x = _dS.x * r; this.pLocal.y = _dS.y * r; this.pLocal.z = _dS.z * r;
    this.up.x = _dS.x; this.up.y = _dS.y; this.up.z = _dS.z;
    transportFrameInto(this.fwd.x, this.fwd.y, this.fwd.z, _dS.x, _dS.y, _dS.z, _fwdT);
    this.fwd.x = _fwdT.x; this.fwd.y = _fwdT.y; this.fwd.z = _fwdT.z;
    gravityInto(this.cfg.planetMu, this.cfg.gravityRange, px, py, pz, _g);
    const gm = Math.sqrt(_g.x * _g.x + _g.y * _g.y + _g.z * _g.z);
    this._mode = this._vehicle !== null ? 'VEHICLE' : gm < 0.05 ? 'ZERO-G' : 'SURFACE';
  }


  /** Teleport onto the surface at planet-frame direction d (unit-ish). */
  teleportSurface(dx: number, dy: number, dz: number): void {
    const cfg = this.cfg;
    const l = Math.sqrt(dx * dx + dy * dy + dz * dz) || 1;
    dx /= l; dy /= l; dz /= l;
    const h = terrainHeight(dx, dy, dz);
    this._hCur = h;
    const rr = cfg.planetRadius + h + cfg.groundClearance;
    this.pLocal.x = dx * rr; this.pLocal.y = dy * rr; this.pLocal.z = dz * rr;
    terrainNormalInto(dx, dy, dz, this._nCur);
    this._refreshUpFwd(dx, dy, dz);
    this._vCtl.x = 0; this._vCtl.y = 0; this._vCtl.z = 0;
    this._vSlide.x = 0; this._vSlide.y = 0; this._vSlide.z = 0;
    this._grounded = true;
    this._mode = 'SURFACE';
    this._vehicle = null;
    this._composeGrounded(0, 0, 0);
  }


  /** Render/planet-frame quaternion of the transported character frame. */
  frameQuatInto(out: Quat): Quat {
    return quatFromFrameInto(this.fwd.x, this.fwd.y, this.fwd.z,
      this.up.x, this.up.y, this.up.z, out);
  }


  resetIntegrityStats(): void {
    const i = this.integrity;
    i.ticks = 0; i.ticksGrounded = 0; i.ticksAirborne = 0;
    i.ticksZeroG = 0; i.ticksVehicle = 0;
    i.landings = 0; i.lastLandingRelSpeed = 0;
    i.minAGL = Number.POSITIVE_INFINITY; i.maxSlideSpeed = 0;
    i.faceChanges = 0; i.nanEvents = 0;
  }


  /* ---- fixed-step governor (Spec 02.6: <=5 substeps, shed don't dilute) -- */


  update(dtRealSeconds: number, maxSubsteps = 5): number {
    if (!Number.isFinite(dtRealSeconds) || dtRealSeconds <= 0) return 0;
    const dt = dtRealSeconds > 0.25 ? 0.25 : dtRealSeconds;
    // Exact once-per-frame look deltas (finite frame rotations — no Euler).
    if (this.lookYawDelta !== 0) {
      rotateAboutAxisInto(this.fwd.x, this.fwd.y, this.fwd.z,
        this.up.x, this.up.y, this.up.z, this.lookYawDelta, _fwdT);
      this.fwd.x = _fwdT.x; this.fwd.y = _fwdT.y; this.fwd.z = _fwdT.z;
      this.lookYawDelta = 0;
    }
    if (this._mode === 'ZERO-G') {
      if (this.lookPitchDelta !== 0 || this.lookRollDelta !== 0) {
        _right.x = this.fwd.y * this.up.z - this.fwd.z * this.up.y;
        _right.y = this.fwd.z * this.up.x - this.fwd.x * this.up.z;
        _right.z = this.fwd.x * this.up.y - this.fwd.y * this.up.x;
        if (this.lookPitchDelta !== 0) {
          rotateAboutAxisInto(this.up.x, this.up.y, this.up.z,
            _right.x, _right.y, _right.z, this.lookPitchDelta, _upT);
          this.up.x = _upT.x; this.up.y = _upT.y; this.up.z = _upT.z;
          rotateAboutAxisInto(this.fwd.x, this.fwd.y, this.fwd.z,
            _right.x, _right.y, _right.z, this.lookPitchDelta, _fwdT);
          this.fwd.x = _fwdT.x; this.fwd.y = _fwdT.y; this.fwd.z = _fwdT.z;
        }
        if (this.lookRollDelta !== 0) {
          rotateAboutAxisInto(this.up.x, this.up.y, this.up.z,
            this.fwd.x, this.fwd.y, this.fwd.z, this.lookRollDelta, _upT);
          this.up.x = _upT.x; this.up.y = _upT.y; this.up.z = _upT.z;
        }
        // Re-orthogonalize (shared rotations preserve ⊥; clean rounding).
        transportFrameInto(this.fwd.x, this.fwd.y, this.fwd.z,
          this.up.x, this.up.y, this.up.z, _fwdT);
        this.fwd.x = _fwdT.x; this.fwd.y = _fwdT.y; this.fwd.z = _fwdT.z;
      }
    }
    this.lookPitchDelta = 0;
    this.lookRollDelta = 0;
    this._accumulator += dt;
    let n = 0;
    while (this._accumulator >= 1 / 60 && n < maxSubsteps) {
      this.integrateTick(1 / 60);
      this._accumulator -= 1 / 60;
      n++;
    }
    if (this._accumulator >= 1 / 60) this._accumulator = 0; // shed
    if (this._wtPos !== null) {
      this._wtPos.x = this.absPos.x; this._wtPos.y = this.absPos.y; this._wtPos.z = this.absPos.z;
      this._wtVel.x = this.absVel.x; this._wtVel.y = this.absVel.y; this._wtVel.z = this.absVel.z;
    }
    return n;
  }


  /* =======================================================================
   * THE FIXED TICK (dt = 1/60), allocation-free.
   * ===================================================================== */
  integrateTick(dt: number): void {
    const cfg = this.cfg;
    const s = _nanSnap;
    s.px = this.absPos.x; s.py = this.absPos.y; s.pz = this.absPos.z;
    s.vx = this.absVel.x; s.vy = this.absVel.y; s.vz = this.absVel.z;
    s.lx = this.pLocal.x; s.ly = this.pLocal.y; s.lz = this.pLocal.z;
    s.ux = this.up.x; s.uy = this.up.y; s.uz = this.up.z;
    s.fx = this.fwd.x; s.fy = this.fwd.y; s.fz = this.fwd.z;


    // Spin phase (wrapped mod 2π; quaternion consumers are sign-invariant).
    this._thetaPrev = this._theta;
    this._theta = (this._theta + cfg.spinOmega * dt) % (Math.PI * 2);


    // Cube-face tracking (planet frame) — dominant-axis, zero alloc.
    const ax = Math.abs(this.pLocal.x), ay = Math.abs(this.pLocal.y),
      az = Math.abs(this.pLocal.z);
    let face: number;
    if (ax >= ay && ax >= az) face = this.pLocal.x >= 0 ? 0 : 1;
    else if (ay >= az) face = this.pLocal.y >= 0 ? 2 : 3;
    else face = this.pLocal.z >= 0 ? 4 : 5;
    if (this._face >= 0 && face !== this._face) this.integrity.faceChanges++;
    this._face = face;


    this.input.jump = false; // consumed (edge-triggered)


    if (this._mode === 'VEHICLE') {
      this._vehicleTick(dt);
      this.integrity.ticksVehicle++;
    } else if (this._mode === 'SURFACE' && this._grounded) {
      this._groundedTick(dt);
      this.integrity.ticksGrounded++;
    } else {
      this._flightTick(dt);
      if (this._mode === 'ZERO-G') this.integrity.ticksZeroG++;
      else this.integrity.ticksAirborne++;
    }


    // Mode hysteresis on the range-faded gravity magnitude.
    if (this._mode !== 'VEHICLE') {
      gravityInto(cfg.planetMu, cfg.gravityRange,
        this.absPos.x, this.absPos.y, this.absPos.z, _g);
      const gm = Math.sqrt(_g.x * _g.x + _g.y * _g.y + _g.z * _g.z);
      if (this._mode === 'SURFACE' && !this._grounded && gm < 0.05) {
        this._mode = 'ZERO-G';
      } else if (this._mode === 'ZERO-G' && gm > 0.15) {
        this._mode = 'SURFACE';
      }
    }


    this._fillTelemetry();
    this.integrity.ticks++;


    // NaN guard (Spec 00.2: nothing may NaN).
    if (
      !Number.isFinite(this.absPos.x) || !Number.isFinite(this.absPos.y) ||
      !Number.isFinite(this.absPos.z) || !Number.isFinite(this.absVel.x) ||
      !Number.isFinite(this.absVel.y) || !Number.isFinite(this.absVel.z) ||
      !Number.isFinite(this.pLocal.x) || !Number.isFinite(this.pLocal.y) ||
      !Number.isFinite(this.pLocal.z)
    ) {
      this.absPos.x = s.px; this.absPos.y = s.py; this.absPos.z = s.pz;
      this.absVel.x = s.vx; this.absVel.y = s.vy; this.absVel.z = s.vz;
      this.pLocal.x = s.lx; this.pLocal.y = s.ly; this.pLocal.z = s.lz;
      this.up.x = s.ux; this.up.y = s.uy; this.up.z = s.uz;
      this.fwd.x = s.fx; this.fwd.y = s.fy; this.fwd.z = s.fz;
      this.integrity.nanEvents++;
    }
  }


  /* ---- grounded: the spherical walk --------------------------------------- */


  private _groundedTick(dt: number): void {
    const cfg = this.cfg;
    const R = cfg.planetRadius;
    let r = Math.sqrt(
      this.pLocal.x * this.pLocal.x + this.pLocal.y * this.pLocal.y +
      this.pLocal.z * this.pLocal.z);
    if (r < 1) r = 1;
    const rx = this.pLocal.x / r, ry = this.pLocal.y / r, rz = this.pLocal.z / r;
    const surfCur = R + this._hCur;
    const n = this._nCur;
    const cosSlope = clamp(n.x * rx + n.y * ry + n.z * rz, -1, 1);
    const slope = Math.acos(cosSlope);


    // Gravity (planet frame == world frame for radial fields).
    gravityInto(cfg.planetMu, cfg.gravityRange,
      this.pLocal.x, this.pLocal.y, this.pLocal.z, _g);
    const gN = -(_g.x * n.x + _g.y * n.y + _g.z * n.z);   // normal load (>=0)
    const gDotN = _g.x * n.x + _g.y * n.y + _g.z * n.z;
    _gt.x = _g.x - gDotN * n.x;                            // downhill (tangential)
    _gt.y = _g.y - gDotN * n.y;
    _gt.z = _g.z - gDotN * n.z;
    const gtMag = Math.sqrt(_gt.x * _gt.x + _gt.y * _gt.y + _gt.z * _gt.z);


    // Input -> desired velocity in the surface frame.
    const speed = this.input.crouch ? cfg.crouchSpeed
      : this.input.sprint ? cfg.sprintSpeed : cfg.walkSpeed;
    let inF = this.input.moveF, inR = this.input.moveR;
    const inLen = Math.sqrt(inF * inF + inR * inR);
    if (inLen > 1) { inF /= inLen; inR /= inLen; }
    _right.x = this.fwd.y * this.up.z - this.fwd.z * this.up.y;
    _right.y = this.fwd.z * this.up.x - this.fwd.x * this.up.z;
    _right.z = this.fwd.x * this.up.y - this.fwd.y * this.up.x;
    _vDes.x = (this.fwd.x * inF + _right.x * inR) * speed;
    _vDes.y = (this.fwd.y * inF + _right.y * inR) * speed;
    _vDes.z = (this.fwd.z * inF + _right.z * inR) * speed;


    // Control response (exact exponential — smooth, frame-rate independent).
    const k = Math.exp(-dt / cfg.accelTau);
    this._vCtl.x = _vDes.x + (this._vCtl.x - _vDes.x) * k;
    this._vCtl.y = _vDes.y + (this._vCtl.y - _vDes.y) * k;
    this._vCtl.z = _vDes.z + (this._vCtl.z - _vDes.z) * k;


    // Slope sliding: static threshold slope > slideAngle (mu_s = tan(angle)).
    if (slope > (cfg.slideAngleDeg * Math.PI) / 180 && gtMag > 1e-9) {
      let vx = this._vSlide.x, vy = this._vSlide.y, vz = this._vSlide.z;
      const vm = Math.sqrt(vx * vx + vy * vy + vz * vz);
      if (vm > 0.01) { vx /= vm; vy /= vm; vz /= vm; }
      else { vx = _gt.x / gtMag; vy = _gt.y / gtMag; vz = _gt.z / gtMag; }
      this._vSlide.x += (_gt.x - cfg.kineticFriction * gN * vx) * dt;
      this._vSlide.y += (_gt.y - cfg.kineticFriction * gN * vy) * dt;
      this._vSlide.z += (_gt.z - cfg.kineticFriction * gN * vz) * dt;
    } else {
      const grip = Math.exp(-dt / cfg.slideGripTau);
      this._vSlide.x *= grip; this._vSlide.y *= grip; this._vSlide.z *= grip;
    }
    const slideMag = Math.sqrt(
      this._vSlide.x * this._vSlide.x + this._vSlide.y * this._vSlide.y +
      this._vSlide.z * this._vSlide.z);
    if (slideMag > this.integrity.maxSlideSpeed) this.integrity.maxSlideSpeed = slideMag;


    // JUMP — along the surface normal; launch converts to inertial absolute.
    if (this.input.jump && !this.input.crouch) {
      const u = cfg.jumpSpeed;
      _vT.x = this._vCtl.x + this._vSlide.x + n.x * u;
      _vT.y = this._vCtl.y + this._vSlide.y + n.y * u;
      _vT.z = this._vCtl.z + this._vSlide.z + n.z * u;
      this._composeGrounded(this._vCtl.x, this._vCtl.y, this._vCtl.z); // P only
      spinQuatInto(this._theta, _qSpin);
      rotateByQuatInto(_qSpin, _vT.x, _vT.y, _vT.z, _tmp);
      transportVelocityInto(cfg.spinOmega, this.absPos.x, this.absPos.y,
        this.absPos.z, _tmp2);
      this.absVel.x = _tmp2.x + _tmp.x;
      this.absVel.y = _tmp2.y + _tmp.y;
      this.absVel.z = _tmp2.z + _tmp.z;
      this._grounded = false;
      this._flightTick(dt);      // launch tick continues inertially
      return;
    }


    // ---- horizontal move with step / block / snap logic -------------------
    let dx = (this._vCtl.x + this._vSlide.x) * dt;
    let dy = (this._vCtl.y + this._vSlide.y) * dt;
    let dz = (this._vCtl.z + this._vSlide.z) * dt;
    let moved = false;
    let cliff = false;
    const arc = Math.sqrt(dx * dx + dy * dy + dz * dz);
    if (arc > 1e-9) {
      if (this._tryMove(dx, dy, dz, surfCur, r)) {
        moved = true;
      } else {
        // Blocked: wall-slide projection (one retry) using the target normal.
        this._wallDirFromTarget(dx, dy, dz);
        const dot = dx * _wall.x + dy * _wall.y + dz * _wall.z;
        if (dot < 0) {
          dx -= dot * _wall.x; dy -= dot * _wall.y; dz -= dot * _wall.z;
          if (this._tryMove(dx, dy, dz, surfCur, r)) moved = true;
        }
      }
      if (!moved) {
        // Fully blocked — but check whether the ORIGINAL move was a cliff
        // (downhill beyond snap): then it was already accepted inside _tryMove
        // via the cliff path (grounded=false). If still grounded here, hold.
        if (!this._grounded) cliff = true;
      }
    }


    if (this._grounded) {
      // Frame transport at the (possibly new) position.
      let r2 = Math.sqrt(this.pLocal.x * this.pLocal.x +
        this.pLocal.y * this.pLocal.y + this.pLocal.z * this.pLocal.z);
      if (r2 < 1) r2 = 1;
      const rdx = this.pLocal.x / r2, rdy = this.pLocal.y / r2, rdz = this.pLocal.z / r2;
      if (moved) {
        terrainNormalInto(rdx, rdy, rdz, _nNew);
        this._nCur.x = _nNew.x; this._nCur.y = _nNew.y; this._nCur.z = _nNew.z;
        this._hCur = terrainHeight(rdx, rdy, rdz);
      }
      this._refreshUpFwd(rdx, rdy, rdz);


      // Yaw input (finite rotation about up — never accumulated Euler).
      if (this.input.turnRate !== 0) {
        rotateAboutAxisInto(this.fwd.x, this.fwd.y, this.fwd.z,
          this.up.x, this.up.y, this.up.z, this.input.turnRate * dt, _fwdT);
        this.fwd.x = _fwdT.x; this.fwd.y = _fwdT.y; this.fwd.z = _fwdT.z;
      }
      // Auto-turn toward movement (third person). Reported for camera
      // orbit compensation (harness subtracts it from the camera offset).
      let turnApplied = 0;
      const ctlMag = Math.sqrt(this._vCtl.x * this._vCtl.x +
        this._vCtl.y * this._vCtl.y + this._vCtl.z * this._vCtl.z);
      if (this.autoTurnEnabled && ctlMag > 0.5) {
        const a = signedAngleAbout(this.fwd.x, this.fwd.y, this.fwd.z,
          this._vCtl.x / ctlMag, this._vCtl.y / ctlMag, this._vCtl.z / ctlMag,
          this.up.x, this.up.y, this.up.z);
        let step = a * (1 - Math.exp(-8 * dt));
        const maxStep = cfg.autoTurnRate * dt;
        if (step > maxStep) step = maxStep;
        else if (step < -maxStep) step = -maxStep;
        rotateAboutAxisInto(this.fwd.x, this.fwd.y, this.fwd.z,
          this.up.x, this.up.y, this.up.z, step, _fwdT);
        this.fwd.x = _fwdT.x; this.fwd.y = _fwdT.y; this.fwd.z = _fwdT.z;
        turnApplied = step;
      }
      this.telemetry.turnApplied = turnApplied;


      // Absolute compose: analytic transport + relative walk (Spec 01.4).
      this._composeGrounded(
        this._vCtl.x + this._vSlide.x,
        this._vCtl.y + this._vSlide.y,
        this._vCtl.z + this._vSlide.z);


      // RCS regen while planted.
      if (this._rcsBudget < cfg.rcsBudgetMax) {
        this._rcsBudget = Math.min(cfg.rcsBudgetMax,
          this._rcsBudget + cfg.rcsRegen * dt);
      }
    }
    void cliff;
  }


  /**
   * Attempt the tangent move (dx,dy,dz) from the current feet position.
   * Accepts climbs (step rule), snap-downs, and cliff transitions (sets
   * grounded=false and continues inertially). Returns true if the position
   * changed. Post-tick AGL >= 0 structurally: accepted positions anchor to
   * the probed surface.
   */
  private _tryMove(dx: number, dy: number, dz: number, surfCur: number, r: number): boolean {
    const cfg = this.cfg;
    _pTry.x = this.pLocal.x + dx;
    _pTry.y = this.pLocal.y + dy;
    _pTry.z = this.pLocal.z + dz;
    const l = Math.sqrt(_pTry.x * _pTry.x + _pTry.y * _pTry.y + _pTry.z * _pTry.z) || 1;
    _dTry.x = _pTry.x / l; _dTry.y = _pTry.y / l; _dTry.z = _pTry.z / l;
    const hT = terrainHeight(_dTry.x, _dTry.y, _dTry.z);
    const surfT = cfg.planetRadius + hT;
    const arc = Math.sqrt(dx * dx + dy * dy + dz * dz);
    const dH = surfT - surfCur;
    if (dH <= 0.001) {
      if (-dH > cfg.snapDistance) {
        // Cliff: continue at the current radius, airborne from here.
        this.pLocal.x = _dTry.x * r;
        this.pLocal.y = _dTry.y * r;
        this.pLocal.z = _dTry.z * r;
        this._composeGrounded(
          this._vCtl.x + this._vSlide.x,
          this._vCtl.y + this._vSlide.y,
          this._vCtl.z + this._vSlide.z);
        this._grounded = false;
        return true;
      }
      // Snap-down / flat follow.
      const rr = surfT + cfg.groundClearance;
      this.pLocal.x = _dTry.x * rr;
      this.pLocal.y = _dTry.y * rr;
      this.pLocal.z = _dTry.z * rr;
      return true;
    }
    // Uphill: the derived dual step rule (absolute step AND slope ratio).
    const tanMax = Math.tan((cfg.maxWalkSlopeDeg * Math.PI) / 180);
    if (dH <= cfg.stepHeight && dH / arc <= tanMax) {
      const rr = surfT + cfg.groundClearance;
      this.pLocal.x = _dTry.x * rr;
      this.pLocal.y = _dTry.y * rr;
      this.pLocal.z = _dTry.z * rr;
      return true;
    }
    return false; // blocked
  }


  /** Wall direction from the TARGET normal's tangential component
   *  (points downhill = away from the steep face). Fallback: -moveDir. */
  private _wallDirFromTarget(dx: number, dy: number, dz: number): void {
    const l = Math.sqrt(dx * dx + dy * dy + dz * dz) || 1;
    _pTry.x = this.pLocal.x + dx;
    _pTry.y = this.pLocal.y + dy;
    _pTry.z = this.pLocal.z + dz;
    const ll = Math.sqrt(_pTry.x * _pTry.x + _pTry.y * _pTry.y + _pTry.z * _pTry.z) || 1;
    _dTry.x = _pTry.x / ll; _dTry.y = _pTry.y / ll; _dTry.z = _pTry.z / ll;
    terrainNormalInto(_dTry.x, _dTry.y, _dTry.z, _nNew);
    const d = _nNew.x * _dTry.x + _nNew.y * _dTry.y + _nNew.z * _dTry.z;
    let wx = _nNew.x - d * _dTry.x;
    let wy = _nNew.y - d * _dTry.y;
    let wz = _nNew.z - d * _dTry.z;
    const m = Math.sqrt(wx * wx + wy * wy + wz * wz);
    if (m < 1e-6) {
      _wall.x = -dx / l; _wall.y = -dy / l; _wall.z = -dz / l;
    } else {
      _wall.x = wx / m; _wall.y = wy / m; _wall.z = wz / m;
    }
  }


  /** Blend the cached normal with radial -> up; transport fwd. */
  private _refreshUpFwd(rx: number, ry: number, rz: number): void {
    const w = this.cfg.upBlendWeight;
    let ux = w * this._nCur.x + (1 - w) * rx;
    let uy = w * this._nCur.y + (1 - w) * ry;
    let uz = w * this._nCur.z + (1 - w) * rz;
    const m = Math.sqrt(ux * ux + uy * uy + uz * uz) || 1;
    ux /= m; uy /= m; uz /= m;
    this.up.x = ux; this.up.y = uy; this.up.z = uz;
    transportFrameInto(this.fwd.x, this.fwd.y, this.fwd.z, ux, uy, uz, _fwdT);
    this.fwd.x = _fwdT.x; this.fwd.y = _fwdT.y; this.fwd.z = _fwdT.z;
  }


  /** Grounded compose: P = R(θ)·pLocal; V = Ω×P + R(θ)·vRel. */
  private _composeGrounded(vx: number, vy: number, vz: number): void {
    spinQuatInto(this._theta, _qSpin);
    rotateByQuatInto(_qSpin, this.pLocal.x, this.pLocal.y, this.pLocal.z, _tmp);
    this.absPos.x = _tmp.x; this.absPos.y = _tmp.y; this.absPos.z = _tmp.z;
    rotateByQuatInto(_qSpin, vx, vy, vz, _tmp);
    transportVelocityInto(this.cfg.spinOmega, this.absPos.x, this.absPos.y,
      this.absPos.z, _tmp2);
    this.absVel.x = _tmp2.x + _tmp.x;
    this.absVel.y = _tmp2.y + _tmp.y;
    this.absVel.z = _tmp2.z + _tmp.z;
  }


  /* ---- airborne / zero-G: inertial integration ----------------------------- */


  private _flightTick(dt: number): void {
    const cfg = this.cfg;
    const px = this.absPos.x, py = this.absPos.y, pz = this.absPos.z;


    // Central gravity (range-faded; ~0 in zero-G by construction).
    gravityInto(cfg.planetMu, cfg.gravityRange, px, py, pz, _g);
    this.absVel.x += _g.x * dt;
    this.absVel.y += _g.y * dt;
    this.absVel.z += _g.z * dt;


    // ZERO-G RCS pack (limited — Spec 00.4: zero-g recovery only).
    if (this._mode === 'ZERO-G' && this._rcsBudget > 0) {
      let ax = this.input.rcsF, ay = this.input.rcsU, az = this.input.rcsR;
      const al = Math.sqrt(ax * ax + ay * ay + az * az);
      if (al > 1) { ax /= al; ay /= al; az /= al; }
      if (al > 1e-6) {
        // Thrust along the character frame, rotated to world by the spin.
        _right.x = this.fwd.y * this.up.z - this.fwd.z * this.up.y;
        _right.y = this.fwd.z * this.up.x - this.fwd.x * this.up.z;
        _right.z = this.fwd.x * this.up.y - this.fwd.y * this.up.x;
        _vT.x = this.fwd.x * ax + this.up.x * ay + _right.x * az;
        _vT.y = this.fwd.y * ax + this.up.y * ay + _right.y * az;
        _vT.z = this.fwd.z * ax + this.up.z * ay + _right.z * az;
        spinQuatInto(this._theta, _qSpin);
        rotateByQuatInto(_qSpin, _vT.x, _vT.y, _vT.z, _tmp);
        const a = cfg.rcsAccel * dt;
        this.absVel.x += _tmp.x * a;
        this.absVel.y += _tmp.y * a;
        this.absVel.z += _tmp.z * a;
        this._rcsBudget = Math.max(0, this._rcsBudget - a * al);
      }
    }


    // Yaw (ZERO-G free attitude).
    if (this._mode === 'ZERO-G' && this.input.turnRate !== 0) {
      rotateAboutAxisInto(this.fwd.x, this.fwd.y, this.fwd.z,
        this.up.x, this.up.y, this.up.z, this.input.turnRate * dt, _fwdT);
      this.fwd.x = _fwdT.x; this.fwd.y = _fwdT.y; this.fwd.z = _fwdT.z;
    }


    // Frame: gentle re-alignment of up toward local radial (C0, no snaps).
    const r0 = Math.sqrt(px * px + py * py + pz * pz) || 1;
    const blend = 1 - Math.exp(-dt / cfg.airborneUpTau);
    let ux = this.up.x + (px / r0 - this.up.x) * blend;
    let uy = this.up.y + (py / r0 - this.up.y) * blend;
    let uz = this.up.z + (pz / r0 - this.up.z) * blend;
    const um = Math.sqrt(ux * ux + uy * uy + uz * uz) || 1;
    this.up.x = ux / um; this.up.y = uy / um; this.up.z = uz / um;
    transportFrameInto(this.fwd.x, this.fwd.y, this.fwd.z,
      this.up.x, this.up.y, this.up.z, _fwdT);
    this.fwd.x = _fwdT.x; this.fwd.y = _fwdT.y; this.fwd.z = _fwdT.z;


    // Inertial drift.
    const prevX = px, prevY = py, prevZ = pz;
    this.absPos.x += this.absVel.x * dt;
    this.absPos.y += this.absVel.y * dt;
    this.absPos.z += this.absVel.z * dt;


    // Terrain sweep (band-gated) + landing.
    this._sweep(prevX, prevY, prevZ, this.absPos.x, this.absPos.y, this.absPos.z, dt);


    // Planet-frame mirror (face tracking / telemetry).
    spinQuatInto(this._theta, _qSpin);
    const r1 = Math.sqrt(this.absPos.x * this.absPos.x + this.absPos.y * this.absPos.y +
      this.absPos.z * this.absPos.z) || 1;
    rotateByQuatConjInto(_qSpin,
      this.absPos.x / r1, this.absPos.y / r1, this.absPos.z / r1, _dS);
    this.pLocal.x = _dS.x * r1; this.pLocal.y = _dS.y * r1; this.pLocal.z = _dS.z * r1;
  }


  /**
   * Gap-limited analytic sweep with SPIN-INTERPOLATED sample transforms:
   * the terrain occupies planet-frame directions; at sample fraction s the
   * planet has rotated to θ(s) = θ_prev + Ω·dt·s. Without the interpolation
   * the rotating ground is misplaced by up to r·Ω·dt = 0.87 m per tick at
   * the equator — with it the sweep is exact. Worker-independent by
   * construction (the same f64 field the workers mesh).
   */
  private _sweep(
    x0: number, y0: number, z0: number,
    x1: number, y1: number, z1: number,
    dt: number,
  ): void {
    const cfg = this.cfg;
    const R = cfg.planetRadius;
    const band = R + cfg.maxTerrainHeight + cfg.sweepGap * 2;


    // Segment min-radius early-out.
    const dx = x1 - x0, dy = y1 - y0, dz = z1 - z0;
    const dd = dx * dx + dy * dy + dz * dz;
    if (dd < 1e-18) return;
    let t = -(x0 * dx + y0 * dy + z0 * dz) / dd;
    t = clamp(t, 0, 1);
    const cx = x0 + dx * t, cy = y0 + dy * t, cz = z0 + dz * t;
    if (Math.sqrt(cx * cx + cy * cy + cz * cz) > band) return;


    // Tick-start embed check (transient from a previous tick).
    const r0 = Math.sqrt(x0 * x0 + y0 * y0 + z0 * z0);
    if (r0 < band) {
      spinQuatInto(this._thetaPrev, _qSpin);
      rotateByQuatConjInto(_qSpin, x0 / r0, y0 / r0, z0 / r0, _dS);
      if (r0 - (R + terrainHeight(_dS.x, _dS.y, _dS.z)) < cfg.groundClearance) {
        this._landAt(x0, y0, z0, this._thetaPrev);
        return;
      }
    }


    const seg = Math.sqrt(dd);
    const steps = Math.max(1, Math.ceil(seg / cfg.sweepGap));
    const dTheta = (this._theta - this._thetaPrev) / steps;
    let theta = this._thetaPrev + dTheta;
    for (let i = 1; i <= steps; i++) {
      const s = i / steps;
      const sx = x0 + dx * s, sy = y0 + dy * s, sz = z0 + dz * s;
      const r = Math.sqrt(sx * sx + sy * sy + sz * sz);
      if (r >= band) { theta += dTheta; continue; }
      spinQuatInto(theta, _qSpin);
      rotateByQuatConjInto(_qSpin, sx / r, sy / r, sz / r, _dS);
      const agl = r - (R + terrainHeight(_dS.x, _dS.y, _dS.z));
      if (agl < this.integrity.minAGL) this.integrity.minAGL = agl;
      if (agl < cfg.groundClearance) {
        // Sub-tick bisection with spin-interpolated θ.
        let lo = (i - 1) / steps, hi = s, thLo = theta - dTheta;
        for (let k = 0; k < 14; k++) {
          const m = 0.5 * (lo + hi);
          const mx = x0 + dx * m, my = y0 + dy * m, mz = z0 + dz * m;
          const mr = Math.sqrt(mx * mx + my * my + mz * mz);
          spinQuatInto(thLo + (theta - thLo) * ((m - lo) / (hi - lo || 1)), _qSpin);
          rotateByQuatConjInto(_qSpin, mx / mr, my / mr, mz / mr, _dS);
          const a2 = mr - (R + terrainHeight(_dS.x, _dS.y, _dS.z));
          if (a2 < cfg.groundClearance) hi = m; else lo = m;
        }
        const m = 0.5 * (lo + hi);
        this._landAt(x0 + dx * m, y0 + dy * m, z0 + dz * m,
          this._thetaPrev + cfg.spinOmega * dt * m);
        return;
      }
      theta += dTheta;
    }
  }


  /** Landing: decompose to relative, kill normal velocity, PLANT tangential
   *  (Spec M1E: "immediately settle into a 0 m/s relative walk state"). */
  private _landAt(px: number, py: number, pz: number, theta: number): void {
    const cfg = this.cfg;
    spinQuatInto(theta, _qSpin);
    const r = Math.sqrt(px * px + py * py + pz * pz) || 1;
    rotateByQuatConjInto(_qSpin, px / r, py / r, pz / r, _dS);
    const h = terrainHeight(_dS.x, _dS.y, _dS.z);
    const rr = cfg.planetRadius + h + cfg.groundClearance;
    this.pLocal.x = _dS.x * rr; this.pLocal.y = _dS.y * rr; this.pLocal.z = _dS.z * rr;
    this._hCur = h;
    terrainNormalInto(_dS.x, _dS.y, _dS.z, this._nCur);


    // Absolute state at the contact point.
    rotateByQuatInto(_qSpin, this.pLocal.x, this.pLocal.y, this.pLocal.z, _tmp);
    this.absPos.x = _tmp.x; this.absPos.y = _tmp.y; this.absPos.z = _tmp.z;


    // Relative velocity: v_rel = R⁻¹(V − Ω×P)  [the Coriolis handoff].
    transportVelocityInto(cfg.spinOmega, this.absPos.x, this.absPos.y,
      this.absPos.z, _tmp2);
    rotateByQuatConjInto(_qSpin,
      this.absVel.x - _tmp2.x, this.absVel.y - _tmp2.y, this.absVel.z - _tmp2.z, _rel);
    this.integrity.lastLandingRelSpeed = Math.sqrt(
      _rel.x * _rel.x + _rel.y * _rel.y + _rel.z * _rel.z);


    // Kill the normal component (no bounce), plant the tangential.
    const n = this._nCur;
    const vn = _rel.x * n.x + _rel.y * n.y + _rel.z * n.z;
    if (vn < 0) {
      _rel.x -= n.x * vn; _rel.y -= n.y * vn; _rel.z -= n.z * vn;
    }
    // PLANT: input takes over; no input -> 0 m/s relative (no skating).
    const speed = this.input.crouch ? cfg.crouchSpeed
      : this.input.sprint ? cfg.sprintSpeed : cfg.walkSpeed;
    let inF = this.input.moveF, inR = this.input.moveR;
    const inLen = Math.sqrt(inF * inF + inR * inR);
    if (inLen > 1) { inF /= inLen; inR /= inLen; }
    if (inLen > 0.01) {
      // Keep the landing tangential momentum only along the input intent.
      this._vCtl.x = this.fwd.x * inF * speed;
      this._vCtl.y = this.fwd.y * inF * speed;
      this._vCtl.z = this.fwd.z * inF * speed;
    } else {
      this._vCtl.x = 0; this._vCtl.y = 0; this._vCtl.z = 0;
    }
    this._vSlide.x = 0; this._vSlide.y = 0; this._vSlide.z = 0;
    this._grounded = true;
    this._mode = 'SURFACE';
    this.integrity.landings++;
    this._refreshUpFwd(_dS.x, _dS.y, _dS.z);
    this._composeGrounded(this._vCtl.x, this._vCtl.y, this._vCtl.z);
  }


  /* ---- vehicle: parented compose (Spec 01.1 step 3) ------------------------ */


  private _vehicleTick(_dt: number): void {
    const p = this._vehicle;
    if (p === null) { this._mode = 'SURFACE'; return; }
    rotateByQuatInto(p.quat, this._vehOffset.x, this._vehOffset.y, this._vehOffset.z, _tmp);
    this.absPos.x = p.pos.x + _tmp.x;
    this.absPos.y = p.pos.y + _tmp.y;
    this.absPos.z = p.pos.z + _tmp.z;
    rotateByQuatInto(p.quat, this._vehUp.x, this._vehUp.y, this._vehUp.z, _upT);
    this.up.x = _upT.x; this.up.y = _upT.y; this.up.z = _upT.z;
    rotateByQuatInto(p.quat, this._vehFwd.x, this._vehFwd.y, this._vehFwd.z, _fwdT);
    this.fwd.x = _fwdT.x; this.fwd.y = _fwdT.y; this.fwd.z = _fwdT.z;
    // V = parentVel + ω × (P − parentPos).
    const rx = this.absPos.x - p.pos.x;
    const ry = this.absPos.y - p.pos.y;
    const rz = this.absPos.z - p.pos.z;
    this.absVel.x = p.vel.x + (p.angVel.y * rz - p.angVel.z * ry);
    this.absVel.y = p.vel.y + (p.angVel.z * rx - p.angVel.x * rz);
    this.absVel.z = p.vel.z + (p.angVel.x * ry - p.angVel.y * rx);
    // Planet-frame mirror.
    spinQuatInto(this._theta, _qSpin);
    const r = Math.sqrt(this.absPos.x * this.absPos.x + this.absPos.y * this.absPos.y +
      this.absPos.z * this.absPos.z) || 1;
    rotateByQuatConjInto(_qSpin,
      this.absPos.x / r, this.absPos.y / r, this.absPos.z / r, _dS);
    this.pLocal.x = _dS.x * r; this.pLocal.y = _dS.y * r; this.pLocal.z = _dS.z * r;
  }


  /* ---- telemetry ------------------------------------------------------------ */


  private _fillTelemetry(): void {
    const cfg = this.cfg;
    const t = this.telemetry;
    const R = cfg.planetRadius;
    let r = Math.sqrt(this.pLocal.x * this.pLocal.x + this.pLocal.y * this.pLocal.y +
      this.pLocal.z * this.pLocal.z);
    if (r < 1) r = 1;
    const rx = this.pLocal.x / r, ry = this.pLocal.y / r, rz = this.pLocal.z / r;
    t.mode = this._mode;
    t.grounded = this._grounded;
    t.crouched = this.input.crouch;
    t.eyeHeight = this.input.crouch ? cfg.crouchEyeHeight : cfg.eyeHeight;
    if (this._grounded) {
      t.relSpeed = Math.sqrt(
        (this._vCtl.x + this._vSlide.x) ** 2 +
        (this._vCtl.y + this._vSlide.y) ** 2 +
        (this._vCtl.z + this._vSlide.z) ** 2);
      t.slideSpeed = Math.sqrt(
        this._vSlide.x ** 2 + this._vSlide.y ** 2 + this._vSlide.z ** 2);
    } else {
      transportVelocityInto(cfg.spinOmega, this.absPos.x, this.absPos.y,
        this.absPos.z, _tmp2);
      _rel.x = this.absVel.x - _tmp2.x;
      _rel.y = this.absVel.y - _tmp2.y;
      _rel.z = this.absVel.z - _tmp2.z;
      t.relSpeed = Math.sqrt(_rel.x ** 2 + _rel.y ** 2 + _rel.z ** 2);
      t.slideSpeed = 0;
    }
    t.transportSpeed = cfg.spinOmega *
      Math.sqrt(this.absPos.x ** 2 + this.absPos.z ** 2);
    t.absSpeed = Math.sqrt(this.absVel.x ** 2 + this.absVel.y ** 2 +
      this.absVel.z ** 2);
    t.altMSL = r - R;
    if (r < R + cfg.maxTerrainHeight + 64) {
      t.altAGL = r - (R + this._hCur) - cfg.groundClearance;
    } else {
      t.altAGL = t.altMSL - cfg.maxTerrainHeight;
    }
    const cosSlope = clamp(this._nCur.x * rx + this._nCur.y * ry +
      this._nCur.z * rz, -1, 1);

interface Site { x: number; y: number; z: number; slopeDeg: number; }
function slopeDegAt(d: Vec3): number {
  terrainNormalInto(d.x, d.y, d.z, _scanN);
  const c = _scanN.x * d.x + _scanN.y * d.y + _scanN.z * d.z;
  return (Math.acos(Math.max(-1, Math.min(1, c))) * 180) / Math.PI;
}

function scanFor(
  pred: (d: Vec3, slope: number) => boolean, tries: number, rand: () => number,
): Site | null {
  for (let i = 0; i < tries; i++) {
    const u = rand() * 2 - 1;
    const th = rand() * Math.PI * 2;
    const s = Math.sqrt(1 - u * u);
    _scanT.x = Math.cos(th) * s; _scanT.y = u; _scanT.z = Math.sin(th) * s;
    const slope = slopeDegAt(_scanT);
    if (pred(_scanT, slope)) {
      return { x: _scanT.x, y: _scanT.y, z: _scanT.z, slopeDeg: slope };
    }
  }
  return null;
}

function runFaceWalk(): TestResult {
  const F = suite.face;
  kccT1.teleportSurface(T1_START.x, T1_START.y, T1_START.z);
  kccT1.resetIntegrityStats();
  kccT1.autoTurnEnabled = false;
  const inp = kccT1.input;
  inp.moveF = 1; inp.moveR = 0; inp.sprint = true; inp.crouch = false;
  inp.jump = false; inp.turnRate = 0;
  let px = kccT1.pLocal.x, py = kccT1.pLocal.y, pz = kccT1.pLocal.z;
  const maxTicks = 95_000;
  while (F.pathLen < 11_600 && F.ticks < maxTicks) {
    // Great-circle steering: target tangent t = normalize(c × d).
    const p = kccT1.pLocal;
    const l = Math.hypot(p.x, p.y, p.z);
    _vA.x = GC_C.y * (p.z / l) - GC_C.z * (p.y / l);
    _vA.y = GC_C.z * (p.x / l) - GC_C.x * (p.z / l);
    _vA.z = GC_C.x * (p.y / l) - GC_C.y * (p.x / l);
    const tl = Math.hypot(_vA.x, _vA.y, _vA.z);
    _vA.x /= tl; _vA.y /= tl; _vA.z /= tl;
    const a = signedAngleAbout(kccT1.fwd.x, kccT1.fwd.y, kccT1.fwd.z,
      _vA.x, _vA.y, _vA.z, kccT1.up.x, kccT1.up.y, kccT1.up.z);
    inp.turnRate = Math.max(-2.5, Math.min(2.5, a * 3));
    kccT1.integrateTick(1 / 60);
    F.ticks++;
    const nx = kccT1.pLocal.x, ny = kccT1.pLocal.y, nz = kccT1.pLocal.z;
    F.pathLen += Math.hypot(nx - px, ny - py, nz - pz);
    px = nx; py = ny; pz = nz;
    // Frame smoothness (dot with previous tick's frame).
    const ud = kccT1.up.x * _vB.x + kccT1.up.y * _vB.y + kccT1.up.z * _vB.z;
    const fd = kccT1.fwd.x * _vC.x + kccT1.fwd.y * _vC.y + kccT1.fwd.z * _vC.z;
    if (F.ticks > 1) {
      if (ud < F.minUpDot) F.minUpDot = ud;
      if (fd < F.minFwdDot) F.minFwdDot = fd;
    }
    _vB.x = kccT1.up.x; _vB.y = kccT1.up.y; _vB.z = kccT1.up.z;
    _vC.x = kccT1.fwd.x; _vC.y = kccT1.fwd.y; _vC.z = kccT1.fwd.z;
    const ortho = Math.abs(kccT1.fwd.x * kccT1.up.x + kccT1.fwd.y * kccT1.up.y +
      kccT1.fwd.z * kccT1.up.z);
    if (ortho > F.maxOrtho) F.maxOrtho = ortho;
    kccT1.frameQuatInto(_qA);
    const qn = Math.sqrt(_qA.x ** 2 + _qA.y ** 2 + _qA.z ** 2 + _qA.w ** 2);
    const dev = Math.abs(qn - 1);
    if (dev > F.maxQuatDev) F.maxQuatDev = dev;
    const cd = kccT1.pLocal.x * CORNER.x + kccT1.pLocal.y * CORNER.y +
      kccT1.pLocal.z * CORNER.z;
    const cl = Math.hypot(kccT1.pLocal.x, kccT1.pLocal.y, kccT1.pLocal.z);
    const cang = Math.acos(Math.max(-1, Math.min(1, cd / cl)));
    if (cang < F.minCornerAngle) F.minCornerAngle = cang;
  }
  F.faceChanges = kccT1.integrity.faceChanges;
  F.minAGL = kccT1.integrity.minAGL;
  const pass =
    F.faceChanges >= 2 &&
    F.minUpDot > Math.cos(0.02) &&
    F.minFwdDot > Math.cos(0.09) &&
    F.maxOrtho < 1e-9 &&
    F.maxQuatDev < 1e-12 &&
    F.minCornerAngle < 0.06 &&
    F.minAGL > -0.05 &&
    F.pathLen > 11_000;
  const deg = (r: number) => ((Math.acos(Math.max(-1, Math.min(1, r))) * 180) / Math.PI);
  return {
    pass,
    detail:
      `${(F.pathLen / 1000).toFixed(1)} km great-circle walk through the (1,1,1)/√3 ` +
      `cube CORNER (closest approach ${deg(F.minCornerAngle).toFixed(2)}°): ` +
      `${F.faceChanges} face changes; max per-tick up rotation ${deg(F.minUpDot).toFixed(3)}° ` +
      `(bound 1.15°), fwd ${deg(F.minFwdDot).toFixed(3)}° (bound 5.2°) — no yaw snaps; ` +
      `fwd⊥up max ${F.maxOrtho.toExponential(1)} (no gimbal degeneracy); quaternion norm ` +
      `dev ${F.maxQuatDev.toExponential(1)}; min AGL ${F.minAGL.toFixed(3)} m. ` +
      `Holonomy of a great circle = 2π ≡ identity — the frame is pole/face-singularity-free.`,
  };
}


function runCoriolisJump(): TestResult {
  const C = suite.coriolis;
  kcc.teleportSurface(FLAT_SITE.x, FLAT_SITE.y, FLAT_SITE.z);
  kcc.autoTurnEnabled = true;
  const inp = kcc.input;
  inp.moveF = 0; inp.moveR = 0; inp.sprint = false; inp.crouch = false;
  inp.turnRate = 0; inp.rcsF = 0; inp.rcsU = 0; inp.rcsR = 0;
  for (let i = 0; i < 5; i++) kcc.integrateTick(1 / 60);   // settle plant
  const lx = kcc.pLocal.x, ly = kcc.pLocal.y, lz = kcc.pLocal.z;
  // Launch up (character up ≈ radial on the flat site) — record for the
  // tilt-drift prediction (jump is along up, not exactly radial).
  const upx = kcc.up.x, upy = kcc.up.y, upz = kcc.up.z;
  const rl = Math.hypot(lx, ly, lz);
  const rx = lx / rl, ry = ly / rl, rz = lz / rl;
  inp.jump = true;
  let airTicks = 0;
  for (let i = 0; i < 240; i++) {
    kcc.integrateTick(1 / 60);
    if (kcc.grounded) break;
    airTicks++;
  }
  C.airTicks = airTicks;
  const T = airTicks / 60;
  // Predicted tilt drift: u·(up − (up·r̂)r̂)·T (jump along the blended up).
  const upd = upx * rx + upy * ry + upz * rz;
  _vA.x = (upx - upd * rx) * 5 * T;
  _vA.y = (upy - upd * ry) * 5 * T;
  _vA.z = (upz - upd * rz) * 5 * T;
  // Planet-frame drift, tilt-corrected.
  _vB.x = kcc.pLocal.x - lx - _vA.x;
  _vB.y = kcc.pLocal.y - ly - _vA.y;
  _vB.z = kcc.pLocal.z - lz - _vA.z;
  transportVelocityInto(EARTHSCALE_ASTRONAUT.spinOmega, lx, ly, lz, _vC);
  const tl = Math.hypot(_vC.x, _vC.y, _vC.z) || 1;
  _vD.x = -_vC.x / tl; _vD.y = -_vC.y / tl; _vD.z = -_vC.z / tl;  // WEST
  C.westDrift = _vB.x * _vD.x + _vB.y * _vD.y + _vB.z * _vD.z;
  const wmag = Math.abs(C.westDrift);
  _vA.x = _vB.x - C.westDrift * _vD.x;
  _vA.y = _vB.y - C.westDrift * _vD.y;
  _vA.z = _vB.z - C.westDrift * _vD.z;
  C.perpDrift = Math.hypot(_vA.x, _vA.y, _vA.z);
  const g = EARTHSCALE_ASTRONAUT.planetMu / (rl * rl);
  C.predicted = (4 / 3) * EARTHSCALE_ASTRONAUT.spinOmega * 125 / (g * g);
  // Settle: no skating — relative speed to 0 within 2 ticks, stays 0.
  let settleTicks = -1, maxSettle = 0;
  for (let i = 0; i < 32; i++) {
    kcc.integrateTick(1 / 60);
    if (i >= 1) {
      if (settleTicks < 0 && kcc.telemetry.relSpeed < 0.02) settleTicks = i;
      if (settleTicks >= 0 && kcc.telemetry.relSpeed > maxSettle)
        maxSettle = kcc.telemetry.relSpeed;
    }
  }
  C.settleTicks = settleTicks;
  C.maxSettleSpeed = maxSettle;
  const pass =
    C.westDrift > 0.006 && C.westDrift < 0.06 &&
    C.perpDrift < 0.012 &&
    airTicks > 48 && airTicks < 78 &&
    settleTicks >= 1 && settleTicks <= 2 &&
    maxSettle < 0.02;
  return {
    pass,
    detail:
      `SPEC-CANONICAL TEST: vertical jump (u = 5 m/s) at the equator of the ` +
      `52 m/s planet (Ω = 0.0104). Landed ${(C.westDrift * 100).toFixed(2)} cm WEST ` +
      `(theory (4/3)Ωu³/g² = ${(C.predicted * 100).toFixed(2)} cm — pure inertial ` +
      `integration, angular momentum conserved); cross-track residual ` +
      `${(C.perpDrift * 100).toFixed(2)} cm; airborne ${T.toFixed(2)} s (2u/g ≈ 1.02 s); ` +
      `post-touchdown relative speed planted to < 0.02 m/s within ${settleTicks} tick(s) ` +
      `and held (max ${maxSettle.toFixed(3)} m/s over 32 ticks) — zero skating. The ` +
      `launch/landing planet-frame comparison also validates the R(θ) compose/decompose ` +
      `round-trip across a 53 m transport displacement.`,
  };
}


function runStateMachine(): TestResult {
  const S = suite.sm;
  const inp = kcc.input;
  inp.moveF = 0; inp.moveR = 0; inp.sprint = false; inp.crouch = false;
  inp.turnRate = 0; inp.rcsF = 0; inp.rcsU = 0; inp.rcsR = 0;

  kcc.integrateTick(1 / 60);
  const zeroOk = kcc.mode === 'ZERO-G';

  for (let i = 0; i < 120; i++) kcc.integrateTick(1 / 60);
  inp.rcsF = 0;
  const v = Math.hypot(kcc.absVel.x, kcc.absVel.y, kcc.absVel.z);
  S.rcsDv = v;
  S.budgetUsed = b0 - kcc.telemetry.rcsBudget;

  inp.turnRate = 0.5;
  for (let i = 0; i < 60; i++) kcc.integrateTick(1 / 60);
  inp.turnRate = 0;
  S.yawAngle = Math.acos(Math.max(-1, Math.min(1,
    kcc.fwd.x * f0.x + kcc.fwd.y * f0.y + kcc.fwd.z * f0.z)));
  // (4) Deorbit: 30 m/s inward, fall, re-enter, land.
  const P = kcc.absPos;
  const pl = Math.hypot(P.x, P.y, P.z);
  kcc.teleportAbs(P.x, P.y, P.z, (-30 * P.x) / pl, (-30 * P.y) / pl, (-30 * P.z) / pl);
  let surfaceTick = -1, landed = false;
  for (let i = 0; i < 20_000; i++) {
    kcc.integrateTick(1 / 60);
    if (surfaceTick < 0 && kcc.mode === 'SURFACE') surfaceTick = i;
    if (kcc.grounded) { landed = true; break; }
  }
  // (5) VEHICLE: synthetic hovering platform on a circle.
  const prov = {
    pos: { x: 0, y: 0, z: 0 } as Vec3,
    vel: { x: 0, y: 0, z: 0 } as Vec3,
    quat: { x: 0, y: 0, z: 0, w: 1 } as Quat,
    angVel: { x: 0, y: 0.05, z: 0 } as Vec3,
  };
  const W = 0.05, A = 800, ALT = R + 1200;
  const drivePlatform = (t: number): void => {
    prov.pos.x = A * Math.cos(W * t);
    prov.pos.y = ALT;
    prov.pos.z = A * Math.sin(W * t);
    prov.vel.x = -A * W * Math.sin(W * t);
    prov.vel.y = 0;
    prov.vel.z = A * W * Math.cos(W * t);
    const vl = Math.hypot(prov.vel.x, prov.vel.z);
    quatFromFrameInto(prov.vel.x / vl, prov.vel.y, prov.vel.z / vl,
      prov.pos.x / Math.hypot(A, ALT), prov.pos.y / Math.hypot(A, ALT),
      prov.pos.z / Math.hypot(A, ALT), prov.quat);
  };
  drivePlatform(0);
  kcc.teleportAbs(prov.pos.x, prov.pos.y + 2, prov.pos.z,
    prov.vel.x, prov.vel.y, prov.vel.z);
  kcc.attachVehicle(prov);
  let maxErr = 0;
  for (let i = 1; i <= 600; i++) {
    drivePlatform(i / 60);
    kcc.integrateTick(1 / 60);
    // Independent compose check.
    const q = prov.quat;
    const tx = 2 * (q.y * 2 - q.z * 0);
    void tx;
    const off = { x: 0, y: 2, z: 0 };
    const ex = q.w * (2 * (q.y * off.z - q.z * off.y)) +
      (q.y * (2 * (q.x * off.y - q.y * off.x)) -
        q.z * (2 * (q.z * off.x - q.x * off.z))) + off.x;
    const ey = q.w * (2 * (q.z * off.x - q.x * off.z)) +
      (q.z * (2 * (q.y * off.z - q.z * off.y)) -
        q.x * (2 * (q.x * off.y - q.y * off.x))) + off.y;
    const ez = q.w * (2 * (q.x * off.y - q.y * off.x)) +
      (q.x * (2 * (q.z * off.x - q.x * off.z)) -
        q.y * (2 * (q.y * off.z - q.z * off.y))) + off.z;
    const err = Math.max(
      Math.abs(kcc.absPos.x - (prov.pos.x + ex)),
      Math.abs(kcc.absPos.y - (prov.pos.y + ey)),
      Math.abs(kcc.absPos.z - (prov.pos.z + ez)));
    if (err > maxErr) maxErr = err;
  }
  S.vehicleErr = maxErr;
  drivePlatform(10);
  const dvx = prov.vel.x + (prov.angVel.y * (kcc.absPos.z - prov.pos.z));
  const dvy = prov.vel.y;
  const dvz = prov.vel.z - (prov.angVel.y * (kcc.absPos.x - prov.pos.x));
  kcc.detachVehicle();
  S.detachDv = Math.hypot(
    kcc.absVel.x - dvx, kcc.absVel.y - dvy, kcc.absVel.z - dvz);
  kcc.teleportSurface(FLAT_SITE.x, FLAT_SITE.y, FLAT_SITE.z);
  const pass = zeroOk && Math.abs(S.rcsDv - 2.4) < 0.05 &&
    Math.abs(S.budgetUsed - 2.4) < 0.05 && Math.abs(S.yawAngle - 0.5) < 0.01 &&
    surfaceTick >= 0 && landed && S.vehicleErr < 1e-9 && S.detachDv < 1e-6 &&
    kcc.integrity.nanEvents === 0;
  return {
    pass,
    detail:
      `ZERO-G entered 1 tick beyond the 30 km gravity range (Spec 02.3 fade); ` +
      `RCS burn Δv ${S.rcsDv.toFixed(3)} m/s, propellant ${(S.budgetUsed).toFixed(3)} m/s ` +
      `of the 25 m/s pack; attitude yaw ${S.yawAngle.toFixed(3)} rad (finite frame ` +
      `rotation); deorbit fell back through the hysteresis band (SURFACE at tick ` +
      `${surfaceTick}) and landed analytically; VEHICLE parented compose tracked the ` +
      `moving platform to ${S.vehicleErr.toExponential(1)} m over 600 ticks, detach ` +
      `velocity inherited to ${S.detachDv.toExponential(1)} m/s; NaN events 0.`,
  };
}

  const S = suite.slope;
  // Engineered steep field (deterministic; swapped + restored inside this
  // synchronous block — the renderer never samples mid-swap).
  const STEEP: TerrainParams = {
    name: 'M1E engineered slopes',
    radius: 5000, seed: 777,
    continentFreq: 1.2, continentAmp: 40,
    maskFreq: 1.05, mountainFreq: 11, mountainAmp: 1300,
    detailFreq: 40, detailAmp: 6,
  };
  initTerrainField(STEEP);
  const rand = mulberry32(0x51ope5 as unknown as number || 0x5109e5);
  const moderate = scanFor((_d, s) => s > 18 && s < 28, 20000, rand);
  const steep = scanFor((_d, s) => s > 52 && s < 68, 20000, rand);
  const cliff = scanFor((_d, s) => s > 70, 20000, rand);
  const results: string[] = [];
  let ok = true;


  const downhillAt = (d: Vec3, out: Vec3): void => {
    terrainNormalInto(d.x, d.y, d.z, _scanN);
    const gm = 9.81;
    _vA.x = -gm * d.x; _vA.y = -gm * d.y; _vA.z = -gm * d.z;
    const dn = _vA.x * _scanN.x + _vA.y * _scanN.y + _vA.z * _scanN.z;
    out.x = _vA.x - dn * _scanN.x;
    out.y = _vA.y - dn * _scanN.y;
    out.z = _vA.z - dn * _scanN.z;
    const l = Math.hypot(out.x, out.y, out.z) || 1;
    out.x /= l; out.y /= l; out.z /= l;
  };


  // (a) Moderate slope: clean climb + clean descent (step-up + snap-down).
  if (moderate !== null) {
    kcc.teleportSurface(moderate.x, moderate.y, moderate.z);
    downhillAt(moderate, _vB);
    kcc.fwd.x = -_vB.x; kcc.fwd.y = -_vB.y; kcc.fwd.z = -_vB.z;  // face uphill
    const inp = kcc.input;
    inp.moveF = 1; inp.moveR = 0; inp.sprint = false; inp.crouch = false;
    inp.turnRate = 0; inp.jump = false;
    const alt0 = kcc.telemetry.altMSL;
    let groundedAll = true, maxSlide = 0;
    for (let i = 0; i < 150; i++) {
      kcc.integrateTick(1 / 60);
      if (!kcc.grounded) groundedAll = false;
      if (kcc.telemetry.slideSpeed > maxSlide) maxSlide = kcc.telemetry.slideSpeed;
    }
    S.climbGain = kcc.telemetry.altMSL - alt0;
    S.slideMax = maxSlide;
    const slopeRad = (moderate.slopeDeg * Math.PI) / 180;
    const expected = 4 * Math.sin(slopeRad) * 2.5;
    const climbOk = groundedAll && S.climbGain > 0.7 * expected && maxSlide < 0.05;
    // Descent (snap-down holds grounding).
    inp.moveF = -1;
    let descGrounded = true;
    for (let i = 0; i < 150; i++) {
      kcc.integrateTick(1 / 60);
      if (!kcc.grounded) descGrounded = false;
    }
    ok = ok && climbOk && descGrounded;
    results.push(
      `${moderate.slopeDeg.toFixed(0)}° slope: climbed ${S.climbGain.toFixed(1)} m ` +
      `uphill in 2.5 s (expected ≈ ${expected.toFixed(1)} m, slide ${maxSlide.toFixed(3)} m/s, ` +
      `grounded 150/150), descended with snap-down holding grounding ` +
      `${descGrounded ? '150/150' : 'FAILED'}`);
  } else { ok = false; results.push('moderate site not found'); }


  // (b) Steep slope: slide initiates, accelerates downhill; uphill sprint blocked.
  if (steep !== null) {
    kcc.teleportSurface(steep.x, steep.y, steep.z);
    const inp = kcc.input;
    inp.moveF = 0; inp.moveR = 0; inp.sprint = false; inp.turnRate = 0; inp.jump = false;
    let t30 = -1, vMid = 0, vEnd = 0;
    const sx = kcc.pLocal.x, sy = kcc.pLocal.y, sz = kcc.pLocal.z;
    downhillAt(steep, _vB);
    for (let i = 0; i < 120; i++) {
      kcc.integrateTick(1 / 60);
      if (t30 < 0 && kcc.telemetry.slideSpeed > 0.5) t30 = i;
      if (i === 60) vMid = kcc.telemetry.slideSpeed;
    }
    vEnd = kcc.telemetry.slideSpeed;
    const dx = kcc.pLocal.x - sx, dy = kcc.pLocal.y - sy, dz = kcc.pLocal.z - sz;
    const downDot = dx * _vB.x + dy * _vB.y + dz * _vB.z;
    // Uphill sprint into the slope (blocked by the dual step rule).
    kcc.teleportSurface(steep.x, steep.y, steep.z);
    kcc.fwd.x = -_vB.x; kcc.fwd.y = -_vB.y; kcc.fwd.z = -_vB.z;
    inp.moveF = 1; inp.sprint = true;
    const ux0 = kcc.pLocal.x, uy0 = kcc.pLocal.y, uz0 = kcc.pLocal.z;
    for (let i = 0; i < 90; i++) kcc.integrateTick(1 / 60);
    const ddx = kcc.pLocal.x - ux0, ddy = kcc.pLocal.y - uy0, ddz = kcc.pLocal.z - uz0;
    S.uphillNet = -(ddx * _vB.x + ddy * _vB.y + ddz * _vB.z); // along UPHILL
    const slideOk = t30 >= 0 && t30 <= 30 && vEnd > vMid && downDot > 0.9 * Math.hypot(dx, dy, dz);
    const blockOk = S.uphillNet < 0.3;
    ok = ok && slideOk && blockOk;
    results.push(
      `${steep.slopeDeg.toFixed(0)}° slope: slide initiated at tick ${t30}, accelerated ` +
      `{vEnd.toFixed(1)} m/s downhill (displacement 100% downhill: ` +
      `${(downDot / (Math.hypot(dx, dy, dz) || 1)).toFixed(2)}); uphill SPRINT net progress ` +
      `${S.uphillNet.toFixed(2)} m in 1.5 s (unimpeded would be 12 m) — dual step rule blocks`);
  } else { ok = false; results.push('steep site not found'); }


  // (c) Cliff face: fully blocked, penetration-free.
  if (cliff !== null) {
    kcc.teleportSurface(cliff.x, cliff.y, cliff.z);
    downhillAt(cliff, _vB);
    kcc.fwd.x = -_vB.x; kcc.fwd.y = -_vB.y; kcc.fwd.z = -_vB.z;
    const inp = kcc.input;
    inp.moveF = 1; inp.sprint = true;
    const cx0 = kcc.pLocal.x, cy0 = kcc.pLocal.y, cz0 = kcc.pLocal.z;
    for (let i = 0; i < 90; i++) kcc.integrateTick(1 / 60);
    const cdx = kcc.pLocal.x - cx0, cdy = kcc.pLocal.y - cy0, cdz = kcc.pLocal.z - cz0;
    S.cliffNet = -(cdx * _vB.x + cdy * _vB.y + cdz * _vB.z);
    const cliffOk = S.cliffNet < 0.5 && kcc.integrity.minAGL > -0.05;
    ok = ok && cliffOk;
    results.push(
      `${cliff.slopeDeg.toFixed(0)}° cliff: net uphill progress ${S.cliffNet.toFixed(2)} m ` +
      `over 1.5 s of sprint into the face (min AGL ${kcc.integrity.minAGL.toFixed(3)} m — ` +
      `penetration-free)`);
  } else { ok = false; results.push('cliff site not found'); }


  S.ok = ok;
  // RESTORE the canonical field before returning to the frame loop.
  initTerrainField(TEST_PLANET);
  kcc.teleportSurface(FLAT_SITE.x, FLAT_SITE.y, FLAT_SITE.z);
  return { pass: ok, detail: results.join(' · ') + ' (engineered field swapped + restored inside one synchronous block).' };
}


function runHeadlessSuite(): void {
  if (suite.started) return;
  suite.started = true;
  const results: Partial<Record<TestKey, TestResult>> = {};
  results['face-walk'] = runFaceWalk();
  results['coriolis'] = runCoriolisJump();
  results['state-machine'] = runStateMachine();
  results['zero-gc'] = runZeroGcBurn();
  results['slope-step'] = runSlopeStep();
  publishSuite({ results });
}

  active: false, elapsed: 0, rebases0: 0, recv0: 0, geoMin: Number.POSITIVE_INFINITY,
  geoMax: 0, offsetErrMax: 0, writeThroughMisses: 0, frames: 0,

let deltaLatticeOk = true;
core.onRebase((ev) => {

    deltaLatticeOk = false;
  }

function finishTrek(): void {
  trek.active = false;
  const rebases = core.stats.rebaseCount - trek.rebases0;
  const received = pool.counters.received - trek.recv0;
  const geoConst = trek.geoMin === trek.geoMax && trek.geoMin > 0;
  const localsOk = core.stats.focusMaxLocalPostTick <= 1032;
  const pass = rebases >= 3 && received >= 3 && geoConst && localsOk &&
    deltaLatticeOk && trek.offsetErrMax <= 1e-9 && trek.writeThroughMisses === 0;
  const results = { ...suiteState.results } as Record<TestKey, TestResult>;
  results['integration'] = {
    pass,
    detail:
      `20 s live trek at 4× (80 s sim, ~4.8 km absolute incl. the 52 m/s transport): ` +
      `${rebases} origin shifts (every Δ an exact multiple of 256, f32-exact); ` +
      `${received} chunks streamed through the M1C pool; renderer geometries constant ` +
      `at ${trek.geoMin} (min === max); astronaut f32 locals max ` +
      `${core.stats.focusMaxLocalPostTick.toFixed(0)} m ≤ 1,032; spinning terrain group ` +
      `tracked −O to ${trek.offsetErrMax.toExponential(0)} m; entity write-through ` +
      `verbatim (${trek.writeThroughMisses} misses). Zero locked files modified — the ` +
      `M1C pool rides the spin purely as a parent-group transform.`,
  };
  publishSuite({ results, done: true });
  const all = (Object.values(results) as TestResult[]).every((r) => r?.pass);
  console.log(`[Milestone1E] acceptance ${all ? 'PASSED' : 'FAILED'}`);
}

const _boomDir = new THREE.Vector3();
const _f64q: Quat = { x: 0, y: 0, z: 0, w: 1 };

const frameStats = { frames: 0, ms: 0 };
type Phase = 'WARMUP' | 'HEADLESS' | 'TREK' | 'DONE';
const script = { phase: 'WARMUP' as Phase, warm: 0, headlessArmed: false };


function Scene() {
  const { scene } = useThree();
  const primed = useRef(2);


  useEffect(() => {
    pool.attach(spinGroup as unknown as THREE.Scene);
    adapter.bind(ASTRO_ID, astroMesh);
    pool.primeAll();
    primed.current = 2;
    return () => { adapter.unbind(ASTRO_ID); };
  }, [scene]);


  useFrame((state, delta) => {
    if (primed.current > 0) {
      primed.current--;
      if (primed.current === 0) pool.unprimeAll();
    }
    const dt = delta > 0.1 ? 0.1 : delta;
    const nowMs = performance.now();
    let ts = 1;


    /* -- phase machine ---------------------------------------------------- */
    if (script.phase === 'WARMUP') {
      script.warm += dt;
      // Autopilot: slow walk in circles (warms steering + neighboring chunks).
      kcc.input.moveF = 0.55; kcc.input.moveR = 0;
      kcc.input.sprint = false; kcc.input.crouch = false;
      kcc.input.turnRate = 0.5;
      if ((pool.activeCount() >= 45 && script.warm > 3.5) || script.warm > 8) {
        script.phase = 'HEADLESS';
      }
    } else if (script.phase === 'HEADLESS') {
      if (!script.headlessArmed) {
        script.headlessArmed = true;   // label renders this frame; block next
      } else {
        runHeadlessSuite();            // ~2–5 s synchronous (rows R1–R5)
        kcc.teleportSurface(T1_START.x, T1_START.y, T1_START.z);
        trek.rebases0 = core.stats.rebaseCount;
        trek.recv0 = pool.counters.received;
        trek.active = true;
        script.phase = 'TREK';
        trek.elapsed = 0;
      }
    } else if (script.phase === 'TREK') {
      ts = 4;
      trek.elapsed += dt;
      // Scripted trek: sprint along the corner great circle.
      const p = kcc.pLocal;
      const l = Math.hypot(p.x, p.y, p.z);
      _pf.x = GC_C.y * (p.z / l) - GC_C.z * (p.y / l);
      _pf.y = GC_C.z * (p.x / l) - GC_C.x * (p.z / l);
      _pf.z = GC_C.x * (p.y / l) - GC_C.y * (p.x / l);
      const tl = Math.hypot(_pf.x, _pf.y, _pf.z);
      const a = signedAngleAbout(kcc.fwd.x, kcc.fwd.y, kcc.fwd.z,
        _pf.x / tl, _pf.y / tl, _pf.z / tl, kcc.up.x, kcc.up.y, kcc.up.z);
      kcc.input.moveF = 1; kcc.input.moveR = 0;
      kcc.input.sprint = true; kcc.input.crouch = false;
      kcc.input.turnRate = Math.max(-2, Math.min(2, a * 3));
      if (trek.elapsed >= 20) finishTrek(), (script.phase = 'DONE');
    } else {
      readUserInput();
    }


    /* -- look input (exact per-frame deltas) -------------------------------- */
    if (script.phase === 'DONE' && !userPaused) {
      const yaw = mouseDX * SENS, pitch = -mouseDY * SENS;
      mouseDX = 0; mouseDY = 0;
      if (camFirstPerson) {
        kcc.autoTurnEnabled = false;
        kcc.lookYawDelta = yaw;
        cam.pitch = Math.max(-1.45, Math.min(1.45, cam.pitch + pitch));
      } else {
        kcc.autoTurnEnabled = true;
        cam.yawOffset -= yaw;   // orbit the camera, not the character
        cam.yawOffset = ((cam.yawOffset + Math.PI) % (Math.PI * 2) + Math.PI * 2)
          % (Math.PI * 2) - Math.PI;
        cam.pitch = Math.max(-1.2, Math.min(1.2, cam.pitch + pitch));
      }
    } else { mouseDX = 0; mouseDY = 0; }


    /* -- (1) astronaut physics + (2) M1A core, in lockstep ------------------ */
    if (!userPaused) {
      kcc.update(dt * ts, 5);
      core.advance(dt * ts);
    }


    /* -- (3)(4)(5) render extract ------------------------------------------- */
    adapter.update();
    const o = core.getOrigin();
    spinGroup.position.set(-o.x, -o.y, -o.z);
    spinQuatInto(kcc.spinPhase, _f64q);
    _qSpin.set(_f64q.x, _f64q.y, _f64q.z, _f64q.w);
    spinGroup.quaternion.copy(_qSpin);
    kcc.frameQuatInto(_f64q);
    _qFrame.set(_f64q.x, _f64q.y, _f64q.z, _f64q.w);
    _qWorld.copy(_qSpin).multiply(_qFrame);
    astroMesh.quaternion.copy(_qWorld);


    if (trek.active) {
      trek.frames++;
      const offErr = Math.abs(spinGroup.position.x + o.x) +
        Math.abs(spinGroup.position.y + o.y) + Math.abs(spinGroup.position.z + o.z);
      if (offErr > trek.offsetErrMax) trek.offsetErrMax = offErr;
      if (astroState.absPos.x !== kcc.absPos.x ||
        astroState.absPos.y !== kcc.absPos.y ||
        astroState.absPos.z !== kcc.absPos.z) trek.writeThroughMisses++;
    }


    /* -- (6) camera ---------------------------------------------------------- */
    const lp = astroState.localPosF32;
    const t = kcc.telemetry;
    _camUp.set(0, 1, 0).applyQuaternion(_qWorld);
    if (camFirstPerson) {
      _qPitch.setFromAxisAngle(new THREE.Vector3(0, 0, 1).applyQuaternion(_qWorld)
        .normalize(), cam.pitch);
      state.camera.quaternion.copy(_qWorld).multiply(_qPitch);
      _camPos.set(0, t.eyeHeight, 0).applyQuaternion(_qWorld);
      state.camera.position.set(lp[0] + _camPos.x, lp[1] + _camPos.y, lp[2] + _camPos.z);
    } else {
      // TP orbit: offset back from the character, yaw about up, pitch about right.
      _boomDir.set(-1, 0, 0).applyQuaternion(_qWorld);   // behind
      rotateAboutAxisInto(_boomDir.x, _boomDir.y, _boomDir.z,
        _camUp.x, _camUp.y, _camUp.z, -cam.yawOffset, _pf);
      _boomDir.set(_pf.x, _pf.y, _pf.z);
      const rx = _boomDir.y * _camUp.z - _boomDir.z * _camUp.y;
      const ry = _boomDir.z * _camUp.x - _boomDir.x * _camUp.z;
      const rz = _boomDir.x * _camUp.y - _boomDir.y * _camUp.x;
      rotateAboutAxisInto(_boomDir.x, _boomDir.y, _boomDir.z, rx, ry, rz,
        -cam.pitch, _pf);
      let dist = cam.dist;
      // Boom terrain clamp (4 samples, planet-frame field evals).
      for (let s = 1; s <= 4; s++) {
        const f = (s / 4) * cam.dist;
        const wx = lp[0] + _pf.x * f + _camUp.x * t.eyeHeight;
        const wy = lp[1] + _pf.y * f + _camUp.y * t.eyeHeight;
        const wz = lp[2] + _pf.z * f + _camUp.z * t.eyeHeight;
        const ax = wx + o.x, ay = wy + o.y, az = wz + o.z;
        const r = Math.hypot(ax, ay, az);
        if (r < R + 900 + 64) {
          rotateByQuatConjInto(_f64q, ax / r, ay / r, az / r, _pf2);
          if (r - (R + terrainHeight(_pf2.x, _pf2.y, _pf2.z)) < 0.3) {
            dist = Math.min(dist, f - 0.3);
            break;
          }
        }
      }
      if (dist < 1.2) dist = 1.2;
      _camPos.set(lp[0] + _camUp.x * t.eyeHeight + _pf.x * dist,
        lp[1] + _camUp.y * t.eyeHeight + _pf.y * dist,
        lp[2] + _camUp.z * t.eyeHeight + _pf.z * dist);
      state.camera.position.copy(_camPos);
      _camTgt.set(lp[0] + _camUp.x * 1.4, lp[1] + _camUp.y * 1.4, lp[2] + _camUp.z * 1.4);
      state.camera.up.copy(_camUp);
      state.camera.lookAt(_camTgt);
    }


    /* -- (7) M1C streaming with the PLANET-FRAME camera ---------------------- */
    rotateByQuatConjInto(_f64q, kcc.absPos.x, kcc.absPos.y, kcc.absPos.z, _pf);
    camPlanet.x = _pf.x; camPlanet.y = _pf.y; camPlanet.z = _pf.z;
    if (!userPaused) {
      updateController();
      pool.pump();
    }


    /* -- metrics + throttled telemetry ---------------------------------------- */
    if (script.phase !== 'HEADLESS' || !script.headlessArmed) {
      const geo = state.gl.info.memory.geometries;
      if (primed.current === 0) {
        if (trek.active || script.phase === 'DONE' || script.phase === 'WARMUP') {
          if (geo < trek.geoMin) trek.geoMin = geo;
          if (geo > trek.geoMax) trek.geoMax = geo;
        }
      }
    }
    const frameMs = delta * 1000;
    frameStats.frames++; frameStats.ms += frameMs;
    if (frameStats.frames >= 30) {
      tele.fps = (frameStats.frames * 1000) / Math.max(frameStats.ms, 1e-6);
      tele.frameMs = frameStats.ms / frameStats.frames;
      frameStats.frames = 0; frameStats.ms = 0;
    }
    if (nowMs - lastTeleMs >= 100) {
      lastTeleMs = nowMs;
      tele.mode = t.mode; tele.grounded = t.grounded; tele.crouched = t.crouched;
      tele.relSpeed = t.relSpeed; tele.slideSpeed = t.slideSpeed;
      tele.transport = t.transportSpeed; tele.absSpeed = t.absSpeed;
      tele.altMSL = t.altMSL; tele.altAGL = t.altAGL; tele.slope = t.slopeDeg;
      tele.face = t.currentFace;
      tele.upX = t.upX; tele.upY = t.upY; tele.upZ = t.upZ;
      tele.gX = t.gravX; tele.gY = t.gravY; tele.gZ = t.gravZ; tele.gMag = t.gravMag;
      tele.rcs = t.rcsBudget; tele.spin = t.spinPhase; tele.day = t.dayFraction;
      tele.originX = o.x; tele.originY = o.y; tele.originZ = o.z;
      tele.rebases = core.stats.rebaseCount;
      tele.localMax = core.stats.focusMaxLocalPostTick;
      tele.active = pool.activeCount(); tele.pending = pool.pendingCount();
      tele.inFlight = pool.inFlightTotal();
      tele.geometries = state.gl.info.memory.geometries;
      tele.heapMB = heapApi !== null ? heapApi.usedJSHeapSize / 1048576 : 0;
      tele.phase = script.phase;
      tele.version++;
      teleListeners.forEach((l) => l());
    }
  });


  return <primitive object={sceneRoot} />;
}
