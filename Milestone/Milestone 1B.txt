## PHASE 1 — REASONING & EDGE-CASE ANALYSIS


### 1.1 Closed-Form Analytic Orbit Purity


**The cost argument.** At 60 Hz, a 60-day fast-forward is 5,184,000 s × 60 = **311,040,000 integration steps** per body — a hard wall. Worse, with the game-scaled Earth period (T = 8,821 s, derived below), one orbit is only ~147 ticks, so any integrator (even symplectic) accumulates per-orbit energy error that compounds over the ~588 orbits a 60-day jump sweeps. Closed-form evaluation is **O(1) at any t**: `P(t = 0)`, `P(t = 60 days)`, and `P(t = −10 years)` each cost ~40 flops. This is also why 30× (or 1000×) macro time cannot melt the CPU (Spec 00.2): the rail cost is **independent of time scale** — one evaluation per tick regardless.


**The correctness argument.** An integrated trajectory approximates the orbit; a closed-form evaluation *is* the orbit. The position is always exactly on the ellipse by construction — zero secular drift, no accumulation of any kind, ever. And purity is what makes reversibility provable (see §1.5): `P(t)` is a deterministic mathematical function of a single double, not the terminal state of a step sequence.


### 1.2 Two-Tier Time Decoupling


The core runs **one** fixed tick (dt = 1/60 s wall) and advances **two** clocks inside it:


- `simTime` (macro): `simTime += dt × macroTimeScale` — drives Kepler rails only. Default 30× per catalog `timeScale: 30`.
- `stats.simTime` (micro, M1A contract preserved): `+= dt` at exactly 1× — drives entity integration now, the Rapier bubble later.


Desynchronization is impossible by construction: both clocks are written by a single writer (the tick), derived from the same dt, and there is no async path anywhere. PAUSE (timeScale = 0) freezes the orbits while the 60 Hz micro clock keeps running — the exact decoupling Spec 00.2 mandates, and the harness displays both clocks diverging to prove it. Time *jumps* (`fastForward`/`reverse`/`setSimTime`) touch **only** `simTime`, evaluate the rails synchronously, and re-extract celestial f32 locals — entity state is untouched because entities are tick-driven, not time-driven. This also gives the M1G save system its contract: serialize `simTime` as a double, restore it with `setSimTime`, and the macro universe is bit-identical.


### 1.3 Parent-Child Hierarchies with Zero Per-Tick Allocation


The trick is that **no vector scratch is needed at all** — only two stack scalars. At boot, each body precomputes:


1. A **topologically ordered** dense array (parents strictly before children — boot-time topo pass; catalog order already satisfies it, but the constructor verifies rather than assumes).
2. The **perifocal basis vectors** `p̂`, `q̂` in the Sun frame — the standard Z-up basis `Rz(Ω)·Rx(i)·Rz(ω)` relabeled to the Y-up world (Z-up `(x,y,z)` → Y-up `(x, z, −y)`), so the identity elements yield `p̂ = (1,0,0)`, `q̂ = (0,0,−1)` and prograde motion is counter-clockwise from +Y. No per-tick matrix, no trig for attitude.
3. `semiMinor = a·√(1−e²)` — computed once.


Per tick, per body, the entire hierarchy composition is scalar arithmetic writing into the body's **own pre-allocated** `absPos`:


```
M   = wrapAngle(M0 + n·t)          // scalar
E   = (e < 1e-12) ? M : solveKeplerE(M, e)   // scalar
px  = a·(cos E − e);  py = b·sin E            // two scalars — THE scratch
ox  = px·p̂.x + py·q̂.x   (oy, oz likewise)     // scalar
absPos.x = parent.absPos.x + ox               // parent already evaluated (topo order)
```


No temporaries, no arrays, no iteration allocation (indexed loops only — Map iteration allocates an iterator object and stays banned). The M1B acceptance suite enforces this with an **identity canary**: the exact `absPos` / `localPosF32` object references captured before a 20,000-tick burn must be the *same references* after it.


### 1.4 Kepler's Third Law & Scaling — and the Sun μ Derivation


**Moons** are fully determined by spec law: μ_host = parent's μ = `g_real × R_game²` (Section 02.3). Earth: 9.81 × 5000² = 245,250,000 (the spec's own worked example) → Moon T = 2π√(38850³/μ) = **3,072 s**. I verified every catalog `gravityRange` and `portalDist` reproduces exactly from the Section 02.2 formulas (e.g., Earth max(6·5000, 1.3·38850) = 50,505 ✓; Jupiter 1.5 × 99,841.2 = 149,761.8 ✓) — confirming the catalog is internally consistent with my reading, and where formula regeneration and catalog disagree by rounding (Mercury radius 3105.7 vs. 3094), **the catalog wins as canon**.


**Planets** need μ_sun, which the catalog does not supply (`surfaceGravity: 0` is the *gameplay* gravity — `gravityRange: 0` confirms the Sun exerts no in-game gravity field; this milestone's Phase 1.4 nevertheless mandates T = 2π√(a³/μ_host)). **Decision (flagged for your review):** apply Section 02.3's own formula to the Sun using its real surface gravity and artistic radius: **μ_sun = 274 m/s² × 20,000² = 1.096×10¹¹ m³/s².** Consequences (all computed exactly at boot in `celestialData.ts`):


| Body | a (m) | T | Body | a (m) | T |
|---|---|---|---|---|---|
| Mercury | 376,200 | 4,381 s (1.22 h) | Saturn | 1,860,000 | 48,139 s (13.4 h) |
| Venus | 512,400 | 6,963 s (1.93 h) | Uranus | 2,634,000 | 81,144 s (22.5 h) |
| **Earth** | 600,000 | **8,821 s (2.45 h)** | Neptune | 3,290,000 | 113,254 s (31.5 h) |
| Mars | 741,600 | 12,122 s (3.37 h) | Pluto | 3,770,000 | 138,927 s (38.6 h) |
| Jupiter | 1,368,600 | 30,392 s (8.44 h) | Moon↔Earth | 38,850 | 3,072 s (51 min) |


At the default 30×, Earth completes an orbit in **4.9 minutes of play** (watchable), the Moon orbits Earth in 102 s (lively), and at 1000× the whole system visibly spins — a usable system map. A single μ_sun means Kepler's Third Law holds *exactly* across all planets: (T_p/T_e)² = (a_p/a_e)³ — asserted in the acceptance suite to 1e-12 relative. One constant to tune, one line to change.


**Retrograde handling:** Triton's catalog fact `"orbit": "Retrograde"` is implemented as a signed mean motion (n < 0) — mathematically equivalent to i = 180°, cleaner to evaluate. Venus's `"rotation": "Retrograde"` is *spin*, not orbit — correctly ignored by rails (spin belongs to the parented-state compose of a later milestone).


### 1.5 The Reversibility Invariant (proof)


1. **Purity:** `P(t) = F(elements; t)` is deterministic and side-effect-free (writes only its own state buffers). Same input double → same output bits, because IEEE 754 arithmetic and libm `sin/cos/sqrt` are deterministic per platform.
2. **Solver determinism:** Newton–Raphson from a fixed starter (`E₀ = M + e·sin M` for e < 0.8, `±π` above) with a fixed exit (`|ΔE| < 1e-15`) executes the identical iterate sequence for identical `(M, e)` — no data-dependent allocation, no early-exit nondeterminism. So `F` is a function in the strictest sense.
3. **The anchor argument:** from `t₀ = 0`, `fastForward(60)` computes `0 + 5,184,000 = 5,184,000` **exactly** (0 + x is exact; 60×86400 is an exact integer), and `reverse(60)` computes `5,184,000 − 5,184,000 = 0` **exactly**. `simTime` returns to the *same double*, so `F(0)` re-evaluates bit-identically. Round-trip error = **exactly 0 m**, beating the 1e-9 m bound by construction. The suite asserts this from the zero anchor (the acceptance criterion as written) *and* additionally proves exact restoration from a non-zero anchor (98,765.4321 s) via saved-double `setSimTime` — error also exactly 0.
4. **The honest general bound:** from an *arbitrary* anchor, `±D` arithmetic round-trips to within 1 ulp of `simTime` (~9.3×10⁻¹⁰ s at 5.18×10⁶ s), i.e. ≤ a·|n|·ulp ≈ **2×10⁻⁷ m** for Earth — below gameplay relevance but above 1e-9 m; that is why exact restoration is via snapshot (`setSimTime` with the saved double), which is precisely the contract the M1G save/load will use. Both behaviors are documented in code.


### 1.6 Test-Design Edge Cases (surfaced during the trace)


- **Bit-matching the independent reference:** the T1 reference evaluator must not merely agree numerically but use *identical expression shapes* (`wrapAngle(M0 + n·t)`, `a·(cosE − e)` with e = 0 exact, `parent.x + (px·p̂.x + py·q̂.x)`) so the comparison is bitwise — expected max error **0.0 m**, tolerance 1e-9 m as a guard. Note `a·√(1−0)·sinE = a·sinE` exactly, and `x + 0` / `0×c` are exact, so the fast path and the reference coincide bit-for-bit.
- **Angle wrapping:** `M = M0 + n·t` reaches ~3,700 rad after 60 days; `sin/cos` of unwrapped angles would cost ~10⁻¹³ rad. All angles are reduced to (−π, π] via `M − 2π·round(M/2π)` *deterministically* before solving, on both the rail and reference paths.
- **The elliptical solver needs teeth even though catalog orbits are circular** (Section 03 supplies single distances → e = 0). The suite probes `solveKeplerE` directly at e ∈ {0, 0.2, 0.45, 0.72} × 11 anomalies and asserts the Kepler residual |E − e·sinE − M| ≤ 1e-12 rad.
- **Zero-GC proof in-browser is bounded:** there is no portable GC API, so T4 layers three defenses: (1) the identity canary (hard fail if any state object or buffer is ever reallocated), (2) `performance.memory` heap delta across a 20,000-tick synchronous burn with a 1 MB threshold (nothing else can run mid-burn — it's inside one frame callback), (3) the static audit documented in `tick()`/`evaluate()`. Full V8 allocation profiling is M1C's acceptance test, where the mandate gets its real instrument.
- **f32 locals for celestials are extracted at step 8, after any rebase** — never during the macro step — so a jump/rebase/tick interleave can never publish stale locals. At system scale, f32's ulp at Pluto's 3.77×10⁶ m is 0.25 m: irrelevant for map-view rendering (the 3-camera/impostor regimes that make this rigorous are M1F).
- **ID precedence:** the unified `getLocalPositionF32(id)` checks M1A entities first, then celestials — the M1A `FloatingOriginAdapter` therefore binds planets and moons *with zero changes*, and the M1A harness contract survives intact.
- **M1A regression is proven, not assumed:** suite row 5 re-runs the entire M1A acceptance (2,000 m/s dummy flight, 9 rebases, Δ = 4×256 exact, local bound ≤ 1,024 m) against the *updated* core, with macro ticking concurrently.
- **Vis-viva speeds** are evaluated per tick (`v = √(μ(2/r − 1/a))`, exact for e = 0) so the telemetry panel's "orbital speeds" are physical, not cached.

```typescript
 *  ORBITAL TYPES — PURE FLOAT64 CELESTIAL DOMAIN
```

### 2. `src/core/orbit/KeplerRail.ts`


```typescript
/**
 * ============================================================================
 *  KEPLER RAIL — CLOSED-FORM ORBITAL EVALUATION (PURE FLOAT64, ZERO-GC)
 *  Milestone 1B · Spec 00.2 (macro rails), 01.1 step 1, 02.6 (time scales)
 * ============================================================================
 *  P = F(elements; simTime) is a pure closed-form function:
 *   - O(1) cost at ANY t (t = 0, t = +60 days, t = −10 years) — which is why
 *     30x (or 1000x) macro time costs exactly one evaluation per tick.
 *   - Positions lie exactly on the orbit by construction: zero energy drift,
 *     no integrator, no accumulation.
 *   - Deterministic bit-for-bit: same simTime double -> same position bits.
 *     This is the foundation of the 1B reversibility acceptance proof.
 *
 *  ZERO-GC AUDIT of evaluate(): scalar arithmetic, field writes into
 *  boot-allocated state objects, indexed for-loops over a dense array.
 *  The only "scratch" needed is two stack scalars (px, py) — the perifocal
 *  basis, semi-minor axis, and parent links are all boot-precomputed.
 *  Allocation count per evaluation: 0.
 */


import type { CelestialConfig, CelestialState } from './types';


export const TWO_PI = Math.PI * 2;


/**
 * Reduce an angle to (−π, π]. Deterministic (pure IEEE arithmetic) — the
 * rail and any independent reference that uses the identical expression
 * produce bit-identical results. Angles reach ~3.7e3 rad after a 60-day
 * jump; reducing before sin/cos keeps trig arguments well-conditioned.
 */
export function wrapAngle(M: number): number {
  return M - TWO_PI * Math.round(M / TWO_PI);
}


/**
 * Solve Kepler's equation  M = E − e·sin(E)  for the eccentric anomaly E.
 * Newton–Raphson with the classical two-branch starter. Deterministic
 * iterate sequence for identical (M, e) — a hard requirement for the
 * reversibility proof (same input -> same output bits).
 *
 * Domain: elliptical orbits, e ∈ [0, ~0.95], M pre-wrapped to (−π, π].
 * Exit: |ΔE| < 1e-15 (double-precision floor for these magnitudes) or 24
 * iterations (boot-domain verification asserts residual ≤ 1e-12 rad).
 */
export function solveKeplerE(M: number, e: number): number {
  let E = e < 0.8 ? M + e * Math.sin(M) : (M >= 0 ? Math.PI : -Math.PI);
  for (let k = 0; k < 24; k++) {
    const f = E - e * Math.sin(E) - M;
    const fp = 1 - e * Math.cos(E);
    const dE = f / fp;
    E -= dE;
    if (dE < 1e-15 && dE > -1e-15) {
      break;
    }
  }
  return E;
}


/** Kepler's Third Law: T = 2π·√(a³/μ) — the mandated period derivation. */
export function computeOrbitalPeriod(a: number, mu: number): number {
  return TWO_PI * Math.sqrt((a * a * a) / mu);
}


/**
 * Mean motion magnitude: |n| = √(μ/a³). Algebraically identical to 2π/T
 * (and computed without the double rounding of the 2π round-trip).
 * The caller applies the retrograde sign.
 */
export function meanMotion(mu: number, a: number): number {
  return Math.sqrt(mu / (a * a * a));
}


export class KeplerRail {
  /** Topologically ordered: parents strictly before children. */
  private readonly _states: CelestialState[] = [];
  private readonly _byId = new Map<string, CelestialState>();


  constructor(configs: readonly CelestialConfig[]) {
    // Boot-time topological insertion. Restart-scan: each pass places the
    // first body whose parent is resolved (or null); a full pass with no
    // placement means a cycle or unknown parent id -> hard error. O(n²)
    // worst case, n = 17, boot path only.
    const pending: CelestialConfig[] = configs.slice();
    while (pending.length > 0) {
      let placed = false;
      for (let i = 0; i < pending.length; i++) {
        const cfg = pending[i];
        if (cfg.parentId === null || this._byId.has(cfg.parentId)) {
          this._addBody(cfg);
          pending.splice(i, 1);
          placed = true;
          break;
        }
      }
      if (!placed) {
        throw new Error(
          '[KeplerRail] celestial hierarchy contains a cycle or an unknown parentId',
        );
      }
    }
  }


  get states(): readonly CelestialState[] {
    return this._states;
  }


  getState(id: string): CelestialState | null {
    return this._byId.get(id) ?? null;
  }


  /* -----------------------------------------------------------------------
   * Boot-time body construction (allocation sanctioned here ONLY).
   * -------------------------------------------------------------------- */
  private _addBody(cfg: CelestialConfig): void {
    let parentIndex = -1;
    if (cfg.parentId !== null) {
      const parent = this._byId.get(cfg.parentId);
      if (parent === undefined) {
        throw new Error(`[KeplerRail] unknown parent '${cfg.parentId}'`);
      }
      parentIndex = this._states.indexOf(parent);
    }


    const state: CelestialState = {
      config: cfg,
      parentIndex,
      absPos: { x: 0, y: 0, z: 0 },
      localPosF32: new Float32Array(3), // the ONE per-body buffer allocation
      orbitalSpeed: 0,
      basisP: { x: 1, y: 0, z: 0 },
      basisQ: { x: 0, y: 0, z: -1 },
      semiMinor: 0,
    };


    if (cfg.orbit !== null) {
      const o = cfg.orbit;
      // Standard perifocal basis (Z-up convention):
      //   p̂ = Rz(Ω)·Rx(i)·Rz(ω)·(1,0,0),  q̂ = ...·(0,1,0)
      const cO = Math.cos(o.Omega), sO = Math.sin(o.Omega);
      const ci = Math.cos(o.i), si = Math.sin(o.i);
      const cw = Math.cos(o.omega), sw = Math.sin(o.omega);
      const pzx = cO * cw - sO * sw * ci;
      const pzy = sO * cw + cO * sw * ci;
      const pzz = sw * si;
      const qzx = -cO * sw - sO * cw * ci;
      const qzy = -sO * sw + cO * cw * ci;
      const qzz = cw * si;
      // Relabel Z-up -> Y-up world: (x, y, z)_zu -> (x, z, −y)_yu.
      // Identity elements yield p̂ = (1,0,0), q̂ = (0,0,−1) EXACTLY:
      // prograde motion is counter-clockwise viewed from +Y.
      state.basisP.x = pzx; state.basisP.y = pzz; state.basisP.z = -pzy;
      state.basisQ.x = qzx; state.basisQ.y = qzz; state.basisQ.z = -qzy;
      state.semiMinor = o.a * Math.sqrt(1 - o.e * o.e);
    }


    this._states.push(state);
    this._byId.set(cfg.id, state);
  }


  /* -----------------------------------------------------------------------
   * THE MACRO EVALUATION — P(elements; t), zero allocation.
   *
   * Expression shapes here are load-bearing for the acceptance suite's
   * bit-exact comparison: the independent reference evaluator deliberately
   * mirrors them (wrapAngle(M0 + n·t), a·(cosE − e), parent + (px·p̂ + py·q̂)).
   * Do not "simplify" these lines without updating the reference.
   * -------------------------------------------------------------------- */
  evaluate(simTime: number): void {
    const states = this._states;
    const count = states.length;
    for (let k = 0; k < count; k++) {
      const s = states[k];
      const o = s.config.orbit;


      if (o === null) {
        // Fixed body (the Sun): root -> origin; otherwise pinned to parent.
        const parent = s.parentIndex >= 0 ? states[s.parentIndex] : null;
        if (parent !== null) {
          s.absPos.x = parent.absPos.x;
          s.absPos.y = parent.absPos.y;
          s.absPos.z = parent.absPos.z;
        } else {
          s.absPos.x = 0; s.absPos.y = 0; s.absPos.z = 0;
        }
        s.orbitalSpeed = 0;
        continue;
      }


      // Mean anomaly (wrapped for conditioning; deterministic).
      const M = wrapAngle(o.M0 + o.n * simTime);
      // Eccentric anomaly — exact for circular orbits (e < 1e-12 fast path:
      // E = M, and a·(cosE − 0) === a·cosE exactly).
      let E: number;
      if (o.e < 1e-12) {
        E = M;
      } else {
        E = solveKeplerE(M, o.e);
      }
      const cosE = Math.cos(E);
      const sinE = Math.sin(E);


      // Perifocal plane coordinates — the only scratch: two scalars.
      const px = o.a * (cosE - o.e);
      const py = s.semiMinor * sinE;


      // World-frame offset via the boot-precomputed basis.
      const P = s.basisP;
      const Q = s.basisQ;
      const ox = px * P.x + py * Q.x;
      const oy = px * P.y + py * Q.y;
      const oz = px * P.z + py * Q.z;


      // Hierarchical composition — parent is already evaluated this pass
      // (topological order). For planets the parent is the Sun at exactly
      // (0,0,0), so `0 + ox === ox` keeps the composition bit-exact.
      const parent = s.parentIndex >= 0 ? states[s.parentIndex] : null;
      if (parent !== null) {
        s.absPos.x = parent.absPos.x + ox;
        s.absPos.y = parent.absPos.y + oy;
        s.absPos.z = parent.absPos.z + oz;
      } else {
        s.absPos.x = ox;
        s.absPos.y = oy;
        s.absPos.z = oz;
      }


      // Vis-viva speed: v = √(μ(2/r − 1/a)), r = a(1 − e·cosE).
      // Exact for e = 0 (r === a, 2/a − 1/a === 1/a in IEEE arithmetic).
      const r = o.a * (1 - o.e * cosE);
      s.orbitalSpeed = Math.sqrt(o.muHost * (2 / r - 1 / o.a));
    }
```

```typescript
   * THE CANONICAL FIXED TICK — dt = 1/60 s, allocation-free.
   * ===================================================================== */


  tick(): void {
    const entities = this._entities;
    const count = entities.length;
    const origin = this._origin;


    // -- STEP 1: MACRO UPDATE (Float64, closed-form Kepler rails) ----------
    // One evaluation per tick regardless of time scale (Spec 00.2): the
    // 30x (or 1000x) macro clock cannot melt the CPU because the rails are
    // analytic functions of simTime, never integrated.
    this._simTime += FIXED_DT * this._macroTimeScale;
    this._rail.evaluate(this._simTime);


    // -- (a) INTEGRATE — Float64: P <- P + V·dt ----------------------------
    for (let i = 0; i < count; i++) {
      const e = entities[i];
      if (e.dynamic) {
        e.absPos.x += e.velocity.x * FIXED_DT;
        e.absPos.y += e.velocity.y * FIXED_DT;
        e.absPos.z += e.velocity.z * FIXED_DT;
      }
    }


    // -- (b) BUBBLE REFRESH TEST — focus entity vs the 1,024 m trigger ----
    const focus = this._focus();
    if (focus !== null) {
      sub(focus.absPos, origin, this._focusLocal);
      if (shouldRebase(this._focusLocal)) {
        // -- (c) CONDITIONAL REBASE — exact 256 m lattice Δ ---------------
        calculateOrigin(focus.absPos, this._candidateOrigin);
        const ev = this._rebaseEvent;
        copy(ev.oldOrigin, origin);
        ev.delta.x = this._candidateOrigin.x - origin.x;
        ev.delta.y = this._candidateOrigin.y - origin.y;
        ev.delta.z = this._candidateOrigin.z - origin.z;
        copy(ev.newOrigin, this._candidateOrigin);
        copy(origin, this._candidateOrigin);
        this.stats.rebaseCount++;
        ev.count = this.stats.rebaseCount;
        this._emitRebase();
      }
    }


    // -- (d) RENDER EXTRACT — p_local_f32 = Float32(P_abs − O) ------------
    // Entities first (M1A), then celestials. Celestial locals are extracted
    // HERE — after any rebase above — never during the macro step, so no
    // interleave can publish stale locals.
    for (let i = 0; i < count; i++) {
      const e = entities[i];
      e.localPosF32[0] = e.absPos.x - origin.x;
      e.localPosF32[1] = e.absPos.y - origin.y;
      e.localPosF32[2] = e.absPos.z - origin.z;
    }
    const celestials = this._rail.states;
    for (let i = 0; i < celestials.length; i++) {
      const c = celestials[i];
      c.localPosF32[0] = c.absPos.x - origin.x;
      c.localPosF32[1] = c.absPos.y - origin.y;
      c.localPosF32[2] = c.absPos.z - origin.z;
    }


    if (focus !== null) {
      const lp = focus.localPosF32;
      const m = Math.max(Math.abs(lp[0]), Math.abs(lp[1]), Math.abs(lp[2]));
      if (m > this.stats.focusMaxLocalPostTick) {
        this.stats.focusMaxLocalPostTick = m;
      }
    }


    this.stats.tickCount++;
    this.stats.simTime += FIXED_DT; // MICRO clock — always 1× (M1A contract)
  }


  private _focus(): EntityState | null {
    if (this._focusId === null) {
      return null;
    }
    const i = this._entityIndex.get(this._focusId);
    return i === undefined ? null : this._entities[i];
  }
}
```

```tsx
/* ---------------------------------------------------------------------------
 * INDEPENDENT CLOSED-FORM REFERENCE (test-only; NOT KeplerRail.evaluate)
 *
 * Expression shapes deliberately MIRROR the rail (wrapAngle(M0 + n·t),
 * a·(cosE − e) with e = 0 exact, semiMinor·sinE with b = a exactly,
 * parent + (px·p̂ + py·q̂)) so the T1 comparison is BITWISE. Independence
 * is in the code path: explicit circular formulas, its own hierarchy walk
 * over the same topo-ordered array, no solver call, no rail evaluation.
 * ------------------------------------------------------------------------- */


function referencePosition(
  state: CelestialState,
  t: number,
  ref: Float64Array,
): void {
  const i3 = BODIES.indexOf(state) * 3; // test path only — indexOf fine here
  const o = state.config.orbit;
  const parentX = state.parentIndex >= 0 ? ref[state.parentIndex * 3] : 0;
  const parentY = state.parentIndex >= 0 ? ref[state.parentIndex * 3 + 1] : 0;
  const parentZ = state.parentIndex >= 0 ? ref[state.parentIndex * 3 + 2] : 0;
  if (o === null) {
    ref[i3] = parentX;
    ref[i3 + 1] = parentY;
    ref[i3 + 2] = parentZ;
    return;
  }
  const M = wrapAngle(o.M0 + o.n * t);
  const px = o.a * (Math.cos(M) - o.e);
  const py = state.semiMinor * Math.sin(M);
  const P = state.basisP;
  const Q = state.basisQ;
  ref[i3] = parentX + (px * P.x + py * Q.x);
  ref[i3 + 1] = parentY + (px * P.y + py * Q.y);
  ref[i3 + 2] = parentZ + (px * P.z + py * Q.z);
}

    s,
    abs: s.absPos,
    loc: s.localPosF32,
  }));
  const mem = (performance as unknown as PerfMemoryHook).memory;
  const heapBefore = mem !== undefined ? mem.usedJSHeapSize : -1;
  for (let i = 0; i < BURN_TICKS; i++) {
    core.tick(); // synchronous burn — nothing else can run mid-burn
  }
  const heapAfter = mem !== undefined ? mem.usedJSHeapSize : -1;
  let identityOk = true;
  for (let i = 0; i < canary.length; i++) {
    const c = canary[i];
    if (
      BODIES[c.k] !== c.s ||
      c.s.absPos !== c.abs ||
      c.s.localPosF32 !== c.loc
    ) {
      identityOk = false;
      break;
    }
  }
  const heapDelta = heapBefore >= 0 ? heapAfter - heapBefore : -1;
  const heapOk = heapBefore < 0 || heapDelta <= HEAP_LIMIT;
  results['zero-gc'] = {
    pass: identityOk && heapOk,
    detail:
      `${BURN_TICKS.toLocaleString()} continuous ticks @30× (10,000 s macro): ` +
      `state identities preserved ${identityOk ? '17/17' : 'FAILED'}; ` +
      `heap Δ ${heapDelta >= 0 ? `${heapDelta.toLocaleString()} B` : 'N/A'}` +
      `${mem !== undefined ? '' : ' (performance.memory unavailable — identity canary stands; full V8 profiling is M1C)'} ` +
      `— limit ${HEAP_LIMIT.toLocaleString()} B.`,
  };


  /* ---- T5: M1A regression ---------------------------------------------- */
  core.registerEntity('m1a-ship', {
    absPos: { x: 0, y: 0, z: 0 },
    velocity: { x: 2000, y: 0, z: 0 },
    dynamic: true,
  });
  core.setFocusEntity('m1a-ship');
  const rebase0 = core.stats.rebaseCount;
  let ticksUsed = 0;
  while (
    core.getAbsPosition('m1a-ship') !== null &&
    (core.getAbsPosition('m1a-ship') as { x: number }).x < 10000 &&
    ticksUsed < 400
  ) {
    core.tick();
    ticksUsed++;
  }
  const shipPos = core.getAbsPosition('m1a-ship');
  const rebaseDelta = core.stats.rebaseCount - rebase0;
  const maxLocal = core.stats.focusMaxLocalPostTick;
  core.unregisterEntity('m1a-ship');
  const t5pass =
    shipPos !== null &&
    shipPos.x >= 10000 &&
    rebaseDelta === 9 &&
    maxLocal <= 1024 + 1e-9;
  results['m1a-regression'] = {
    pass: t5pass,
    detail:
      `2,000 m/s dummy flight with macro ticking concurrently: P.x = ` +
      `${shipPos !== null ? shipPos.x.toFixed(3) : 'n/a'} m after ${ticksUsed} ticks; ` +
      `${rebaseDelta} origin shifts (each Δ = 4×256 exact); max focus local ` +
      `${maxLocal.toFixed(2)} m ≤ 1,024 — M1A contract intact on the updated core.`,
  };


  /* ---- restore a clean live state & publish ---------------------------- */
  core.setSimTime(0);
  const allPass = (
    ['closed-form', 'reversibility', 'parenting', 'zero-gc', 'm1a-regression'] as TestKey[]
  ).every((k) => results[k]?.pass === true);
  const elapsed = performance.now() - t0;
  console.log(
    `[Milestone1B] acceptance ${allPass ? 'PASSED' : 'FAILED'} in ${elapsed.toFixed(1)} ms — ` +
      `maxPosErr={errRoundTrip.toExponential(1)}m ` +
      `restore={identityOk ? 'OK' : 'FAIL'} ` +
      `heapDelta={rebaseDelta}`,
  );
  publishSuite({ started: true, results, done: true });
}

function mulberry32(seed: number): () => number {
  let a = seed >>> 0;
  return () => {
    a = (a + 0x6d2b79f5) | 0;
    let t = Math.imul(a ^ (a >>> 15), 1 | a);
    t = (t + Math.imul(t ^ (t >>> 7), 61 | t)) ^ t;
    return ((t ^ (t >>> 14)) >>> 0) / 4294967296;
  };
}


function makeStarLayer(
  rand: () => number,
  count: number,
  radius: number,
  size: number,
  color: number,
  opacity: number,
): THREE.Points {
  const positions = new Float32Array(count * 3);
  for (let i = 0; i < count; i++) {
    const u = rand() * 2 - 1;
    const theta = rand() * Math.PI * 2;
    const r = Math.sqrt(1 - u * u);
    positions[i * 3] = Math.cos(theta) * r * radius;
    positions[i * 3 + 1] = u * radius;
    positions[i * 3 + 2] = Math.sin(theta) * r * radius;
  }
  const geometry = new THREE.BufferGeometry();
  geometry.setAttribute('position', new THREE.BufferAttribute(positions, 3));
  const material = new THREE.PointsMaterial({
    color, size, sizeAttenuation: false, transparent: true, opacity,
    fog: false, depthWrite: false,
  });
  return new THREE.Points(geometry, material);
}


function makeGlowSprite(scale: number): THREE.Sprite {
  const canvas = document.createElement('canvas');
  canvas.width = 128;
  canvas.height = 128;
  const ctx = canvas.getContext('2d') as CanvasRenderingContext2D;
  const grad = ctx.createRadialGradient(64, 64, 0, 64, 64, 64);
  grad.addColorStop(0, 'rgba(255, 236, 190, 1)');
  grad.addColorStop(0.25, 'rgba(255, 210, 130, 0.55)');
  grad.addColorStop(1, 'rgba(255, 190, 100, 0)');
  ctx.fillStyle = grad;
  ctx.fillRect(0, 0, 128, 128);
  const sprite = new THREE.Sprite(
    new THREE.SpriteMaterial({
      map: new THREE.CanvasTexture(canvas),
      color: 0xffe7b0,
      transparent: true,
      blending: THREE.AdditiveBlending,
      depthWrite: false,
    }),
  );
  sprite.scale.set(scale, scale, 1);
  return sprite;
}


/** Circle of radius a in the XZ plane (matches the orbit-plane mapping). */
function makeOrbitRing(a: number, color: number, opacity: number): THREE.LineLoop {
  const SEGMENTS = 256;
  const positions = new Float32Array(SEGMENTS * 3);
  for (let k = 0; k < SEGMENTS; k++) {
    const ang = (k / SEGMENTS) * TWO_PI;
    positions[k * 3] = a * Math.cos(ang);
    positions[k * 3 + 1] = 0;
    positions[k * 3 + 2] = -a * Math.sin(ang);
  }
  const geometry = new THREE.BufferGeometry();
  geometry.setAttribute('position', new THREE.BufferAttribute(positions, 3));
  return new THREE.LineLoop(
    geometry,
    new THREE.LineBasicMaterial({ color, transparent: true, opacity }),
  );
}


function makeBodyMesh(id: string): THREE.Mesh {
  const d = DISPLAY[id];
  return new THREE.Mesh(
    new THREE.SphereGeometry(d.radius, 26, 18),
    new THREE.MeshStandardMaterial({
      color: d.color, roughness: 0.92, metalness: 0,
    }),
  );
}


interface BuiltScene {
  root: THREE.Group;
  nodeById: Record<string, THREE.Object3D>;
  stars: THREE.Points;
}


function buildSystemScene(): BuiltScene {
  const root = new THREE.Group();
  const nodeById: Record<string, THREE.Object3D> = {};


  const rand = mulberry32(0x1b5eed1a);
  const stars = makeStarLayer(rand, 1500, 8.5e6, 2, 0xaec6dc, 0.75);
  root.add(stars);
  root.add(new THREE.AmbientLight(0x2a3b52, 1.1));


  // Sun: emissive sphere + decay-0 point light (uniform map lighting) + glow.
  const sunGroup = new THREE.Group();
  sunGroup.add(
    new THREE.Mesh(
      new THREE.SphereGeometry(DISPLAY.sun.radius, 32, 24),
      new THREE.MeshBasicMaterial({ color: 0xffd98c }),
    ),
  );
  sunGroup.add(new THREE.PointLight(0xfff3dd, 2.4, 0, 0));
  sunGroup.add(makeGlowSprite(320000));
  root.add(sunGroup);
  nodeById.sun = sunGroup;


  for (let i = 0; i < BODIES.length; i++) {
    const s = BODIES[i];
    if (s.config.type === 'star') {
      continue;
    }
    if (s.config.parentId === null) {
      // Planet: adapter-bound group holding the sphere, an optional Saturn
      // ring, and its moons' orbit rings (rings follow the moving planet).
      const group = new THREE.Group();
      group.add(makeBodyMesh(s.config.id));
      if (s.config.id === 'saturn') {
        const ring = new THREE.Mesh(
          new THREE.RingGeometry(
            DISPLAY.saturn.radius * 1.45,
            DISPLAY.saturn.radius * 2.3,
            64,
          ),
          new THREE.MeshBasicMaterial({
            color: 0xcbb489, transparent: true, opacity: 0.5,
            side: THREE.DoubleSide,
          }),
        );
        ring.rotation.x = -Math.PI / 2;
        group.add(ring);
      }
      for (let m = 0; m < BODIES.length; m++) {
        if (BODIES[m].config.parentId === s.config.id) {
          const mo = BODIES[m].config.orbit;
          if (mo !== null) {
            group.add(makeOrbitRing(mo.a, MOON_TRAIL_COLOR, 0.5));
          }
        }
      }
      root.add(group);
      nodeById[s.config.id] = group;
    } else {
      // Moon: standalone adapter-bound mesh at absolute local coordinates.
      const mesh = makeBodyMesh(s.config.id);
      root.add(mesh);
      nodeById[s.config.id] = mesh;
    }
  }


  // Heliocentric orbit trails.
  for (let i = 0; i < BODIES.length; i++) {
    const s = BODIES[i];
    if (s.config.parentId === null && s.config.orbit !== null) {
      root.add(makeOrbitRing(s.config.orbit.a, TRAIL_COLOR, 0.42));
    }
  }


  return { root, nodeById, stars };
}

let suiteAutoStarted = false;


function Scene() {
  // Lazy ref: stable across StrictMode double-render of this instance.
  const builtRef = useRef<BuiltScene | null>(null);
  if (builtRef.current === null) {
    builtRef.current = buildSystemScene();
  }
  const built = builtRef.current;
  const { gl, camera } = useThree();


  useEffect(() => {
    // Bind all 17 celestials through the UNCHANGED M1A adapter (the core's
    // unified entity->celestial lookup resolves them). Idempotent —
    // StrictMode double-mount safe.
    for (let i = 0; i < BODIES.length; i++) {
      adapter.bind(BODIES[i].config.id, built.nodeById[BODIES[i].config.id]);
    }
    const el = gl.domElement;
    const onDown = (ev: PointerEvent): void => {
      cam.dragging = true;
      cam.lastX = ev.clientX;
      cam.lastY = ev.clientY;
      el.setPointerCapture(ev.pointerId);
    };
    const onMove = (ev: PointerEvent): void => {
      if (!cam.dragging) {
        return;
      }
      const dx = ev.clientX - cam.lastX;
      const dy = ev.clientY - cam.lastY;
      cam.lastX = ev.clientX;
      cam.lastY = ev.clientY;
      cam.theta -= dx * 0.005;
      cam.phi = clamp(cam.phi - dy * 0.005, 0.03, Math.PI - 0.03);
    };
    const onUp = (ev: PointerEvent): void => {
      cam.dragging = false;
      try {
        el.releasePointerCapture(ev.pointerId);
      } catch {
        /* pointer already released */
      }
    };
    const onWheel = (ev: WheelEvent): void => {
      ev.preventDefault();
      cam.dist = clamp(
        cam.dist * Math.exp(ev.deltaY * 0.0011),
        minDistFor(cam.trackId),
        CAM_MAX_DIST,
      );
    };
    el.addEventListener('pointerdown', onDown);
    el.addEventListener('pointermove', onMove);
    el.addEventListener('pointerup', onUp);
    el.addEventListener('wheel', onWheel, { passive: false });
    return () => {
      el.removeEventListener('pointerdown', onDown);
      el.removeEventListener('pointermove', onMove);
      el.removeEventListener('pointerup', onUp);
      el.removeEventListener('wheel', onWheel);
      for (let i = 0; i < BODIES.length; i++) {
        adapter.unbind(BODIES[i].config.id);
      }
    };
  }, [gl, built]);


  useFrame((state, delta) => {
    // (1) Fixed-step simulation: macro rails advance dt·timeScale, micro
    //     entities at 1× — both inside core.advance's governor (≤5 substeps,
    //     shed-don't-dilate per Spec 02.6).
    core.advance(delta);


    // (2) Render extract — single downstream pass over all bound objects
    //     (entities + celestials). Zero allocation.
    adapter.update();


    // (3) Camera: target tracks the focused body's f32 local; position is
    //     target + spherical offset on preallocated Vector3s (zero alloc).
    const trackState = RAIL.getState(cam.trackId) ?? BODIES[0];
    const lp = trackState.localPosF32;
    camTarget.set(lp[0], lp[1], lp[2]);
    const sinPhi = Math.sin(cam.phi);
    const cosPhi = Math.cos(cam.phi);
    camPos.set(
      camTarget.x + cam.dist * sinPhi * Math.cos(cam.theta),
      camTarget.y + cam.dist * cosPhi,
      camTarget.z + cam.dist * sinPhi * Math.sin(cam.theta),
    );
    camera.position.copy(camPos);
    camera.lookAt(camTarget);


    // (4) Distant stars follow the camera (parallax ~ 0 at infinity).
    built.stars.position.copy(camera.position);


    // (5) Auto-run the acceptance suite once, after a short warmup.
    if (!suiteAutoStarted && state.clock.elapsedTime > 0.75) {
      suiteAutoStarted = true;
      publishSuite({ started: true });
      runSuite();
    }


    // (6) Throttled telemetry (≤10 Hz) — the only per-frame object build,
    //     at the sanctioned UI boundary.
    maybePublishTelemetry(performance.now());
  });


  return <primitive object={built.root} />;
}

function fmtSimTime(t: number): string {
  const sign = t < 0 ? '−' : '';
  const at = Math.abs(t);
  const d = Math.floor(at / DAY_SECONDS);
  let rem = at - d * DAY_SECONDS;
  const h = Math.floor(rem / 3600);
  rem -= h * 3600;
  const m = Math.floor(rem / 60);
  const s = rem - m * 60;
  const p2 = (v: number): string => (v < 10 ? `0{v}`);
  return `{d}d {p2(m)}:${s.toFixed(1).padStart(4, '0')}`;
}
```
