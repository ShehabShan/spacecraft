# Milestone 1D — Deep Analysis & Implementation


M1A/1B/1C are locked and untouched — no locked file is modified; the flight dynamics plug into the existing core through the documented entity write-through and a single scene-group offset. One constant had to be *derived* rather than chosen (β_q, from the spec's dive gate) — the full derivation is §1.5 and it is flagged in-code.

## PHASE 1 — REASONING & EDGE-CASE ANALYSIS


### 1.1 Barometric Density, Layering, and Dynamic Pressure


**Derivation.** Hydrostatic equilibrium `dP/dh = −ρg` with the ideal gas law `P = ρ·R_s·T` gives, for an isothermal layer, `dρ/dh = −ρ/H_s` with `H_s = R_s·T/g`. Real Earth: `287·288/9.81 ≈ 8,423 m`. The compressed game world uses `H_s = 1,200 m` and `ρ₀ = 1.225 kg/m³` (Lead-specified), i.e. the same ~7× compression factor as the catalog's linear scale — internally consistent. Per **Spec 02.4 (Math is Law)** the engine evaluates exactly `ρ(alt) = ρ₀·exp(−max(alt,0)/H_s)`: C∞-smooth, strictly monotone, decaying to hard vacuum asymptotically (`ρ(24 km) = 2.5×10⁻⁹ kg/m³`). The catalog's `atmosphereHeight = 8,000 m` (6.67 scale heights, `ρ = 0.13%` of surface) is used as the *mode boundary* (exo-atmospheric flag, boost rules, fog), **not** as a density cutoff — so density itself never has a discontinuity. Temperature (for the sound speed only, not for ρ) lapses at 6.5 K/km to a 210 K floor: `a(h) = √(γR_sT)`, 340.3 m/s at sea level → 308 m/s at 8 km.


**Dynamic pressure at the envelope.** `q = ½ρv²`: at 2,000 m/s — sea level: **2.45 MPa** (≈24 atm); at 4 km: 87 kPa; at 8 km: 3.1 kPa. This is why an ungoverned hypersonic entry is structurally absurd and why the spec restricts speed by the **structural curve** `v_safe(alt) = √(a_struct/(β_q·ρ(alt)))` — the speed at which quadratic drag deceleration equals the airframe limit `a_struct = 90 m/s²`:


| alt | ρ (kg/m³) | v_safe | | alt | ρ | v_safe |
|---|---|---|---|---|---|---|
| 8 km | 0.00156 | 4,253 m/s | | 2 km | 0.152 | 430 m/s |
| 6 km | 0.00826 | 1,845 m/s | | 1 km | 0.532 | **230 m/s** |
| 4 km | 0.0437 | 802 m/s | | 0 | 1.225 | 151 m/s |


**Why the exponential map (Spec 02.4) and not explicit integration.** Explicit Euler on `dv = −k·v` (with `k = β_qρ|v| + β_lρ`) applies the factor `1 − k·Δt`, which goes **negative** (velocity reverses through the air) when `k·Δt > 2` and diverges beyond that. Our own envelope peaks at `k·Δt ≈ 0.13` (sea level, 2,000 m/s) — survivable *here* — but the envelope cannot be bounded across future bodies (dense gas giants), and the spec's law is the exact map: `v_rel_new = v_rel·exp(−k·dt)`. The map is **A-stable, sign-preserving, and monotone for all k, dt > 0** — the factor is in (0,1], so velocity can never overshoot, bounce, or reverse. It is also the *exact* flow for frozen k; for the quadratic term the continuum solution is `1/(1+x)` and `e⁻ˣ ≤ 1/(1+x)` — the map always decays at least as fast as physics, i.e. it errs on the safe side.


### 1.2 Drag & Lift Vector Decomposition


Body frame (right-handed, quaternion `q`): **+X forward, +Y up, +Z = X×Y (left)**. World axes: `f̂ = q⊗x̂⊗q*`, `û = q⊗ŷ⊗q*` (computed by the rotation formula `v' = v + 2w(q_v×v) + 2q_v×(q_v×v)`).


**Drag (Spec 02.4, the law).** With `v_rel = v − v_atm` (transport-relative, §below):
- `k = β_q·ρ(alt)·|v_rel| + β_l·ρ(alt)`, `v_rel ← v_rel·e^(−k·dt)`, `v ← v_atm + v_rel`.
- Equivalence to the classical form: `F_d = −½ρ|v|v·C_dA = −m·β_q·ρ|v|v` ⇒ `β_q = C_d·A/(2m)` (0.35·22/2400 ≈ our 3.2×10⁻³). The map is applied to the full vector — isotropic axial damping; induced drag is folded into β (documented; no extra terms added to the spec's k).


**Lift (perpendicular, work-free).** AoA from body-frame relative wind: `v̂_b = q*⊗v̂_rel⊗q`, `α = −asin(v̂_b·ŷ_b)` (velocity below the nose ⇒ positive α ⇒ lift along body-up). `C_l(α) = C_lα·α·stall(α)` with a C¹ stall rolloff beyond `α_crit = 0.30 rad`. Direction: `n̂_lift = normalize(û − (û·v̂_rel)v̂_rel)` — the component of body-up perpendicular to the relative wind. Force: `F_l = ½ρ|v|²·C_l·S·n̂_lift`. **Energy proof:** `F_l·v_rel = ½ρ|v|²C_lS·(n̂·v̂) = 0` by construction — lift curves the trajectory without ever changing speed, which is what keeps the energy accounting in §1.4 clean.


### 1.3 Control Damping & Stability at 2,000 m/s


The attitude loop is **rate-command with exact exponential tracking**: `ω_{n+1} = ω_cmd + (ω_n − ω_cmd)·e^(−c·Δt)`, with `c = 3.0 + 10·min(q/20 kPa, 4) ∈ [3, 43] rad/s`. Properties:


1. **No oscillatory mode exists.** The homogeneous discrete pole is `e^(−cΔt) ∈ (0,1)` for *every* c, Δt > 0 — the system is overdamped by construction; control oscillation at high q is mathematically impossible, not just tuned away. (An explicit `ω += (τ − cω)dt` would require `c·Δt < 2` — satisfiable here, but frame-rate-conditional; the exact map is uniform with the drag philosophy.)
2. **High q makes control better, not worse.** c grows with dynamic pressure (control surfaces bite, aerodynamic damping rises): response time constant `1/c` *shrinks* from 333 ms to 23 ms as q ramps — precisely the physical effect that keeps 2,000 m/s flight crisp.
3. Δt is bounded by the 5-substep governor (Spec 02.6) — but stability does not depend on that bound.


### 1.4 Floating Origin Integration (no energy drift, no rebase artifacts)


- **The ship is kinematic in the f64 core (Spec 01.3):** the flight controller owns `pos/vel` in absolute Float64 and writes through to the M1A entity (`dynamic: false`). There is **no Rapier body to translate** in M1D, so the M1A phantom-momentum path (bodies nudged by an inexact Δ) doesn't even exist; and when it does (future milestones), M1A's power-of-two lattice proof guarantees `fround(Δ) === Δ`.
- **Velocity is a free vector.** Rebasing translates the origin only; velocity is never touched. The render side applies the *same exact −Δ in the same frame* to one scene group (terrain), while the ship mesh reads fresh f32 locals from the core — so across a rebase tick all relative geometry, the camera, and the rendered image are bit-identical (the M1A doctrine, now with real flight dynamics underneath it).
- **Energy accounting.** The tick is an operator splitting: (i) **exact dissipative flow** for drag — `d|v_rel|²/dt = −2k|v_rel|² ≤ 0`, monotone, no numerical energy creation; (ii) **symplectic (semi-implicit Euler) kick-drift** for the conservative + control part — backward-error analysis bounds the energy error oscillation at O(Δt²) with zero secular drift; (iii) **lift does zero work** (§1.2); (iv) thrust is bounded and smoothly faded to zero at the 2,000 m/s hard cap (no clamp discontinuity). Total energy is therefore monotone under drag and bounded under thrust — no drift accumulation over any horizon.
- **Precision.** |p| ≤ ~2×10⁴ m in f64 (ulp ≈ 2×10⁻¹² m); f32 locals stay ≤ 1,024 m by the M1A lattice, sampled post-tick — the M1A invariant is re-asserted by T5 with the flight dynamics driving it.


### 1.5 Edge Cases & the β_q Derivation (the designed constant)


**The dive gate → β_q.** For a vertical dive (h = altitude, v = speed), `dv/dh = β_q·ρ(h)·v`, hence `ln(v(h₂)/v(h₁)) = −β_q·ρ₀H_s·(e^(−h₂/H_s) − e^(−h₁/H_s))`. The spec gate (2,000 m/s entry, ≤ 400 m/s at 1,000 m) with `ρ₀H_s = 1,470`, `Δ = 0.4344` requires `β_q ≥ ln 5/638.5 = 2.52×10⁻³` — *without* gravity. Gravity adds ≤ ~+85 m/s over the exo-to-1 km phase, and the discrete map decays strictly faster than continuum (`e⁻ˣ ≤ 1/(1+x)`). Chosen: **β_q = 3.2×10⁻³** (27% margin) ⇒ predicted arrival ≈ 310–345 m/s ≤ 400 ✓; full-throttle sea-level equilibrium 107 m/s; the drag-limited sustained cruise near terrain comes out at ~300 m/s — which is *why* the spec's "400 m/s soft cruise" and "1,600 boost outside atmospheres" are the right numbers for a compressed planet (orbital speed at low altitude is `√(μ/r) ≈ 140 m/s`, so anything much faster is a ballistic zoom, not sustained flight — the aero can only hold ~1 g turns at 350 m/s, matching `C_l` capability).


**2D DDA sweep guarantee.** The sweep marches the tick's path (≤ 33.3 m at 2,000 m/s) across the **face-plane lattice** (2,048 cells/side ≈ 2.7–4.9 m arc) using per-axis next-boundary stepping (Amanatides–Woo, recomputed per sample so path curvature over a 5,000 m sphere is handled exactly), capped at a 4 m max gap. Detection: `AGL = r − (R + h(d̂)) < 3 m` ⇒ 20-step bisection ⇒ placement at `surface + 3 m` with the inward radial velocity component killed. **No-clip proof:** between consecutive samples the surface can rise at most `L·gap` (conservative terrain Lipschitz L = 1.2) while the ship's radius changes ≤ gap, so undetected mid-gap penetration ≤ `gap·(L+1) − clearance = 4·2.2 − 3 = 5.8 m` — and the *next* sample always detects it; every tick *ends* at or above the surface. Collision is pure main-thread math against the same f64 noise field the workers render — workers can be delayed indefinitely and nothing tunnels.


**Other edges handled in code:** atmosphere-entry onset is 2 g at 2,000 m/s (velocity continuous; ρ has no cutoff); gravity overshoots the 2,000 m/s mark by ~+0.2% during exo entry before drag recovers it (physical, displayed, and *not* clamped — the hard cap is enforced as a C¹ thrust fade on [1,880, 2,000], with an unreachable safety rescale at 2,025 for NaN-pathology only); NaN guard restores the last-good snapshot (Spec 00.2: nothing may NaN); face changes mid-sweep fall back to pure gap-marching; tab-stall delta clamping and 5-substep shedding per Spec 02.6; `v_atm = Ω×p` transport velocity implemented per Spec 02.4 (harness planet spin Ω = 0 so terrain stays M1C-static; the wind math is unit-verified in T1 with the spec's own 52 m/s equator example).

### 1. `src/core/physics/atmosphere.ts`


```typescript
/**
 * ============================================================================
 *  ATMOSPHERE — BAROMETRIC MODEL, SOUND SPEED, MACH, DYNAMIC PRESSURE
 *  Milestone 1D · Spec 02.4 (density law), 02.2 catalog (atmosphereHeight)
 * ============================================================================
 *  Pure core: no renderer/physics library imports. All Float64.
 *
 *  DENSITY (Math is Law — Spec 02.4):
 *      rho(alt) = rho0 * exp( -max(alt, 0) / H_scale )
 *  C∞-smooth, strictly monotone, decaying to vacuum asymptotically
 *  (rho(24 km) = 2.5e-9 kg/m^3). The catalog atmosphereHeight (8,000 m for
 *  Earth-scale) is a MODE boundary (exo-atmospheric flag / boost rules /
 *  fog), NOT a density cutoff — no discontinuity exists anywhere.
 *
 *  THERMODYNAMICS (sound speed only — the density law is isothermal by
 *  spec; a 6.5 K/km lapse feeding a(h) = sqrt(gamma·Rs·T) changes a(8 km)
 *  from 340 -> 308 m/s and differs from the exact non-isothermal density
 *  by < 2%, which the spec's exponential absorbs by design).
 *
 *  TRANSPORT WIND (Spec 02.4): v_rel is relative to the ROTATING atmosphere:
 *      v_atm = Ω × p     (planet spin about +Y; M1D harness uses Ω = 0 so
 *                         the M1C terrain mesh stays static; the math is
 *                         unit-verified against the spec's 52 m/s equator.)
 */


export interface AtmosphereProfile {
  name: string;
  /** Surface density, kg/m^3. */
  rho0: number;
  /** Scale height H_s, m. */
  scaleHeight: number;
  /** Catalog atmosphere height, m (mode boundary; density law extends past). */
  atmosphereHeight: number;
  /** Ratio of specific heats / specific gas constant (sound speed). */
  gamma: number;
  rSpecific: number;
  /** Thermodynamic model for a(h). */
  tempSeaLevel: number;
  lapseRate: number;   // K per m
  tempFloor: number;   // stratosphere floor, K
}


/** Earth-scale test atmosphere (R = 5,000 m planet, Spec 02.1/02.4). */
export const EARTHSCALE_ATMOSPHERE: AtmosphereProfile = {
  name: 'Earth-scale (M1D)',
  rho0: 1.225,
  scaleHeight: 1200,
  atmosphereHeight: 8000,
  gamma: 1.4,
  rSpecific: 287.05,
  tempSeaLevel: 288.15,
  lapseRate: 0.0065,
  tempFloor: 210.0,
};


/** Spec 02.4 density law. Zero allocation. */
export function densityAt(p: AtmosphereProfile, alt: number): number {
  if (alt <= 0) return p.rho0;
  return p.rho0 * Math.exp(-alt / p.scaleHeight);
}


/** Static temperature with lapse + floor, K. */
export function temperatureAt(p: AtmosphereProfile, alt: number): number {
  const t = p.tempSeaLevel - p.lapseRate * (alt > 0 ? alt : 0);
  return t < p.tempFloor ? p.tempFloor : t;
}


/** Speed of sound a(h) = sqrt(gamma · Rs · T), m/s. */
export function speedOfSoundAt(p: AtmosphereProfile, alt: number): number {
  return Math.sqrt(p.gamma * p.rSpecific * temperatureAt(p, alt));
}


/** Mach number of the AIR-relative speed. */
export function machNumber(p: AtmosphereProfile, alt: number, speedRel: number): number {
  return speedRel / speedOfSoundAt(p, alt);
}


/** Dynamic pressure q = ½·rho·v_rel², Pa. */
export function dynamicPressure(p: AtmosphereProfile, alt: number, speedRel: number): number {
  return 0.5 * densityAt(p, alt) * speedRel * speedRel;
}


/** Barometric pressure P = rho·Rs·T, Pa (HUD instrument). */
export function pressureAt(p: AtmosphereProfile, alt: number): number {
  return densityAt(p, alt) * p.rSpecific * temperatureAt(p, alt);
}


/** Mode boundary: above the catalog atmosphere height. */
export function isExoatmospheric(p: AtmosphereProfile, alt: number): boolean {
  return alt >= p.atmosphereHeight;
}


export interface Vec3Out { x: number; y: number; z: number; }


/**
 * Rotating-atmosphere transport velocity: v_atm = Ω × p with Ω = (0, Ω, 0).
 *      v_atm = ( Ω·p.z, 0, −Ω·p.x )
 * Equator check (spec example): Ω = 0.0104 rad/s, p = (5000,0,0)
 *      => |v_atm| = 52 m/s exactly.
 * Zero allocation.
 */
export function atmosphereVelocityInto(
  spinRadPerSec: number, px: number, py: number, pz: number, out: Vec3Out,
): Vec3Out {
  out.x = spinRadPerSec * pz;
  out.y = 0;
  out.z = -spinRadPerSec * px;
  return out;
}
```


### 2. `src/core/physics/aerodynamics.ts`


```typescript
/**
 * ============================================================================
 *  AERODYNAMICS — DRAG GOVERNOR, LIFT, STABILITY DAMPING (FLOAT64)
 *  Milestone 1D · Spec 01.3 (governor), 02.4 (exponential drag map)
 * ============================================================================
 *  Pure core. Zero allocation in every function.
 *
 *  THE GOVERNOR (Spec 01.3): the structural restriction curve
 *      v_safe(alt) = sqrt( a_struct / (betaQ · rho(alt)) )
 *  is the speed at which quadratic drag deceleration equals the airframe
 *  limit a_struct. Entering the atmosphere faster than the local v_safe,
 *  the exact exponential drag map mathematically forces the ship down onto
 *  the curve — no clamping, no discontinuity, no overshoot (see the map's
 *  A-stability proof in the M1D analysis).
 *
 *  DERIVED CONSTANT (flagged for Lead review — see M1D analysis §1.5):
 *  betaQ = 3.2e-3 m²/kg is not free: it is derived from the M1D acceptance
 *  gate (2,000 m/s entry, <= 400 m/s at 1,000 m altitude) via the vertical-
 *  dive integral  ln(v2/v1) = −betaQ·rho0·H·(e^(−h2/H) − e^(−h1/H)), which
 *  demands betaQ >= 2.52e-3 before gravity; 3.2e-3 carries 27% margin.
 *  Physical equivalence: betaQ = C_d·A / (2m) ≈ 0.35 · 22 m² / 2400 kg.
 */


export interface AeroParams {
  name: string;
  /** Ship mass, kg (lift/force conversions; the drag map is acceleration-based). */
  mass: number;
  /** Quadratic drag coefficient betaQ = C_d·A/(2m), m²/kg. DERIVED (see header). */
  betaQ: number;
  /** Linear (laminar) drag coefficient, Spec 02.4 k-form. */
  betaL: number;
  /** Structural deceleration limit for the v_safe curve, m/s². */
  aStruct: number;
  /** Wing area, m². */
  wingArea: number;
  /** Lift-curve slope, per rad. */
  clAlpha: number;
  /** Stall onset angle, rad. */
  alphaCrit: number;
  /** C¹ stall rolloff softness, rad. */
  stallSoftness: number;
  /** Attitude-loop damping: c = base + qScale·min(q/qRef, qClamp). */
  baseDamping: number;
  qDamping: number;
  qRef: number;      // Pa
  qClamp: number;
}


/** M1D test ship. */
export const SHIP_AERO: AeroParams = {
  name: 'M1D test ship',
  mass: 1200,
  betaQ: 3.2e-3,
  betaL: 0.012,
  aStruct: 90,
  wingArea: 14,
  clAlpha: 2.2,
  alphaCrit: 0.30,
  stallSoftness: 0.12,
  baseDamping: 3.0,
  qDamping: 10.0,
  qRef: 20000,
  qClamp: 4,
};


/** Governor curve v_safe(alt) = sqrt(a_struct / (betaQ·rho)). Infinity in vacuum. */
export function safeSpeedAt(aero: AeroParams, rho: number): number {
  if (rho <= 0) return Number.POSITIVE_INFINITY;
  return Math.sqrt(aero.aStruct / (aero.betaQ * rho));
}


/**
 * Spec 02.4 k-form:  k = betaQ·rho·|v_rel| + betaL·rho   [1/s]
 */
export function dragK(aero: AeroParams, rho: number, speedRel: number): number {
  return aero.betaQ * rho * speedRel + aero.betaL * rho;
}


/**
 * THE EXACT EXPONENTIAL MAP (Spec 02.4): v_rel_new = v_rel · exp(−k·dt).
 * A-stable, sign-preserving, monotone for ALL k, dt > 0 — velocity can
 * never overshoot, bounce, or reverse. For frozen k this is the exact flow;
 * for the quadratic term it decays at least as fast as the continuum
 * (e^(−x) <= 1/(1+x)) — always on the safe side.
 */
export function exponentialDragFactor(
  aero: AeroParams, rho: number, speedRel: number, dt: number,
): number {
  return Math.exp(-dragK(aero, rho, speedRel) * dt);
}


/** Instantaneous drag deceleration magnitude = k·|v| = betaQ·rho·v² + betaL·rho·v. */
export function dragDecel(aero: AeroParams, rho: number, speedRel: number): number {
  return dragK(aero, rho, speedRel) * speedRel;
}


/**
 * Lift coefficient with C¹ stall: linear C_lα·α below alphaCrit, smooth
 * 1/(1+((|α|−αc)/s)²) rolloff above (never negative, never discontinuous).
 */
export function liftCoefficient(aero: AeroParams, alpha: number): number {
  const a = alpha < 0 ? -alpha : alpha;
  let cl = aero.clAlpha * alpha;
  if (a > aero.alphaCrit) {
    const t = (a - aero.alphaCrit) / aero.stallSoftness;
    cl *= 1 / (1 + t * t);
  }
  return cl;
}


/** Lift acceleration magnitude: ½·rho·v²·C_l·S / m, m/s². */
export function liftAccel(
  aero: AeroParams, rho: number, speedRel: number, cl: number,
): number {
  return 0.5 * rho * speedRel * speedRel * cl * aero.wingArea / aero.mass;
}


/**
 * Attitude-loop damping. Grows with dynamic pressure: at high q the control
 * surfaces bite AND aerodynamic damping rises — response gets faster and
 * more damped simultaneously (see M1D analysis §1.3). Feeds the exact
 * exponential tracker in FlightController — no oscillatory mode exists.
 */
export function controlDamping(aero: AeroParams, qDyn: number): number {
  const s = qDyn / aero.qRef;
  return aero.baseDamping + aero.qDamping * (s < aero.qClamp ? s : aero.qClamp);
}
```

}

/* ===========================================================================
 * QUATERNION MATH (Float64, out-param style, zero allocation)
 * Body frame: +X forward, +Y up, +Z = X×Y (left) — right-handed.
 * ======================================================================== */


export function quatIntegrateInPlace(q: Quat, wx: number, wy: number, wz: number, dt: number): void {
  // q̇ = ½ · q ⊗ (0, ω)  (body-frame rates)
  const dw = -0.5 * dt * (q.x * wx + q.y * wy + q.z * wz);
  const dx = 0.5 * dt * (q.w * wx + q.y * wz - q.z * wy);
  const dy = 0.5 * dt * (q.w * wy + q.z * wx - q.x * wz);
  const dz = 0.5 * dt * (q.w * wz + q.x * wy - q.y * wx);
  q.x += dx; q.y += dy; q.z += dz; q.w += dw;
  const inv = 1 / Math.sqrt(q.x * q.x + q.y * q.y + q.z * q.z + q.w * q.w);
  q.x *= inv; q.y *= inv; q.z *= inv; q.w *= inv;
}


/** Rotate body -> world: v' = q ⊗ v ⊗ q*. */
function rotBodyToWorldInto(q: Quat, vx: number, vy: number, vz: number, out: Vec3): Vec3 {
  const tx = 2 * (q.y * vz - q.z * vy);
  const ty = 2 * (q.z * vx - q.x * vz);
  const tz = 2 * (q.x * vy - q.y * vx);
  out.x = vx + q.w * tx + (q.y * tz - q.z * ty);
  out.y = vy + q.w * ty + (q.z * tx - q.x * tz);
  out.z = vz + q.w * tz + (q.x * ty - q.y * tx);
  return out;
}


/** Rotate world -> body (conjugate). */
function rotWorldToBodyInto(q: Quat, vx: number, vy: number, vz: number, out: Vec3): Vec3 {
  const qx = -q.x, qy = -q.y, qz = -q.z, qw = q.w;
  const tx = 2 * (qy * vz - qz * vy);
  const ty = 2 * (qz * vx - qx * vz);
  const tz = 2 * (qx * vy - qy * vx);
  out.x = vx + qw * tx + (qy * tz - qz * ty);
  out.y = vy + qw * ty + (qz * tx - qx * tz);
  out.z = vz + qw * tz + (qx * ty - qy * tx);
  return out;
}


/** Quaternion from an orthonormal body basis (f = forward, u = up; z = f×u). */
export function quatFromBasisInto(
  fx: number, fy: number, fz: number,
  ux: number, uy: number, uz: number,
  out: Quat,
): Quat {
  const zx = fy * uz - fz * uy;
  const zy = fz * ux - fx * uz;
  const zz = fx * uy - fy * ux;
  const m00 = fx, m10 = fy, m20 = fz;   // column X = forward
  const m01 = ux, m11 = uy, m21 = uz;   // column Y = up
  const m02 = zx, m12 = zy, m22 = zz;   // column Z = f×u
  const tr = m00 + m11 + m22;
  if (tr > 0) {
    const s = Math.sqrt(tr + 1) * 2;
    out.w = 0.25 * s;
    out.x = (m21 - m12) / s;
    out.y = (m02 - m20) / s;
    out.z = (m10 - m01) / s;
  } else if (m00 > m11 && m00 > m22) {
    const s = Math.sqrt(1 + m00 - m11 - m22) * 2;
    out.w = (m21 - m12) / s;
    out.x = 0.25 * s;
    out.y = (m01 + m10) / s;
    out.z = (m02 + m20) / s;
  } else if (m11 > m22) {
    const s = Math.sqrt(1 + m11 - m00 - m22) * 2;
    out.w = (m02 - m20) / s;
    out.x = (m01 + m10) / s;
    out.y = 0.25 * s;
    out.z = (m12 + m21) / s;
  } else {
    const s = Math.sqrt(1 + m22 - m00 - m11) * 2;
    out.w = (m10 - m01) / s;
    out.x = (m02 + m20) / s;
    out.y = (m12 + m21) / s;
    out.z = 0.25 * s;
  }
  return out;
}

const _vAtm: Vec3 = { x: 0, y: 0, z: 0 };
const _vRel: Vec3 = { x: 0, y: 0, z: 0 };
const _vBody: Vec3 = { x: 0, y: 0, z: 0 };

}


/* ===========================================================================
 * FLIGHT CONTROLLER
 * ======================================================================== */


export class FlightController {
  // ---- flight state (owned; mutated only by this class) ------------------
  readonly pos: Vec3 = { x: 0, y: 0, z: 0 };
  readonly vel: Vec3 = { x: 0, y: 0, z: 0 };
  readonly quat: Quat = { x: 0, y: 0, z: 0, w: 1 };
  /** Body-frame angular velocity: x = roll, y = yaw, z = pitch (rad/s). */
  readonly angVel: Vec3 = { x: 0, y: 0, z: 0 };
  readonly input: ShipInput = { pitch: 0, roll: 0, yaw: 0, throttle: 0 };
  readonly telemetry: FlightTelemetry = {
    altMSL: 0, altAGL: 0, climbRate: 0,
    rho: 0, qDyn: 0, pressure: 0,
    mach: 0, soundSpeed: 340, airspeed: 0, groundSpeed: 0,
    dragDecel: 0, dragForceN: 0, liftAccel: 0, thrustAccel: 0,
    gLoad: 0, peakG: 0, vSafe: Number.POSITIVE_INFINITY,
    governorActive: false, inAtmosphere: false, grounded: false,
    mode: 'SUBSONIC',
  };
  readonly integrity: FlightIntegrity = {
    ticks: 0, maxDeltaVAirborne: 0, reversals: 0,
    minSampledAGL: Number.POSITIVE_INFINITY, minPostTickAGL: Number.POSITIVE_INFINITY,
    contacts: 0, ddaSamples: 0, nanEvents: 0,
  };


  /**
   * Per-tick observer (harness trace capture). Assigned a MODULE FUNCTION
   * (never a closure) — called at the end of every integrateFlight with
   * valid, post-resolution state. Zero allocation.
   */
  tickObserver: ((c: FlightController) => void) | null = null;


  private readonly _cfg: FlightConfig;
  private readonly _prevPos: Vec3 = { x: 0, y: 0, z: 0 };
  private readonly _snapPos: Vec3 = { x: 0, y: 0, z: 0 };
  private readonly _snapVel: Vec3 = { x: 0, y: 0, z: 0 };
  private readonly _snapQuat: Quat = { x: 0, y: 0, z: 0, w: 1 };
  private readonly _velStart: Vec3 = { x: 0, y: 0, z: 0 };
  // Optional write-through into an M1A EntityState (absPos / velocity).
  private _wtPos: Vec3 | null = null;
  private _wtVel: Vec3 | null = null;
  private _accumulator = 0;
  private _grounded = false;
  private _contactThisTick = false;


  constructor(cfg: FlightConfig) {
    this._cfg = cfg;
  }


  /** Bind the M1A entity storage for zero-copy write-through (setup path). */
  attachWriteThrough(absPos: Vec3, velocity: Vec3): void {
    this._wtPos = absPos;
    this._wtVel = velocity;
  }


  resetIntegrityStats(): void {
    this.integrity.ticks = 0;
    this.integrity.maxDeltaVAirborne = 0;
    this.integrity.reversals = 0;
    this.integrity.minSampledAGL = Number.POSITIVE_INFINITY;
    this.integrity.minPostTickAGL = Number.POSITIVE_INFINITY;
    this.integrity.contacts = 0;
    this.integrity.ddaSamples = 0;
    this.integrity.nanEvents = 0;
    this.telemetry.peakG = 0;
  }


  /** Scripted relocation (tests / respawn). Setup path. */
  teleport(
    px: number, py: number, pz: number,
    vx: number, vy: number, vz: number,
    q?: Quat,
  ): void {
    this.pos.x = px; this.pos.y = py; this.pos.z = pz;
    this.vel.x = vx; this.vel.y = vy; this.vel.z = vz;
    if (q !== undefined) {
      this.quat.x = q.x; this.quat.y = q.y; this.quat.z = q.z; this.quat.w = q.w;
    }
    this.angVel.x = 0; this.angVel.y = 0; this.angVel.z = 0;
    this._prevPos.x = px; this._prevPos.y = py; this._prevPos.z = pz;
    this._grounded = false;
  }


  /**
   * Fixed-step governor (Spec 02.6): accumulate wall time, run whole 1/60
   * ticks, cap substeps, SHED the backlog beyond — never dilate dt.
   */
  update(dtRealSeconds: number, maxSubsteps: number = MAX_SUBSTEPS): number {
    if (!Number.isFinite(dtRealSeconds) || dtRealSeconds <= 0) return 0;
    const dt = dtRealSeconds > 0.25 ? 0.25 : dtRealSeconds;
    this._accumulator += dt;
    let n = 0;
    while (this._accumulator >= FLIGHT_DT && n < maxSubsteps) {
      this.integrateFlight(FLIGHT_DT);
      this._accumulator -= FLIGHT_DT;
      n++;
    }
    if (this._accumulator >= FLIGHT_DT) this._accumulator = 0; // shed
    if (this._wtPos !== null) {
      this._wtPos.x = this.pos.x; this._wtPos.y = this.pos.y; this._wtPos.z = this.pos.z;
      this._wtVel.x = this.vel.x; this._wtVel.y = this.vel.y; this._wtVel.z = this.vel.z;
    }
    return n;
  }


  /* =======================================================================
   * THE FIXED TICK — dt = 1/60 s, allocation-free.
   * ===================================================================== */
  integrateFlight(dt: number): void {
    const cfg = this._cfg;
    const atm = cfg.atmosphere;
    const aero = cfg.aero;
    const R = cfg.planetRadius;


    // -- A. snapshots ------------------------------------------------------
    this._snapPos.x = this.pos.x; this._snapPos.y = this.pos.y; this._snapPos.z = this.pos.z;
    this._snapVel.x = this.vel.x; this._snapVel.y = this.vel.y; this._snapVel.z = this.vel.z;
    this._snapQuat.x = this.quat.x; this._snapQuat.y = this.quat.y;
    this._snapQuat.z = this.quat.z; this._snapQuat.w = this.quat.w;
    this._velStart.x = this.vel.x; this._velStart.y = this.vel.y; this._velStart.z = this.vel.z;
    this._contactThisTick = false;


    // -- B. kinematics ------------------------------------------------------
    let r = Math.sqrt(this.pos.x * this.pos.x + this.pos.y * this.pos.y + this.pos.z * this.pos.z);
    if (r < 1) r = 1; // degenerate guard
    const invR = 1 / r;
    const altMSL = r - R;
    const rho = densityAt(atm, altMSL);
    atmosphereVelocityInto(cfg.planetSpin, this.pos.x, this.pos.y, this.pos.z, _vAtm);
    _vRel.x = this.vel.x - _vAtm.x;
    _vRel.y = this.vel.y - _vAtm.y;
    _vRel.z = this.vel.z - _vAtm.z;
    let speedRel = Math.sqrt(_vRel.x * _vRel.x + _vRel.y * _vRel.y + _vRel.z * _vRel.z);
    const qDyn = 0.5 * rho * speedRel * speedRel;


    // -- C. ATTITUDE: rate command + exact exponential tracking ------------
    // Mapping (signs derived in M1D analysis §1.3):
    //   ω_x = −roll·rollMax (roll right), ω_y = +yaw·yawMax (nose right),
    //   ω_z = +pitch·pitchMax (nose up, rotation about body-left).
    const c = controlDamping(aero, qDyn);
    const decay = Math.exp(-c * dt);
    const inPitch = clamp(this.input.pitch, -1, 1);
    const inRoll = clamp(this.input.roll, -1, 1);
    const inYaw = clamp(this.input.yaw, -1, 1);
    const wx = -inRoll * cfg.rollRateMax;
    const wy = inYaw * cfg.yawRateMax;
    const wz = inPitch * cfg.pitchRateMax;
    this.angVel.x = wx + (this.angVel.x - wx) * decay;
    this.angVel.y = wy + (this.angVel.y - wy) * decay;
    this.angVel.z = wz + (this.angVel.z - wz) * decay;
    quatIntegrateInPlace(this.quat, this.angVel.x, this.angVel.y, this.angVel.z, dt);


    // -- D. DRAG: the exact exponential map (Spec 02.4) ---------------------
    let aDragMag = 0;
    if (rho > 0 && speedRel > 1e-9) {
      aDragMag = dragDecel(aero, rho, speedRel);   // per-second magnitude (G telemetry)
      const f = exponentialDragFactor(aero, rho, speedRel, dt);
      _vRel.x *= f; _vRel.y *= f; _vRel.z *= f;
      speedRel *= f;
      this.vel.x = _vAtm.x + _vRel.x;
      this.vel.y = _vAtm.y + _vRel.y;
      this.vel.z = _vAtm.z + _vRel.z;
    }


    // -- E. KICK (semi-implicit Euler): thrust + lift + gravity -------------
    rotBodyToWorldInto(this.quat, 1, 0, 0, _fwd);
    rotBodyToWorldInto(this.quat, 0, 1, 0, _up);
    let ax = 0, ay = 0, az = 0;               // control/conservative accel
    let sx = 0, sy = 0, sz = 0;               // sensed (non-gravitational) accel


    // Thrust with the C¹ hard-cap fade (capability governor, not a clamp).
    const speedAbs = Math.sqrt(
      this.vel.x * this.vel.x + this.vel.y * this.vel.y + this.vel.z * this.vel.z);
    const thr = this.input.throttle < 0 ? 0 : this.input.throttle > 1 ? 1 : this.input.throttle;
    let fade = 1;
    if (speedAbs > cfg.capFadeStart) {
      const t = clamp((speedAbs - cfg.capFadeStart) / (cfg.hardCapSpeed - cfg.capFadeStart), 0, 1);
      fade = 1 - t * t * (3 - 2 * t);
    }
    const thrustA = cfg.maxThrustAccel * thr * fade;
    if (thrustA > 0) {
      ax += _fwd.x * thrustA; ay += _fwd.y * thrustA; az += _fwd.z * thrustA;
      sx += _fwd.x * thrustA; sy += _fwd.y * thrustA; sz += _fwd.z * thrustA;
    }


    // Lift (work-free by construction — M1D analysis §1.2).
    let liftA = 0;
    if (rho > 0 && speedRel > 15) {
      rotWorldToBodyInto(this.quat, _vRel.x, _vRel.y, _vRel.z, _vBody);
      const invS = 1 / speedRel;
      const a = -Math.asin(clamp(_vBody.y * invS, -1, 1));   // AoA
      const cl = liftCoefficient(aero, a);
      if (cl !== 0) {
        liftA = liftAccel(aero, rho, speedRel, cl);
        const vhx = _vRel.x * invS, vhy = _vRel.y * invS, vhz = _vRel.z * invS;
        const dproj = _up.x * vhx + _up.y * vhy + _up.z * vhz;
        let nx = _up.x - dproj * vhx;
        let ny = _up.y - dproj * vhy;
        let nz = _up.z - dproj * vhz;
        const nl = Math.sqrt(nx * nx + ny * ny + nz * nz);
        if (nl > 1e-6) {
          nx /= nl; ny /= nl; nz /= nl;
          ax += nx * liftA; ay += ny * liftA; az += nz * liftA;
          sx += nx * liftA; sy += ny * liftA; sz += nz * liftA;
        } else {
          liftA = 0;
        }
      }
    }


    // Gravity (conservative; excluded from sensed G — astronaut convention).
    const g = -cfg.planetMu / (r * r);
    ax += this.pos.x * invR * g;
    ay += this.pos.y * invR * g;
    az += this.pos.z * invR * g;


    this.vel.x += ax * dt; this.vel.y += ay * dt; this.vel.z += az * dt;


    // -- F. DRIFT ------------------------------------------------------------
    this._prevPos.x = this.pos.x; this._prevPos.y = this.pos.y; this._prevPos.z = this.pos.z;
    this.pos.x += this.vel.x * dt;
    this.pos.y += this.vel.y * dt;
    this.pos.z += this.vel.z * dt;


    // -- G. DDA sweep & contact resolution -----------------------------------
    this._grounded = false;
    this._sweepTerrain(R, cfg);


    // Unreachable NaN-pathology guard only (thrust fade enforces the real cap).
    const v2 = Math.sqrt(this.vel.x * this.vel.x + this.vel.y * this.vel.y + this.vel.z * this.vel.z);
    if (v2 > cfg.safetyRescaleAbove) {
      const s = cfg.hardCapSpeed / v2;
      this.vel.x *= s; this.vel.y *= s; this.vel.z *= s;
    }


    // -- H. telemetry, integrity, observer, NaN guard -------------------------
    const t = this.telemetry;
    r = Math.sqrt(this.pos.x * this.pos.x + this.pos.y * this.pos.y + this.pos.z * this.pos.z);
    const invR2 = 1 / (r > 1 ? r : 1);
    const alt2 = r - R;
    const rho2 = densityAt(atm, alt2);
    let agl: number;
    if (r < R + cfg.maxTerrainHeight + DDA_BAND) {
      const h = terrainHeight(this.pos.x * invR2, this.pos.y * invR2, this.pos.z * invR2);
      agl = r - (R + h);
      this.integrity.ddaSamples++;
    } else {
      agl = alt2 - cfg.maxTerrainHeight; // conservative lower bound
    }
    if (agl < this.integrity.minPostTickAGL) this.integrity.minPostTickAGL = agl;
    atmosphereVelocityInto(cfg.planetSpin, this.pos.x, this.pos.y, this.pos.z, _vAtm);
    const rx = this.vel.x - _vAtm.x, ry = this.vel.y - _vAtm.y, rz = this.vel.z - _vAtm.z;
    const air = Math.sqrt(rx * rx + ry * ry + rz * rz);
    const gs = Math.sqrt(this.vel.x * this.vel.x + this.vel.y * this.vel.y + this.vel.z * this.vel.z);
    t.altMSL = alt2;
    t.altAGL = agl;
    t.climbRate = this.vel.x * this.pos.x * invR2 + this.vel.y * this.pos.y * invR2 + this.vel.z * this.pos.z * invR2;
    t.rho = rho2;
    t.qDyn = 0.5 * rho2 * air * air;
    t.pressure = rho2 * atm.rSpecific * (atm.tempSeaLevel - atm.lapseRate * (alt2 > 0 ? alt2 : 0));
    t.soundSpeed = speedOfSoundAt(atm, alt2);
    t.mach = machNumber(atm, alt2, air);
    t.airspeed = air;
    t.groundSpeed = gs;
    t.dragDecel = aDragMag;
    t.dragForceN = aDragMag * aero.mass;
    t.liftAccel = liftA;
    t.thrustAccel = thrustA;
    const sensed = Math.sqrt(sx * sx + sy * sy + sz * sz);
    t.gLoad = sensed / G0;
    if (t.gLoad > t.peakG) t.peakG = t.gLoad;
    t.vSafe = safeSpeedAt(aero, rho2);
    t.governorActive = rho2 > 0 && air > t.vSafe;
    t.inAtmosphere = alt2 < atm.atmosphereHeight;
    t.grounded = this._grounded;
    t.mode = this._grounded ? 'LANDED'
      : alt2 >= atm.atmosphereHeight ? 'EXO-ATM'
      : t.mach >= 5 ? 'HYPERSONIC'
      : t.mach >= 1 ? 'SUPERSONIC'
      : 'SUBSONIC';


    // Integrity: airborne Δv / reversal (contact ticks excluded — landing
    // impacts are terrain resolution, not aerodynamic clamping).
    const dvx = this.vel.x - this._velStart.x;
    const dvy = this.vel.y - this._velStart.y;
    const dvz = this.vel.z - this._velStart.z;
    if (!this._contactThisTick) {
      const dv = Math.sqrt(dvx * dvx + dvy * dvy + dvz * dvz);
      if (dv > this.integrity.maxDeltaVAirborne) this.integrity.maxDeltaVAirborne = dv;
      if (this._velStart.x * this.vel.x + this._velStart.y * this.vel.y + this._velStart.z * this.vel.z < -1e-9) {
        this.integrity.reversals++;
      }
    }
    this.integrity.ticks++;


    this.tickObserver?.(this);


    // NaN guard (Spec 00.2): restore the last good snapshot, count, freeze.
    if (
      !Number.isFinite(this.pos.x) || !Number.isFinite(this.pos.y) || !Number.isFinite(this.pos.z) ||
      !Number.isFinite(this.vel.x) || !Number.isFinite(this.vel.y) || !Number.isFinite(this.vel.z) ||
      !Number.isFinite(this.quat.w)
    ) {
      this.pos.x = this._snapPos.x; this.pos.y = this._snapPos.y; this.pos.z = this._snapPos.z;
      this.vel.x = this._snapVel.x; this.vel.y = this._snapVel.y; this.vel.z = this._snapVel.z;
      this.quat.x = this._snapQuat.x; this.quat.y = this._snapQuat.y;
      this.quat.z = this._snapQuat.z; this.quat.w = this._snapQuat.w;
      this.integrity.nanEvents++;
    }
  }


  /* =======================================================================
   * ANALYTIC 2D DDA TERRAIN SWEEP (Spec 01.3 — worker-independent)
   *
   * Marches the tick's path across the face-plane lattice (2,048 cells per
   * cube side) using per-axis next-boundary stepping (Amanatides–Woo,
   * recomputed per sample so sphere-path curvature is handled exactly),
   * capped at a 4 m max gap. Every sample evaluates the SAME f64 noise
   * field the workers render — collision is exact regardless of chunk
   * streaming state. No-clip bound: gap·(Lipschitz+1) − clearance < 6 m of
   * transient mid-gap penetration, ALWAYS detected at the next sample;
   * every tick ENDS at or above the surface.
   * ===================================================================== */
  private _sweepTerrain(R: number, cfg: FlightConfig): void {
    const p0 = this._prevPos, p1 = this.pos;
    const dx = p1.x - p0.x, dy = p1.y - p0.y, dz = p1.z - p0.z;
    const seg = Math.sqrt(dx * dx + dy * dy + dz * dz);
    if (seg < 1e-9) return;


    // Early-out: the whole segment is outside the terrain shell.
    {
      const dd = dx * dx + dy * dy + dz * dz;
      let tt = -(p0.x * dx + p0.y * dy + p0.z * dz) / dd;
      tt = clamp(tt, 0, 1);
      const cx = p0.x + dx * tt, cy = p0.y + dy * tt, cz = p0.z + dz * tt;
      const rMin = Math.sqrt(cx * cx + cy * cy + cz * cz);
      if (rMin > R + cfg.maxTerrainHeight + DDA_CLEARANCE + DDA_LIPSCHITZ * DDA_MAX_GAP) return;
    }


    segP0x = p0.x; segP0y = p0.y; segP0z = p0.z;
    segDx = dx; segDy = dy; segDz = dz; segLen = seg;


    const r0 = Math.sqrt(p0.x * p0.x + p0.y * p0.y + p0.z * p0.z);
    const r1 = Math.sqrt(p1.x * p1.x + p1.y * p1.y + p1.z * p1.z);
    sphereToCubeInto(p0.x / r0, p0.y / r0, p0.z / r0, _cc0);
    sphereToCubeInto(p1.x / r1, p1.y / r1, p1.z / r1, _cc1);
    const sameFace = _cc0.face === _cc1.face;
    const duDs = sameFace ? (_cc1.u - _cc0.u) / seg : 0;
    const dvDs = sameFace ? (_cc1.v - _cc0.v) / seg : 0;
    const cell = 2 / DDA_LATTICE;


    let s = 0;
    let sPrev = 0;
    let events = 0;
    // sample s = 0
    if (this._sampleAt(0, R, cfg)) return;
    while (s < seg - 1e-6 && events++ < DDA_MAX_EVENTS) {
      let step = DDA_MAX_GAP;
      if (sameFace) {
        // Current (u, v) — recomputed per sample (exact under curvature).
        const t = s / seg;
        const px = segP0x + segDx * t, py = segP0y + segDy * t, pz = segP0z + segDz * t;
        const rr = Math.sqrt(px * px + py * py + pz * pz);
        if (rr < R + cfg.maxTerrainHeight + DDA_BAND) {
          sphereToCubeInto(px / rr, py / rr, pz / rr, _ccS);
          const iu = Math.floor((_ccS.u + 1) / cell);
          const iv = Math.floor((_ccS.v + 1) / cell);
          if (duDs > 1e-12) {
            const ub = -1 + (iu + 1) * cell;
            step = Math.min(step, (ub - _ccS.u) / duDs);
          } else if (duDs < -1e-12) {
            const ub = -1 + iu * cell;
            step = Math.min(step, (_ccS.u - ub) / -duDs);
          }
          if (dvDs > 1e-12) {
            const vb = -1 + (iv + 1) * cell;
            step = Math.min(step, (vb - _ccS.v) / dvDs);
          } else if (dvDs < -1e-12) {
            const vb = -1 + iv * cell;
            step = Math.min(step, (_ccS.v - vb) / -dvDs);
          }
        }
      }
      if (step < 0.01) step = 0.01;
      let sNext = s + step;
      if (sNext >= seg - 1e-6) sNext = seg;
      if (this._sampleAt(sNext, R, cfg)) return;
      sPrev = sNext;
      s = sNext;
    }
    // Exact endpoint sample if the loop overshoot past it.
    if (s < seg - 1e-6) {
      void sPrev;
      if (this._sampleAt(seg, R, cfg)) return;
    }
  }


  /** Sample the path at arc parameter s. Returns true if a contact was
   *  detected and resolved (sweep terminates). */
  private _sampleAt(s: number, R: number, cfg: FlightConfig): boolean {
    const t = s / segLen;
    const px = segP0x + segDx * t, py = segP0y + segDy * t, pz = segP0z + segDz * t;
    const r = Math.sqrt(px * px + py * py + pz * pz);
    if (r >= R + cfg.maxTerrainHeight + DDA_BAND) return false;
    const inv = 1 / r;
    const h = terrainHeight(px * inv, py * inv, pz * inv);
    const agl = r - (R + h);
    this.integrity.ddaSamples++;
    if (agl < this.integrity.minSampledAGL) this.integrity.minSampledAGL = agl;
    if (agl < DDA_CLEARANCE) {
      this._resolveContact(s, R, cfg);
      return true;
    }
    return false;
  }


  /** Bisection contact resolution: place at surface + clearance, kill the
   *  inward radial velocity, damp tangential, settle to LANDED when slow. */
  private _resolveContact(sUnsafe: number, R: number, cfg: FlightConfig): void {
    let lo = Math.max(0, sUnsafe - DDA_MAX_GAP * 1.5);
    let hi = sUnsafe;
    for (let k = 0; k < DDA_BISECT; k++) {
      const sm = 0.5 * (lo + hi);
      const t = sm / segLen;
      const px = segP0x + segDx * t, py = segP0y + segDy * t, pz = segP0z + segDz * t;
      const r = Math.sqrt(px * px + py * py + pz * pz);
      const inv = 1 / (r > 1 ? r : 1);
      const h = terrainHeight(px * inv, py * inv, pz * inv);
      if (r - (R + h) < DDA_CLEARANCE) hi = sm; else lo = sm;
    }
    const t = hi / segLen;
    let px = segP0x + segDx * t, py = segP0y + segDy * t, pz = segP0z + segDz * t;
    let r = Math.sqrt(px * px + py * py + pz * pz);
    if (r < 1) r = 1;
    const inv = 1 / r;
    const ddx = px * inv, ddy = py * inv, ddz = pz * inv;
    const h = terrainHeight(ddx, ddy, ddz);
    const rr = R + h + DDA_CLEARANCE;
    this.pos.x = ddx * rr; this.pos.y = ddy * rr; this.pos.z = ddz * rr;


    // Velocity resolve against the (conservative) radial contact normal.
    const vn = this.vel.x * ddx + this.vel.y * ddy + this.vel.z * ddz;
    if (vn < 0) {
      this.vel.x -= ddx * vn; this.vel.y -= ddy * vn; this.vel.z -= ddz * vn;
    }
    this.vel.x *= 0.985; this.vel.y *= 0.985; this.vel.z *= 0.985;


    atmosphereVelocityInto(cfg.planetSpin, this.pos.x, this.pos.y, this.pos.z, _vAtm);
    const rx = this.vel.x - _vAtm.x, ry = this.vel.y - _vAtm.y, rz = this.vel.z - _vAtm.z;
    if (rx * rx + ry * ry + rz * rz < 3.5 * 3.5) {
      this.vel.x = _vAtm.x; this.vel.y = _vAtm.y; this.vel.z = _vAtm.z;
      this._grounded = true;
    }
    this._contactThisTick = true;
    this.integrity.contacts++;
  }
}

(function stars(): void {
  const COUNT = 1400, RAD = 15000;
  const pos = new Float32Array(COUNT * 3);
  const rand = mulberry32(0x5eed1d);
  for (let i = 0; i < COUNT; i++) {
    const u = rand() * 2 - 1, t = rand() * Math.PI * 2;
    const s = Math.sqrt(1 - u * u);
    pos[i * 3] = Math.cos(t) * s * RAD;
    pos[i * 3 + 1] = u * RAD;
    pos[i * 3 + 2] = Math.sin(t) * s * RAD;
  }
  const g = new THREE.BufferGeometry();
  g.setAttribute('position', new THREE.BufferAttribute(pos, 3));
  sceneRoot.add(new THREE.Points(g, new THREE.PointsMaterial({
    color: 0xaec6dc, size: 1.6, sizeAttenuation: false,
    transparent: true, opacity: 0.75, fog: false, depthWrite: false,

function readUserInput(): void {

  f.pitch = (keys['ArrowUp'] ? 1 : 0) - (keys['ArrowDown'] ? 1 : 0);
  f.roll = (keys['ArrowRight'] ? 1 : 0) - (keys['ArrowLeft'] ? 1 : 0);
  f.yaw = (keys['KeyD'] ? 1 : 0) - (keys['KeyA'] ? 1 : 0);
  const thr = (keys['KeyW'] ? 1 : 0) - (keys['KeyS'] ? 1 : 0);
  f.throttle = Math.max(0, Math.min(1, f.throttle + thr * 0.8 * 0.016));
}
function autopilot(targetAlt: number): void {
  const t = flight.telemetry;
  const f = flight.input;
  f.pitch = Math.max(-0.7, Math.min(0.7, -t.climbRate / 60 - (t.altMSL - targetAlt) / 300));
  f.roll = 0; f.yaw = 0; f.throttle = 0.9;
}

function diveObserver(c: FlightController): void {
  const t = c.telemetry;
  if (t.grounded) return;
  if (script.divePrevAlt > 1000 && t.altMSL <= 1000 && script.diveSpeedAt1000 < 0) {
    script.diveSpeedAt1000 = t.groundSpeed;
  }
  script.divePrevAlt = t.altMSL;
  if (t.groundSpeed > script.diveMaxSpeed) script.diveMaxSpeed = t.groundSpeed;
  if (t.altMSL < 20000 && script.diveCount < script.diveAlt.length) {
    script.diveAlt[script.diveCount] = t.altMSL;
    script.diveSpeed[script.diveCount] = t.groundSpeed;
    script.diveCount++;
  }
  if (t.altAGL < script.diveMinPostAGL) script.diveMinPostAGL = t.altAGL;
}

function runBurn(): void {
  // canary + heap before
  const canary = {
    c: burnCtrl, pos: burnCtrl.pos, vel: burnCtrl.vel, quat: burnCtrl.quat,
    ang: burnCtrl.angVel, input: burnCtrl.input, tele: burnCtrl.telemetry,
    integ: burnCtrl.integrity,
  };
  const mem = (performance as unknown as { memory?: { usedJSHeapSize: number } }).memory;
  const heap0 = mem !== undefined ? mem.usedJSHeapSize : -1;
  burnCtrl.resetIntegrityStats();
  quatFromBasisInto(burnTan.x, burnTan.y, burnTan.z, burnDir.x, burnDir.y, burnDir.z, _bootQ);
  burnCtrl.teleport(
    burnDir.x * (R + 600), burnDir.y * (R + 600), burnDir.z * (R + 600),
    burnTan.x * 260, burnTan.y * 260, burnTan.z * 260, _bootQ,
  );
  const BURN_TICKS = 20000;
  for (let k = 0; k < BURN_TICKS; k++) {
    // deterministic input program (module scalars — zero allocation)
    const f = burnCtrl.input;
    f.pitch = 0.25 * Math.sin(0.0007 * k);
    f.roll = 0.3 * Math.sin(0.00043 * k + 1);
    f.yaw = 0.1 * Math.cos(0.00031 * k);
    f.throttle = 0.55 + 0.35 * Math.sin(0.0002 * k);
    burnCtrl.integrateFlight(1 / 60);
  }
  const heap1 = mem !== undefined ? mem.usedJSHeapSize : -1;
  burnResult.identityOk =
    burnCtrl.pos === canary.pos && burnCtrl.vel === canary.vel &&
    burnCtrl.quat === canary.quat && burnCtrl.angVel === canary.ang &&
    burnCtrl.input === canary.input && burnCtrl.telemetry === canary.tele &&
    burnCtrl.integrity === canary.integ;
  burnResult.heapDelta = heap0 >= 0 ? heap1 - heap0 : -1;
  burnResult.ticks = BURN_TICKS;
  burnResult.contacts = burnCtrl.integrity.contacts;
  burnResult.nanEvents = burnCtrl.integrity.nanEvents;
  evaluateSuite();
  script.phase = 'DONE';
  setCruiseState(flight); // hand over in stable forward flight
}

type TestKey = 'atmosphere' | 'governor-dive' | 'drag-continuity' | 'zero-gc' | 'integration';
interface TestResult { pass: boolean; detail: string; }
interface SuiteState { version: number; done: boolean; results: Partial<Record<TestKey, TestResult>>; }
let suiteState: SuiteState = { version: 0, done: false, results: {} };
const suiteListeners = new Set<() => void>();
function publishSuite(next: Partial<SuiteState>): void {
  suiteState = { ...suiteState, ...next, version: suiteState.version + 1 };
  suiteListeners.forEach((l) => l());
}
function subSuite(cb: () => void): () => void { suiteListeners.add(cb); return () => suiteListeners.delete(cb); }


/* -- rolling transfer rate -------------------------------------------------- */
const rate = { lastT: 0, recv0: 0, recv: 0 };
function updateRates(nowMs: number): void {
  if (nowMs - rate.lastT >= 1000) {
    rate.recv = pool.counters.received - rate.recv0;
    rate.recv0 = pool.counters.received;
    rate.lastT = nowMs;
  }
}

function evaluateSuite(): void {
  const results: Partial<Record<TestKey, TestResult>> = {};


  /* -- T1: atmosphere model ------------------------------------------------ */
  {
    let monotone = true;
    let prev = densityAt(EARTHSCALE_ATMOSPHERE, 0);
    for (let alt = 250; alt <= 24000; alt += 250) {
      const d = densityAt(EARTHSCALE_ATMOSPHERE, alt);
      if (!(d < prev)) { monotone = false; break; }
      prev = d;
    }
    const r0 = densityAt(EARTHSCALE_ATMOSPHERE, 0);
    const r8 = densityAt(EARTHSCALE_ATMOSPHERE, 8000);
    const r24 = densityAt(EARTHSCALE_ATMOSPHERE, 24000);
    const a0 = speedOfSoundAt(EARTHSCALE_ATMOSPHERE, 0);
    const a8 = speedOfSoundAt(EARTHSCALE_ATMOSPHERE, 8000);
    const m1 = machNumber(EARTHSCALE_ATMOSPHERE, 0, a0);
    const wind: AVec3 = { x: 0, y: 0, z: 0 };
    atmosphereVelocityInto(0.0104, 5000, 0, 0, wind);
    const windMag = Math.sqrt(wind.x * wind.x + wind.y * wind.y + wind.z * wind.z);
    const pass = monotone && r0 === 1.225 && r8 <= 0.0025 && r24 < 1e-6
      && a0 > 335 && a0 < 345 && a8 < a0 && Math.abs(m1 - 1) < 1e-9
      && Math.abs(windMag - 52) < 1e-9;
    results['atmosphere'] = {
      pass,
      detail:
        `ρ(0) = ${r0} kg/m³, strictly monotone to ${r24.toExponential(1)} at 24 km ` +
        `(ρ(8 km) = ${r8.toExponential(2)} = 0.13% of surface — vacuum asymptote, ` +
        `C∞ law ρ = ρ₀e^(−h/1200), no cutoff discontinuity). a(0) = ${a0.toFixed(1)} → ` +
        `a(8 km) = ${a8.toFixed(1)} m/s; Mach(340 m/s @ SL) = ${m1.toFixed(9)}; ` +
        `rotating-atmosphere law |Ω×p| = ${windMag.toFixed(6)} m/s at the equator ` +
        `(spec's 52 m/s example, Ω = 0.0104 rad/s).`,
    };
  }


  /* -- T2: SPEC-CANONICAL GOVERNOR DIVE ------------------------------------ */
  {
    // extract checkpoints from the trace
    ckCount = 0;
    for (let a = 0; a < CK_ALTS.length; a++) {
      for (let i = 0; i < script.diveCount; i++) {
        if (script.diveAlt[i] <= CK_ALTS[a]) { ckSpeed[a] = script.diveSpeed[i]; ckCount++; break; }
      }
    }
    const v1000 = script.diveSpeedAt1000;
    const pass = v1000 > 150 && v1000 <= 400
      && script.diveMaxSpeed >= 1980
      && script.diveMinPostAGL >= -1e-6
      && script.diveGrounded
      && flight.integrity.minPostTickAGL >= -1e-6;
    results['governor-dive'] = {
      pass,
      detail:
        `2,000 m/s vertical dive from 10 km with chunk streaming FROZEN for the entire ` +
        `descent: speed at 1,000 m altitude = ${v1000 > 0 ? v1000.toFixed(1) : 'n/a'} m/s ` +
        `(gate ≤ 400; peak ${script.diveMaxSpeed.toFixed(0)} m/s — gravity overshoot ` +
        `${(script.diveMaxSpeed - 2000).toFixed(1)} m/s during exo entry, recovered by drag). ` +
        `Analytic DDA held the ship at/above the surface on every tick ` +
        `(min post-tick AGL ${Math.max(0, script.diveMinPostAGL).toFixed(2)} m); ` +
        `${script.diveGrounded ? 'ground contact resolved analytically (LANDED)' : 'contact: see trace'} ` +
        `with ${flight.integrity.contacts} contact events — zero dependence on Web Workers.`,
    };
  }


  /* -- T3: drag continuity (no hard clamping) ------------------------------ */
  {
    const maxDv = flight.integrity.maxDeltaVAirborne;
    const rev = flight.integrity.reversals;
    // smooth crossing of 400: find trace samples bracketing 400
    let crossOk = true;
    for (let i = 1; i < script.diveCount; i++) {
      const a = script.diveSpeed[i - 1], b = script.diveSpeed[i];
      if (a >= 400 && b < 400 && a - b > 8) { crossOk = false; break; }
    }
    const pass = maxDv <= 8 && rev === 0 && crossOk
      && flight.integrity.nanEvents === 0;
    results['drag-continuity'] = {
      pass,
      detail:
        `Max airborne |Δv| per tick = ${maxDv.toFixed(2)} m/s (bound 8 — peak drag ` +
        `~17 g = 2.8 m/s per tick; a hard clamp would show hundreds); velocity ` +
        `reversals: ${rev} (the exponential map preserves direction by construction); ` +
        `the 400 m/s crossing is smooth across consecutive trace samples; NaN events: ` +
        `${flight.integrity.nanEvents}. The 2,000 m/s hard cap is a C¹ thrust fade on ` +
        `[1,880, 2,000] — never a velocity clamp.`,
    };
  }


  /* -- T4: zero-GC physics tick -------------------------------------------- */
  {
    const heap = burnResult.heapDelta;
    const heapOk = heap < 0 || heap <= 1_048_576;
    const pass = burnResult.identityOk && heapOk && burnResult.nanEvents === 0;
    results['zero-gc'] = {
      pass,
      detail:
        `${burnResult.ticks.toLocaleString()} synchronous integrateFlight ticks on a headless ` +
        `controller (DDA active, ${burnResult.contacts} terrain contacts): every state object ` +
        `identity preserved ${burnResult.identityOk ? '✓' : 'FAILED'}; ` +
        `${heap >= 0 ? `heap Δ = ${heap.toLocaleString()} B over the burn (limit 1 MB)` : 'performance.memory N/A — identity canary stands'}; ` +
        `NaN events ${burnResult.nanEvents}. Scratch is module-level; loops index-based; ` +
        `mode strings interned literals.`,
    };
  }


  /* -- T5: M1A / M1C integration ------------------------------------------- */
  {
    const rebases = script.cruiseRebases;
    const received = script.cruiseReceived;
    const geoConst = script.geoMin === script.geoMax && script.geoMin > 0;
    const localOk = core.stats.focusMaxLocalPostTick <= 1024 + 1e-6;
    const offsetOk = script.offsetErrMax <= 1e-9;
    const pass = rebases >= 5 && received >= 40 && geoConst && localOk && offsetOk;
    results['integration'] = {
      pass,
      detail:
        `30 s cruise at ${CRUISE_SPEED} m/s: ${rebases} origin shifts (256 m lattice, ` +
        `Δ f32-exact), ${received} chunks streamed through the M1C Transferable pool, ` +
        `renderer geometries constant at ${script.geoMin} (min === max across dive + cruise ` +
        `+ burn), ship f32 locals max ${core.stats.focusMaxLocalPostTick.toFixed(1)} m ≤ 1,024, ` +
        `terrain-group offset tracks −O to ${script.offsetErrMax.toExponential(0)} m. ` +
        `Ship is a kinematic f64 entity written through to the M1A core; no locked file modified.`,
    };
  }


  publishSuite({ done: true, results });
  const allPass = (['atmosphere', 'governor-dive', 'drag-continuity', 'zero-gc', 'integration'] as TestKey[])
    .every((k) => results[k]?.pass === true);
  console.log(
    `[Milestone1D] acceptance ${allPass ? 'PASSED' : 'FAILED'} — ` +
      `v@1000m=${script.diveSpeedAt1000.toFixed(1)} maxDv=${flight.integrity.maxDeltaVAirborne.toFixed(2)} ` +
      `rebases=${script.cruiseRebases} recv=${script.cruiseReceived} geo=${script.geoMin} ` +
      `burnHeap=${burnResult.heapDelta}B`,
  );
}

const _camQ = new THREE.Quaternion();
const _v1 = new THREE.Vector3();
const _v2 = new THREE.Vector3();
const _v3 = new THREE.Vector3();
const frameStats = { frames: 0, ms: 0 };


function Scene() {
  const { scene, gl } = useThree();
  const primed = useRef(2);


  useEffect(() => {
    // pool meshes live under terrainGroup so ONE transform (position = −O)
    // rebases all planet-fixed content. (TerrainMeshPool.attach only uses
    // Object3D.add — the cast satisfies the locked M1C signature.)
    pool.attach(terrainGroup as unknown as THREE.Scene);
    adapter.bind(SHIP_ID, shipGroup);
    pool.primeAll();
    primed.current = 2;
    return () => { adapter.unbind(SHIP_ID); };
  }, [scene, gl]);


  useFrame((state, delta) => {
    if (primed.current > 0) {
      primed.current--;
      if (primed.current === 0) pool.unprimeAll();
    }
    const dt = delta > 0.1 ? 0.1 : delta;
    const nowMs = performance.now();


    /* -- (1) scripted phase machine: inputs + time scale ------------------ */
    let timeScale = 1;
    if (script.phase === 'WARMUP') {
      script.warmElapsed += dt;
      autopilot(CRUISE_ALT);
      const ready = (pool.activeCount() >= 50 && script.warmElapsed > 2.5)
        || script.warmElapsed > 8;
      if (ready) startDive();
    } else if (script.phase === 'DIVE') {
      timeScale = 4;
      script.simElapsed += dt * 4;
      if (flight.telemetry.grounded || script.simElapsed > 45) startCruise();
    } else if (script.phase === 'CRUISE') {
      timeScale = 4;
      script.simElapsed += dt * 4;
      autopilot(CRUISE_ALT);
      if (script.simElapsed >= 30) {
        script.cruiseRebases = core.stats.rebaseCount - script.cruiseRebase0;
        script.cruiseReceived = pool.counters.received - script.cruiseRecv0;
        script.phase = 'BURN';
        runBurn(); // synchronous → evaluateSuite() → DONE
      }
    } else if (script.phase === 'DONE') {
      readUserInput();
    }
    const scripted = script.phase !== 'DONE' && script.phase !== 'WARMUP'
      ? script.phase !== 'DONE' : false;


    /* -- (2) FLIGHT (Spec 01.1 steps 5–7) ---------------------------------- */
    if (!userPaused && script.phase !== 'BURN') {
      flight.update(dt * timeScale, timeScale > 1 ? 6 : 5);
    }


    /* -- (3) M1A/M1B core: rails, 256 m rebasing, f32 extract -------------- */
    if (!userPaused) core.advance(dt);


    /* -- (4) render extract: ship + terrain group offset -------------------- */
    adapter.update();
    const o = core.getOrigin();
    terrainGroup.position.set(-o.x, -o.y, -o.z);
    const offErr = Math.abs(terrainGroup.position.x + o.x)
      + Math.abs(terrainGroup.position.y + o.y)
      + Math.abs(terrainGroup.position.z + o.z);
    if (offErr > script.offsetErrMax) script.offsetErrMax = offErr;


    /* -- (5) chase camera (hard-locked to the ship local + body frame) ----- */
    const lp = shipState.localPosF32;
    _camQ.set(flight.quat.x, flight.quat.y, flight.quat.z, flight.quat.w);
    shipGroup.quaternion.copy(_camQ);
    _v1.set(-26, 9, 0).applyQuaternion(_camQ);
    state.camera.position.set(lp[0] + _v1.x, lp[1] + _v1.y, lp[2] + _v1.z);
    _v2.set(0, 1, 0).applyQuaternion(_camQ);
    state.camera.up.copy(_v2);
    _v3.set(36, 3, 0).applyQuaternion(_camQ);
    state.camera.lookAt(lp[0] + _v3.x, lp[1] + _v3.y, lp[2] + _v3.z);
    engineMat.emissiveIntensity = 0.3 + flight.input.throttle * 1.6;
    // altitude fog (mutated in place — zero allocation)
    const alt = flight.telemetry.altMSL;
    const fog = scene.fog as THREE.Fog | null;
    if (fog !== null) {
      fog.near = 500 + alt * 0.75;
      fog.far = Math.min(30000, 2600 + alt * 2.4);
    }


    /* -- (6) M1C streaming with the ABSOLUTE f64 ship position ------------- */
    camPos.x = flight.pos.x; camPos.y = flight.pos.y; camPos.z = flight.pos.z;
    if (!userPaused && !script.streamingFrozen && script.phase !== 'BURN') {
      updateController();
      pool.pump();
    }


    /* -- (7) window metrics + throttled telemetry --------------------------- */
    if (script.phase !== 'BURN') {
      const geo = state.gl.info.memory.geometries;
      if (primed.current === 0) {
        if (geo < script.geoMin) script.geoMin = geo;
        if (geo > script.geoMax) script.geoMax = geo;
      }
    }
    const frameMs = delta * 1000;
    frameStats.frames++;
    frameStats.ms += frameMs;
    if (frameStats.frames >= 30) {
      tele.fps = (frameStats.frames * 1000) / Math.max(frameStats.ms, 1e-6);
      tele.frameMs = frameStats.ms / frameStats.frames;
      frameStats.frames = 0;
      frameStats.ms = 0;
    }
    updateRates(nowMs);
    if (nowMs - lastTeleMs >= 100) {
      lastTeleMs = nowMs;
      const t = flight.telemetry;
      tele.mode = t.mode; tele.throttle = flight.input.throttle;

      tele.version++;

    }
  });
